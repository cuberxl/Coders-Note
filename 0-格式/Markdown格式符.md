## Markdown 格式符

## 一、标题

| 写法 | 效果 |
| :--- | :--- |
| `# 一级标题` | H1 |
| `## 二级标题` | H2 |
| `### 三级标题` | H3 |
| `#### 四级标题` | H4 |
| `##### 五级标题` | H5 |
| `###### 六级标题` | H6 |
| `一级标题` + `===` | H1（Setext） |
| `二级标题` + `---` | H2（Setext） |

注意：`#` 和文字之间要有空格。

---

## 二、强调

| 写法 | 效果 |
| :--- | :--- |
| `*斜体*` | *斜体* |
| `_斜体_` | _斜体_ |
| `**粗体**` | **粗体** |
| `__粗体__` | __粗体__ |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮==（部分支持） |
| `H~2~O` | H~2~O（下标，部分支持） |
| `x^2^` | x^2^（上标，部分支持） |

---

## 三、列表

### 无序列表

```markdown
- 项目1
- 项目2
  - 子项目
    - 孙项目
```

可用 `-`、`*`、`+`，同一列表内保持一致。

### 有序列表

```markdown
1. 第一项
2. 第二项
   1. 子项
   2. 子项
```

数字不必连续，渲染时自动编号。

### 任务列表

```markdown
- [ ] 未完成
- [x] 已完成
```

### 定义列表

```markdown
术语
: 定义内容
```

部分渲染器支持。

---

## 四、链接与图片

| 写法 | 效果 |
| :--- | :--- |
| `[文字](url)` | 行内链接 |
| `[文字](url "标题")` | 带标题 |
| `<https://example.com>` | 自动链接 |
| `[文字][id]` + `[id]: url` | 引用式链接 |
| `![替代文字](url)` | 图片 |
| `![替代文字](url "标题")` | 带标题图片 |
| `[![图片](img)](url)` | 图片链接 |

### 锚点

```markdown
[跳转到标题](#标题)
```

标题会生成锚点，空格转 `-`，大写转小写。

## 五、代码

| 写法 | 效果 |

| `` `代码` `` | 行内代码 |
| ```` ``` ```` | 代码块 |
| ```` ```python ```` | 指定语言高亮 |


## 六、引用

```markdown
> 一级引用
>> 二级引用
>>> 三级引用
```

| 写法 | 效果 |
| :--- | :--- |
| `> 文本` | 引用 |
| `> **粗体**` | 引用内可用其他语法 |
| `> - 列表` | 引用内列表 |

---

## 七、表格

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
| D | E | F |
```

| 写法 | 对齐 |
| :--- | :--- |
| `:---` | 左对齐 |
| `:---:` | 居中 |
| `---:` | 右对齐 |
| `---` | 默认 |

**注意**：表格第二行是分隔行，必须有。单元格内不能直接换行，需用 `<br>`。

## 十、HTML

Markdown 通常支持内嵌 HTML：

```markdown
<br>
<hr>
<b>粗体</b>
<u>下划线</u>
<sup>上标</sup>
<sub>下标</sub>
<kbd>Ctrl</kbd>
<details>
<summary>折叠标题</summary>
内容
</details>
```

| 标签 | 作用 |
| :--- | :--- |
| `<br>` | 换行 |
| `<hr>` | 分割线 |
| `<b>` / `<strong>` | 粗体 |
| `<i>` / `<em>` | 斜体 |
| `<u>` | 下划线 |
| `<sup>` / `<sub>` | 上标 / 下标 |
| `<kbd>` | 键盘按键 |
| `<mark>` | 高亮 |
| `<details>` | 折叠 |
| `<summary>` | 折叠标题 |

## 十一、数学公式

| 写法 | 效果 |
| :--- | :--- |
| `$...$` | 行内公式 |
| `$$...$$` | 块级公式 |

```markdown
行内：$E = mc^2$

块级：
$$
\int_a^b f(x) dx
$$
```

`$$` 前后建议空一行。

## 十五、踩坑提醒

- `#`、`-`、`*` 等标记和内容之间要空格。
- 表格第二行分隔行不能省。
- 代码块里的 ``` 要配对，嵌套时用更多反引号。
- 分割线 `---` 前面有空行，否则可能变成标题。
- 列表嵌套用 2 或 4 个空格缩进，保持一致。
- 转义字符只对 Markdown 语法字符有效。
- 不同渲染器支持范围不同：GitHub、Typora、Obsidian、VS Code 各有差异。
- HTML 内嵌不是所有平台都支持，部分平台会过滤。
- 数学公式、Mermaid、脚注通常需要额外配置或插件。
