#### 代码格式

**概念**：本页约定笔记中 C++ 代码的书写方式，保证同一份笔记里所有代码块的缩进、空格与高亮一致。

---

#### 缩进

**规则**：统一使用 4 个空格缩进，禁止使用 Tab。

**原因**：Tab 在不同编辑器下宽度不同，混用会让代码在网页上错位。

**示例**：

```cpp
for (int i = 0; i < n; i++) {
    if (a[i] > x) {
        cnt++;
    }
}
```

---

#### 空格

**规则**：二元运算符两侧、逗号之后、控制语句的括号之前都要留一个空格。

**正确**：

```text
int mid = (l + r) >> 1;
if (a[mid] >= k) r = mid;
for (int i = 0; i < n; i++) swap(a[i], a[i + 1]);
```

**错误**：

```text
int mid=(l+r)>>1;
if(a[mid]>=k)r=mid;
for(int i=0;i<n;i++)swap(a[i],a[i+1]);
```

**说明**：`i++`、`->`、`::` 这类一元或成员运算符不需要空格；`a[i]` 的下标紧贴方括号。

---

#### 高亮

**规则**：超过两行的代码必须放进代码块，并标注语言为 `cpp`。

**正确**：使用三个反引号加 `cpp` 包裹，页面会按 C++ 语法高亮。

**错误**：用普通段落或列表写多行代码，页面只会渲染成纯文本，关键字不会着色。

**行内代码**：函数名、变量名、单个表达式用一对反引号包裹，例如 `sort`、`O(n log n)`、`a[i]`。

---

#### 注释

**规则**：代码块内不写 `//` 注释，需要说明的内容写在代码块外面。

**原因**：注释会挤占行宽，且网页上正文与代码的说明应当放在一起阅读。

**做法**：在代码块前用「说明」「原理」「流程」等加粗标签写作一段文字。
