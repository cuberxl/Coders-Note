### 双端队列deque
---

- **定义**：`deque<int> a;`

- **迭代器**：
    - `a.begin();` // 起始迭代器
    - `a.end();` // 结束迭代器

- **访问**：
    - `a.front();` // 队首元素
    - `a.back();` // 队尾元素

- **操作**：
    - `a.push_back(x);` // 在队尾插入 x
    - `a.push_front(x);` // 在队首插入 x
    - `a.pop_back();` // 弹出队尾
    - `a.pop_front();` // 弹出队首
    - `a.clear();` // 清空队列
