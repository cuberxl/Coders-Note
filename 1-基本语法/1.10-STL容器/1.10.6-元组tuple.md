### 元组tuple

---

**定义**：C++11 引入的固定大小、可存储不同类型元素的容器，定义在 `<tuple>` 头文件中。

#### 特点

- **固定大小**：元素个数在编译期确定，不能增删。
- **类型可混合**：可存放不同类型，如 `tuple<int, string, double>`。
- **有序**：按声明顺序排列，通过下标或类型访问。
- **值语义**：可拷贝、可比较（需元素类型支持）。

#### 创建

```cpp
#include <tuple>
using namespace std;

tuple<int, string, double> t1(1, "hello", 3.14);   // 直接构造
auto t2 = make_tuple(1, "hello", 3.14);             // make_tuple
tuple<int, int> t3 = {1, 2};                        // C++17 起支持
```

#### 访问

```cpp
get<0>(t1);        // 1，按位置访问
get<1>(t1);        // "hello"
get<double>(t1);   // 3.14，按类型访问（类型唯一时可用）
```

#### 解包（C++17 结构化绑定）

```cpp
auto [a, b, c] = t1;   // a=1, b="hello", c=3.14
```

#### 常用操作

| 操作 | 写法 | 说明 |
|:---|:---|:---|
| 元素个数 | `tuple_size<decltype(t)>::value` | 编译期常量 |
| 第 i 个元素类型 | `tuple_element<i, decltype(t)>::type` | 编译期获取 |
| 拼接 | `tuple_cat(t1, t2)` | 合并两个 tuple |
| 交换 | `t1.swap(t2)` | 同类型 tuple 交换 |
| 比较 | `t1 == t2`、`t1 < t2` | 逐元素按字典序比较 |
| 解包 | `tie(a, b, c) = t1` | 按位置赋值给已有变量 |

#### 与 pair 的区别

| | tuple | pair |
|:---|:---|:---|
| 元素个数 | 任意个 | 固定 2 个 |
| 头文件 | `<tuple>` | `<utility>` |
| 访问 | `get<i>(t)` | `p.first` / `p.second` |
| 适用场景 | 多返回值、多键组合 | 二元组、map 键值 |

#### 典型用途

- **函数返回多个值**：
  ```cpp
  tuple<int, int> minmax(vector<int>& a) {
      return {*min_element(a.begin(), a.end()),
              *max_element(a.begin(), a.end())};
  }
  ```
- **作为 map 的键**：`map<tuple<int,int>, string>`
- **多键排序**：把多个字段打包成 tuple 直接比较

#### 注意

- `get<>` 的下标必须是**编译期常量**，不能用变量。
- 按类型访问时，该类型在 tuple 中必须**唯一**，否则编译错误。
- 结构化绑定需要 **C++17** 及以上标准。
