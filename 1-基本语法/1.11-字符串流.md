#### 字符串流

C++ 的 `<sstream>` 提供了基于字符串的流操作，用于在内存中对字符串进行格式化输入输出。

**基本使用**

- 输出到字符串（类似 cout）：使用 `ostringstream` 配合 `<<` 写入，通过 `.str()` 获取结果。
- 从字符串读取（类似 cin）：使用 `istringstream` 绑定字符串，配合 `>>` 提取数据。
- 可读可写：使用 `stringstream` 进行双向操作。

**清空与重置**

- `str("")` 用于清空内容。
- `clear()` 用于清除错误状态（如 EOF 标志），两者通常配合使用。

**常用操作**

| 操作 | 说明 |
|------|------|
| `oss.str()` | 获取 `oss` 中的字符串内容 |
| `oss.str(new_str)` | 将 `oss` 的内容替换为 `new_str` |
| `iss >> var` | 从 `iss` 中读取数据到变量 |
| `oss << expr` | 将表达式输出到 `oss` 中 |

**典型应用场景**

- 字符串拼接与格式化（替代 `to_string()` + 手动拼接）
- 解析带分隔符或混合类型的数据
- 类型转换（如 `string` 转 `int`/`double`）
