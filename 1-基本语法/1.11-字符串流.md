
### 字符串流
---
C++ 的 `<sstream>` 提供了基于字符串的流操作，用于在内存中对字符串进行格式化输入输出。


#### 基本使用

```cpp
#include <sstream>
#include <iostream>
#include <string>
using namespace std;

// 1. 输出到字符串（类似 cout）
ostringstream oss;
oss << "Hello " << 2024 << "!";
string s = oss.str();   // s = "Hello 2024!"

// 2. 从字符串读取（类似 cin）
string data = "100 3.14 Hello";
istringstream iss(data);
int a; double b; string c;
iss >> a >> b >> c;     // a=100, b=3.14, c="Hello"

// 3. 可读可写
stringstream ss;
ss << 42 << " " << 3.14;
int x; double y;
ss >> x >> y;           // x=42, y=3.14
```

---

#### 清空与重置

```cpp
stringstream ss;
ss << "Hello";
ss.str("");           // 清空内容
ss.clear();           // 重置状态标志（重要！）
ss << "World";        // 重新使用
```

**注意**：`str("")` 清空内容，`clear()` 清除错误状态（如 EOF 标志），两者通常配合使用。

---

#### 常用操作

| 操作 | 说明 |
|------|------|
| `oss.str()` | 获取 `oss` 中的字符串内容 |
| `oss.str(new_str)` | 将 `oss` 的内容替换为 `new_str` |
| `iss >> var` | 从 `iss` 中读取数据到变量 |
| `oss << expr` | 将表达式输出到 `oss` 中 |

---

#### 典型应用场景

- 字符串拼接与格式化（替代 `to_string()` + 手动拼接）
- 解析带分隔符或混合类型的数据
- 类型转换（如 `string` 转 `int`/`double`）
