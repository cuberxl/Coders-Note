<h3 id="双端队列deque"><span class="prefix"></span><span class="content">双端队列deque</span><span class="suffix"></span></h3>
<hr>
<ol>
<li>deque 定义</li>
<li>deque 函数</li>
</ol>
<ul>
<li>
<p>deque 双端队列</p>
</li>
<li>
<p><strong>定义</strong>：<code>deque&lt;int&gt; a;</code></p>
</li>
<li>
<p><strong>迭代器</strong>：</p>
<ul>
<li><code>a.begin();</code> // 起始迭代器</li>
<li><code>a.end();</code> // 结束迭代器</li>
</ul>
</li>
<li>
<p><strong>访问</strong>：</p>
<ul>
<li><code>a.front();</code> // 队首元素</li>
<li><code>a.back();</code> // 队尾元素</li>
</ul>
</li>
<li>
<p><strong>操作</strong>：</p>
<ul>
<li><code>a.push_back(x);</code> // 在队尾插入 x</li>
<li><code>a.push_front(x);</code> // 在队首插入 x</li>
<li><code>a.pop_back();</code> // 弹出队尾</li>
<li><code>a.pop_front();</code> // 弹出队首</li>
<li><code>a.clear();</code> // 清空队列</li>
</ul>
</li>
</ul>
