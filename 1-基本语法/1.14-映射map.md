<h3 id="映射map"><span class="prefix"></span><span class="content">映射map</span><span class="suffix"></span></h3>
<hr>
<ul>
<li>
<p><strong>map</strong></p>
<ul>
<li><strong>定义</strong>：<code>map&lt;int, int&gt; a;</code> 不允许重复键（自动去重）</li>
<li><strong>语句</strong>：<code>a[键] = 值;</code> 如果键存在则修改值，如果不存在则插入新的键值对</li>
<li>键可以是基本类型或 string 等，不一定是整数。</li>
<li>值可以是基本类型或其他类型。</li>
<li><strong>函数</strong>：<code>a.size();</code> <code>a.empty();</code> <code>a.clear();</code> <code>a.begin();</code> <code>a.end();</code> // 同 vector <code>a.insert();</code> // 插入键值对，不重复 <code>a.erase();</code> // 删除键值对 <code>a.count();</code> // 返回键是否存在（0或1）</li>
</ul>
</li>
<li>
<p><strong>multimap</strong></p>
<ul>
<li><strong>定义</strong>：<code>multimap&lt;int, int&gt; a;</code> 允许重复键</li>
<li><strong>语句</strong>：同 map</li>
<li><strong>函数</strong>：同 map，<code>a.find()</code> 只返回第一个匹配项</li>
</ul>
</li>
<li>
<p><strong>unordered_map</strong></p>
<ul>
<li><strong>定义</strong>：<code>unordered_map&lt;int, int&gt; a;</code> 不允许重复键</li>
<li><strong>语句</strong>：同 map</li>
<li><strong>函数</strong>：同 map</li>
</ul>
</li>
</ul>
