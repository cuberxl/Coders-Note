</table><p>位运算：<code>&amp;</code>, <code>|</code>, <code>~</code>, <code>^</code>, <code>&lt;&lt;</code>, <code>&gt;&gt;</code> 均为按位运算</p>
<ul>
<li>
<p><strong>左移 (<code>&lt;&lt;</code>)</strong>：<code>a &lt;&lt; 1</code> 等价于 <code>a * 2</code>，<code>a &lt;&lt; k</code> 等价于 <code>a * 2^k</code></p>
</li>
<li>
<p><strong>右移 (<code>&gt;&gt;</code>)</strong>：<code>a &gt;&gt; 1</code> 等价于 <code>a / 2</code>，<code>a &gt;&gt; k</code> 等价于 <code>a / 2^k</code></p>
</li>
</ul>
<p><strong>应用</strong>：</p>
<ul>
<li>
<p>取第 k 位 <code>a &gt;&gt; k &amp; 1</code></p>
</li>
<li>
<p><strong>取反 (<code>~</code>)</strong>：<code>~a = -a - 1</code></p>
</li>
<li>
<p><code>lowbit(x) = x &amp; -x</code> // 返回 x 的二进制最低位的 1 及其后面的 0</p>
</li>
</ul>
