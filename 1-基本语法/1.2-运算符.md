
### 运算符
---

| 运算符 | 名称 | 描述 | 示例 |
| :--- | :--- | :--- | :--- |
| `+` | 加法 | 计算两个操作数的和 | `a + b` |
| `-` | 减法 | 计算两个操作数的差 | `a - b` |
| `*` | 乘法 | 计算两个操作数的积 | `a * b` |
| `/` | 除法 | 计算两个操作数的商（整数除法截断） | `a / b` |
| `%` | 取模 | 计算两个操作数的余数 | `a % b` |
| `++` | 自增 | 将操作数加1，`i++` 先取值再加1，`++i` 先加1再取值 | `i++` / `++i` |
| `--` | 自减 | 将操作数减1，`i--` 先取值再减1，`--i` 先减1再取值 | `i--` / `--i` |
| `==` | 等于 | 判断两个操作数是否相等 | `a == b` |
| `!=` | 不等于 | 判断两个操作数是否不相等 | `a != b` |
| `>` | 大于 | 判断前一个操作数是否大于后一个操作数 | `a > b` |
| `<` | 小于 | 判断前一个操作数是否小于后一个操作数 | `a < b` |
| `>=` | 大于等于 | 判断前一个操作数是否大于等于后一个操作数 | `a >= b` |
| `<=` | 小于等于 | 判断前一个操作数是否小于等于后一个操作数 | `a <= b` |
| `&` | 按位与 | 两个操作数对应位均为1时结果为1 | `a & b` |
| `\|` | 按位或 | 两个操作数对应位至少一个为1时结果为1 | `a \| b` |
| `!` | 逻辑非 | 将操作数的逻辑值取反 | `!a` |
| `^` | 按位异或 | 两个操作数对应位不同时结果为1 | `a ^ b` |
| `~` | 按位取反 | 将操作数的每一位取反 | `~a` |
| `<<` | 左移 | 将操作数的二进制位左移若干位 | `a << 1` |
| `>>` | 右移 | 将操作数的二进制位右移若干位 | `a >> 1` |
| `?:` | 条件运算符 | 三元条件运算，判断条件真假返回不同值 | `a > b ? a : b` |
| `()` | 函数调用/括号 | 用于函数调用或改变运算优先级 | `func()` / `(a + b) * c` |
| `sizeof` | 大小运算符 | 计算操作数所占内存字节数 | `sizeof(int)` |
| `new` | 动态分配 | 在堆上动态分配内存 | `new int` |
| `delete` | 动态释放 | 释放 `new` 分配的内存 | `delete p` |
