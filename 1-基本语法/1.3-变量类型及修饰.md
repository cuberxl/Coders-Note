#### 变量类型及修饰

**概念**：变量类型决定了数据在内存中的存放方式与可表示的数值范围，修饰符则用于改变类型的符号性、存储期、可修改性或作用域。

**策略**：竞赛代码优先使用 `int` 与 `long long`，浮点数一律用 `double`，字符用 `char`，布尔用 `bool`；仅在需要节省内存时考虑 `short` 或 `unsigned`。

---

#### 基本类型

**说明**：下表列出常用基本类型在常见 64 位环境下的字节数与取值范围，实际大小可用 `sizeof` 验证。

| 类型 | 标识符 | 字节数 | 取值范围或精度 |
| :--- | :--- | :--- | :--- |
| 短整型 | `short` | 2 | $-2^{15} \sim 2^{15} - 1$ |
| 整型 | `int` | 4 | $-2^{31} \sim 2^{31} - 1$ |
| 长整型 | `long` | 4 或 8 | 视平台而定 |
| 长整型 | `long long` | 8 | $-2^{63} \sim 2^{63} - 1$ |
| 单精度浮点 | `float` | 4 | 约 $6 \sim 7$ 位有效数字 |
| 双精度浮点 | `double` | 8 | 约 $15 \sim 16$ 位有效数字 |
| 扩展精度浮点 | `long double` | 16 | 约 $18 \sim 19$ 位有效数字 |
| 字符型 | `char` | 1 | $-128 \sim 127$ 或 $0 \sim 255$ |
| 布尔型 | `bool` | 1 | `true` 或 `false` |
| 无类型 | `void` | 无 | 不表示具体值 |

**注意**：`long` 的大小随平台变化，Windows 与 64 位 Linux 上长度不同。需要明确的 64 位整数时一律写 `long long`，不要用 `long`。

**范围估算**：`int` 上限约 $2.1 \times 10^9$，`long long` 上限约 $9.2 \times 10^{18}$。两数相乘前先判断是否会溢出。

#### 类型修饰符

**说明**：修饰符加在基本类型前后，改变其符号性或存储方式。

| 修饰符 | 说明 | 示例 |
| :--- | :--- | :--- |
| `signed` | 有符号，默认行为 | `signed int` |
| `unsigned` | 无符号，只表示非负数，范围翻倍 | `unsigned int` |
| `short` | 短整型 | `short int` |
| `long` | 长整型 | `long int` |
| `long long` | 更长的整型 | `long long int` |
| `const` | 只读，值不可修改 | `const int N = 100010;` |
| `static` | 静态存储期，函数内只初始化一次 | `static int cnt;` |
| `extern` | 声明别处定义的变量 | `extern int x;` |
| `volatile` | 禁止编译器优化该变量的读写 | `volatile int flag;` |
| `register` | 建议放入寄存器，C++17 起已废弃 | `register int i;` |

**应用**：`const` 配合全局数组定义容量是竞赛中的常规写法，例如 `const int N = 100010; int a[N];`，这样容量只写一处，改动时不会遗漏。

---

#### 函数修饰符

**说明**：这类修饰符作用于函数或类成员，用于控制内联、绑定方式、异常规范与访问权限。

| 修饰符 | 说明 | 示例 |
| :--- | :--- | :--- |
| `inline` | 建议内联展开，消除调用开销 | `inline int add(int a, int b)` |
| `static` | 限制为当前文件可见 | `static void helper()` |
| `virtual` | 声明虚函数，实现运行时多态 | `virtual void draw()` |
| `override` | 显式声明重写基类虚函数 | `void draw() override` |
| `final` | 禁止继续重写或继承 | `void draw() final` |
| `const` | 常成员函数，承诺不修改成员 | `int get() const` |
| `noexcept` | 声明不抛异常 | `void func() noexcept` |
| `friend` | 声明友元，允许访问私有成员 | `friend void print(const A&)` |
| `explicit` | 禁止隐式类型转换 | `explicit A(int x)` |
| `constexpr` | 编译期求值 | `constexpr int square(int x)` |
| `mutable` | 允许常成员函数修改该成员 | `mutable int cache` |

#### 溢出与隐式转换

**定义**：有符号整型溢出在 C++ 中是未定义行为，结果不可预测；无符号整型溢出则按模 $2^n$ 回绕。

**分析**：混合运算时，较小类型会先提升为较大类型，`int` 与 `long long` 运算时结果按 `long long` 计算；但若两个 `int` 先相乘再赋值，溢出发生在赋值之前。

- 乘法的安全写法：`long long c = 1LL * a * b;`，用 `1LL` 把整个表达式提升为 64 位。
- 无符号与有符号比较时，有符号数会被转换成无符号数，此时 `-1 > 0u` 为真，容易写出反直觉的判断。
- `char` 是否有符号由编译器决定，涉及大于 $127$ 的字节值时不要依赖默认符号性。

```cpp
const int N = 100010;

long long sum = 0;

for (int i = 0; i < N; i++) {
    sum += 1LL * a[i] * b[i];
}
```
