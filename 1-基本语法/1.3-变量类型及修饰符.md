</table><h3 id="函数修饰符"><span class="prefix"></span><span class="content">函数修饰符</span><span class="suffix"></span></h3>

<table>
<thead>
<tr>
<th align="left">修饰符</th>
<th align="left">说明</th>
<th align="left">示例</th>
</tr>
</thead>
<tbody>
<tr>
<td align="left"><code>inline</code></td>
<td align="left">建议编译器将函数体展开，消除函数调用开销（仅建议，编译器可忽略）</td>
<td align="left"><code>inline int add(int a, int b) { return a + b; }</code></td>
</tr>
<tr>
<td align="left"><code>static</code></td>
<td align="left">将函数的作用域限制在当前文件（内部链接），或类内静态成员函数</td>
<td align="left"><code>static void helper() { ... }</code></td>
</tr>
<tr>
<td align="left"><code>virtual</code></td>
<td align="left">声明虚函数，用于实现多态（运行时绑定）</td>
<td align="left"><code>virtual void draw() { ... }</code></td>
</tr>
<tr>
<td align="left"><code>const</code></td>
<td align="left">声明常成员函数，承诺不修改对象成员（除 <code>mutable</code> 成员外）</td>
<td align="left"><code>int get() const { return x; }</code></td>
</tr>
<tr>
<td align="left"><code>override</code></td>
<td align="left">（C++11）显式表示重写基类虚函数，编译时检查</td>
<td align="left"><code>void draw() override { ... }</code></td>
</tr>
<tr>
<td align="left"><code>final</code></td>
<td align="left">（C++11）禁止虚函数被继续重写，或禁止类被继承</td>
<td align="left"><code>void draw() final { ... }</code> / <code>class A final { ... };</code></td>
</tr>
<tr>
<td align="left"><code>noexcept</code></td>
<td align="left">（C++11）声明函数不会抛出异常，编译器可优化</td>
<td align="left"><code>void func() noexcept { ... }</code></td>
</tr>
<tr>
<td align="left"><code>friend</code></td>
<td align="left">声明友元函数或友元类，允许访问类的私有成员</td>
<td align="left"><code>friend void print(const A&amp; a);</code></td>
</tr>
<tr>
<td align="left"><code>explicit</code></td>
<td align="left">禁止构造函数或转换运算符的隐式类型转换</td>
<td align="left"><code>explicit A(int x) { ... }</code></td>
</tr>
<tr>
<td align="left"><code>constexpr</code></td>
<td align="left">（C++11）声明常量表达式函数，编译期求值</td>
<td align="left"><code>constexpr int square(int x) { return x * x; }</code></td>
</tr>
<tr>
<td align="left"><code>mutable</code></td>
<td align="left">允许常成员函数修改该成员（常用于缓存、锁等）</td>
<td align="left"><code>mutable int cache;</code></td>
</tr>
<tr>
<td align="left"><code>static_assert</code></td>
<td align="left">（C++11）编译期断言，条件不成立则编译失败</td>
<td align="left"><code>static_assert(sizeof(int) == 4, "int must be 4 bytes");</code></td>
</tr>
</tbody>
</table>
