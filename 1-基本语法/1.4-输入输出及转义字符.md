
### 输入输出及转义字符
---
C++ 支持两种输入输出方式：流式输入输出（`cin`/`cout`）和 C 风格格式化输入输出（`scanf`/`printf`）。


#### cin / cout（流式 I/O）

`cin` 是标准输入流对象，`cout` 是标准输出流对象，使用 `>>` 和 `<<` 运算符进行数据读写，自动根据变量类型处理格式。

```cpp
#include <iostream>
using namespace std;

int a;
double b;
string s;
cin >> a >> b >> s;     // 读取三个数据
cout << "a=" << a << ", b=" << b << ", s=" << s << endl;
```

**注意**：`cin` 默认以空白字符（空格、Tab、换行）作为分隔符，读取字符串时遇空白停止。


#### cin / cout 常用成员函数

| 函数 | 说明 |
|------|------|
| `cin.get()` | 读取一个字符（包括空白符），返回 int |
| `cin.getline(char*, size)` | 读取一行到 C 风格字符串，遇换行停止 |
| `cin.ignore(n, c)` | 忽略 n 个字符，或遇到字符 c 时停止 |
| `cin.peek()` | 查看下一个字符但不提取 |
| `cin.putback(ch)` | 将一个字符放回流中 |
| `cout.put(ch)` | 输出一个字符 |
| `cout.write(str, len)` | 输出 C 风格字符串的前 len 个字符 |
| `cout.precision(n)` | 设置浮点数精度（与 `fixed` 配合） |
| `cout.width(n)` | 设置最小输出宽度（仅影响下一次） |
| `cout.fill(ch)` | 设置填充字符（默认空格） |

```cpp
// 示例：读取带空格的整行
char buf[100];
cin.getline(buf, 100);
cout << buf << endl;

// 示例：精细控制输出
cout.precision(3);
cout << fixed << 3.14159 << endl;  // 3.142
cout.width(8);
cout.fill('0');
cout << right << 42 << endl;        // 00000042
```


#### 读取整行（`getline`）

```cpp
string line;
getline(cin, line);    // 读取一整行，包括空格
```

若 `getline` 之前使用了 `cin >>`，需先处理残留的换行符：

```cpp
cin >> n;
getline(cin, s);       // 会读取残留的换行符，读不到内容
// 解决方法：
cin.ignore();          // 忽略一个字符（换行符）
getline(cin, s);       // 正确读取
```


#### scanf / printf（C 风格格式化 I/O）

`scanf` 和 `printf` 使用格式控制字符串，需包含 `<cstdio>` 头文件，适合需要精确控制格式的场景。

```cpp
#include <cstdio>

int a;
double b;
char s[100];
scanf("%d%lf%s", &a, &b, s);        // 读取
printf("a=%d, b=%.2f, s=%s\n", a, b, s);
```

**常用格式符：**

| 格式符 | 说明 |
|--------|------|
| `%d` | int |
| `%hd` | short |
| `%ld` | long |
| `%lld` | long long |
| `%u` | unsigned int |
| `%o` | 八进制整数 |
| `%x` / `%X` | 十六进制整数（小写/大写） |
| `%f` | float（输出） |
| `%lf` | double（输入用 `%lf`，输出可用 `%f`） |
| `%.nf` | 保留 n 位小数的浮点数 |
| `%e` / `%E` | 科学计数法 |
| `%c` | char |
| `%s` | char[] 字符串 |
| `%p` | 指针地址 |
| `%%` | 输出百分号 `%` |

**修饰符：**

| 修饰符 | 说明 |
|--------|------|
| `%nd` | 输出宽度为 n，右对齐，空格填充 |
| `%-nd` | 输出宽度为 n，左对齐 |
| `%0nd` | 输出宽度为 n，前导零填充 |
| `%.nf` | 浮点数保留 n 位小数 |
| `%*d` | 宽度由参数指定，如 `printf("%*d", 8, 123);` |


#### 常用转义字符

| 转义字符 | 含义 |
|----------|------|
| `\n` | 换行 |
| `\t` | 水平制表符（Tab） |
| `\r` | 回车 |
| `\a` | 响铃（Alert） |
| `\b` | 退格 |
| `\f` | 换页 |
| `\v` | 垂直制表符 |
| `\0` | 空字符（字符串结束标志） |
| `\\` | 反斜杠 `\` |
| `\'` | 单引号 `'` |
| `\"` | 双引号 `"` |
| `\xhh` | 十六进制 ASCII 码（如 `\x41` = 'A'） |
| `\ooo` | 八进制 ASCII 码（如 `\101` = 'A'） |

```cpp
cout << "第一行\n第二行\t制表符\n";
cout << "文件路径：C:\\Users\\name\n";
cout << "双引号：\"Hello\"，十六进制 A：\x41\n";
```
