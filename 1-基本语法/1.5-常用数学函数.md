#### 常用数学函数

**概念**：`<cmath>` 提供绝对值、指数对数、幂与根、取整、三角与双曲函数等数学运算，全部以 `double` 为主进行运算与返回。

**注意**：这些函数的参数与返回值多为 `double`，在精度要求高的题目中要控制误差；涉及整数运算时优先用整型函数，避免浮点误差。

---

#### 绝对值

| 函数 | 说明 |
| :--- | :--- |
| `int abs(int x)` | 整型绝对值 |
| `long labs(long x)` | 长整型绝对值 |
| `long long llabs(long long x)` | 长整型绝对值 |
| `double fabs(double x)` | 浮点绝对值 |

**注意**：`abs` 有 `int` 与 `double` 多个重载，混用 `using namespace std;` 时容易匹配到错误版本，对 `double` 求绝对值应显式写 `fabs`。

---

#### 指数与对数

| 函数 | 说明 |
| :--- | :--- |
| `double exp(double x)` | 自然指数 $e^x$ |
| `double exp2(double x)` | 以 2 为底的指数 $2^x$ |
| `double log(double x)` | 自然对数 $\ln x$，要求 $x > 0$ |
| `double log10(double x)` | 常用对数 $\log_{10} x$，要求 $x > 0$ |
| `double log2(double x)` | 以 2 为底的对数，要求 $x > 0$ |

**应用**：求一个整数有多少位，可用 `(int)log10(n) + 1`；但在 $n$ 为 $10$ 的整数次幂时可能因精度误差少算一位，需特判。

---

#### 幂与根

| 函数 | 说明 |
| :--- | :--- |
| `double sqrt(double x)` | 平方根，要求 $x \ge 0$ |
| `double cbrt(double x)` | 立方根 |
| `double pow(double x, double y)` | 幂运算 $x^y$ |
| `double hypot(double x, double y)` | 斜边长度 $\sqrt{x^2 + y^2}$ |

**注意**：`pow` 内部走浮点运算，整数幂直接用快速幂更准也更快；`pow` 在 $x < 0$ 且 $y$ 非整数时返回 `NaN`。

---

#### 取整

| 函数 | 说明 |
| :--- | :--- |
| `double ceil(double x)` | 向上取整，不小于 $x$ 的最小整数 |
| `double floor(double x)` | 向下取整，不大于 $x$ 的最大整数 |
| `double round(double x)` | 四舍五入到最近整数 |
| `double trunc(double x)` | 向零取整，截断小数部分 |

**注意**：负数上四者的差异最明显。以 $x = -1.5$ 为例，`ceil` 得 $-1$，`floor` 得 $-2$，`round` 得 $-2$，`trunc` 得 $-1$。

---

#### 三角函数与反三角函数

**说明**：所有三角函数的参数与返回值均为弧度制，不是角度制。

| 函数 | 说明 |
| :--- | :--- |
| `double sin(double x)` | 正弦 |
| `double cos(double x)` | 余弦 |
| `double tan(double x)` | 正切 |
| `double asin(double x)` | 反正弦，范围 $[-\pi/2, \pi/2]$ |
| `double acos(double x)` | 反余弦，范围 $[0, \pi]$ |
| `double atan(double x)` | 反正切，范围 $[-\pi/2, \pi/2]$ |
| `double atan2(double y, double x)` | 求 $y/x$ 的反正切，范围 $[-\pi, \pi]$，能区分象限 |

**应用**：`atan2` 保留了两个参数的符号信息，可以正确判断点所在象限；`atan(y / x)` 会把第三象限的角算成第一象限。

---

#### 双曲函数

| 函数 | 说明 |
| :--- | :--- |
| `double sinh(double x)` | 双曲正弦 |
| `double cosh(double x)` | 双曲余弦 |
| `double tanh(double x)` | 双曲正切 |
| `double asinh(double x)` | 反双曲正弦 |
| `double acosh(double x)` | 反双曲余弦，要求 $x \ge 1$ |
| `double atanh(double x)` | 反双曲正切，要求 $-1 < x < 1$ |

---

#### 其他函数

| 函数 | 说明 |
| :--- | :--- |
| `double fmod(double x, double y)` | 浮点取模，结果符号与 $x$ 相同 |
| `double remainder(double x, double y)` | 舍入到最近整数的余数 |
| `double copysign(double x, double y)` | 取 $x$ 的绝对值，符号取 $y$ 的符号 |

#### 常量与角度换算

**说明**：`M_PI` 与 `M_E` 并非 C++ 标准常量，GCC 环境下可用；需要严格可移植时自己定义。

```cpp
const double PI = acos(-1.0);
const double EPS = 1e-8;
```

**角度与弧度互转**：

- 角度转弧度：$rad = deg \times \pi / 180$。
- 弧度转角度：$deg = rad \times 180 / \pi$。

**比较浮点数**：不要用 `==`，而应写成 `fabs(a - b) < EPS`；判断大小关系时也要带容差，例如 `a > b + EPS`。
