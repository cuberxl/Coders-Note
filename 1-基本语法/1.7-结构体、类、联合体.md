#### 结构体

- **pair 二元组**
  - 定义：`pair<类型1, 类型2> a;`
  - 访问：`a.first` 访问第一个元素，`a.second` 访问第二个元素
  - 比较：先比较 `first`，`first` 相等时再比较 `second`
  - 创建：`make_pair(x, y)` 或 `{x, y}`（C++11）

- **greater\<T\>**
  - `greater<int>` 是函数对象，用于比较两个值的大小（前者是否大于后者）
  - 常用于优先队列、排序等场景，实现降序排列

- **结构体定义与重载运算符**
  - 方式一：重载小于号 `<`。在结构体内定义 `bool operator < (const Node& other) const`，常用于排序或优先队列。通过返回 `x < other.x` 实现升序，返回 `x > other.x` 实现降序。
  - 方式二：重载大于号 `>`。与小于号逻辑相反，在结构体内定义 `bool operator > (const Node& other) const`。

#### 类

- **struct 与 class 的区别**
  - `struct` 默认访问权限和继承方式为 `public`。
  - `class` 默认访问权限和继承方式为 `private`。

- **类的基本结构**
  - 包含公有 (`public`)、保护 (`protected`) 和私有 (`private`) 成员。
  - 通常包含构造函数、析构函数和成员函数。

- **构造与析构**
  - 包括默认构造（`= default`）、带参构造（使用初始化列表 `: x(v)`）、拷贝构造以及析构函数。

- **const 成员函数**
  - 在函数声明末尾加 `const`，承诺不修改成员变量，可被 `const` 对象调用。
  - 不带 `const` 的成员函数可以修改成员。

- **this 指针**
  - 指向当前对象，常用于区分同名参数和成员变量，如 `this->x = x;`。

- **静态成员**
  - 静态成员变量（`static int cnt;`）所有对象共享，必须在类外定义。
  - 静态成员函数（`static int get()`）只能访问静态成员。

- **虚函数与多态**
  - 基类中使用 `virtual` 声明虚函数，派生类使用 `override` 重写，实现运行时多态。
  - 基类的析构函数必须声明为虚析构（`virtual ~Base() = default;`）。

- **delete 禁用函数**
  - 使用 `= delete` 可以显式禁用拷贝构造和拷贝赋值（如 `A(const A&) = delete;`）。

- **友元**
  - 使用 `friend` 关键字声明友元函数或友元类，允许它们访问类的私有成员。

#### 联合体

- **定义**：一种特殊的类，所有成员共享同一块内存。
- **特点**：内存大小等于最大成员的大小；同一时间只能有一个成员有效。
- **用途**：用于节省内存，或者在底层编程中进行类型双关（Type Punning）。
