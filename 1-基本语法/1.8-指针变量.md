#### 指针变量

- **定义与核心概念**：
    - 语法：`类型说明符 * 指针变量名`（如 `int * p;`）。
    - 本质：指针变量用于存储另一个变量的**内存地址**。可通过 `(void*)p` 直接输出地址。
    - 运算符：取地址符 `&`（获取变量地址），取值（解引用）符 `*`（访问指针指向的内存）。

- **指针与普通变量的关系**：
假设有 `int a; int *p = &a;`：
    - `p` 等价于 `&a`（指针本身的值是 a 的地址）。
    - `*p` 等价于 `a`（对指针解引用，即访问 a 本身）。
    - `*p = 3` 等价于 `a = 3`（通过指针修改目标变量的值）。

- **空指针**：`NULL` 和 `nullptr`（C++11 推荐）均表示不指向任何有效内存的空地址。

- **指针的加减运算**：
    - `p++` 或 `p += 3`：指针向后移动至下一个（或第 3 个）同类型元素的内存地址。
    - `p--` 或 `p -= 3`：指针向前移动至上一个（或前 3 个）同类型元素的内存地址。

- **类型转换**：使用 `(类型*)p` 或 `类型*(p)` 将指针强制转换为其他类型的指针。
