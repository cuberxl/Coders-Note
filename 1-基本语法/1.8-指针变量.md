<h3 id="指针变量"><span class="prefix"></span><span class="content">指针变量</span><span class="suffix"></span></h3>
<hr>
<ul>
<li>
<p><strong>指针的定义</strong>：<code>类型说明符 * 指针变量名</code></p>
<ul>
<li>例如：<code>int * p;</code></li>
</ul>
</li>
<li>
<p><strong>取地址运算符</strong>：<code>&amp;</code></p>
</li>
<li>
<p><strong>取值运算符</strong>：<code>*</code></p>
</li>
<li>
<p><strong>指针的赋值</strong>：<code>p = &amp;a;</code> 把指针指向a的地址</p>
</li>
<li>
<p><strong>指针变量存取的是内存地址。</strong></p>
<ul>
<li>例如：<code>cout &lt;&lt; p;</code> <code>cout &lt;&lt; (void*)p;</code> 直接输出地址</li>
</ul>
</li>
<li>
<p><strong>指针变量与指针变量的关系</strong></p>
<ul>
<li>例如：<code>cout &lt;&lt; p;</code> 输出当前地址的地址</li>
</ul>
</li>
<li>
<p>*<em>指针变量(int <em>)与普通变量(int)的关系：</em></em></p>
<ul>
<li><code>p &lt;=&gt; &amp;a</code></li>
<li><code>*p &lt;=&gt; a</code></li>
<li><code>*p = 3 &lt;=&gt; a = 3</code></li>
</ul>
</li>
<li>
<p><code>NULL</code>、<code>nullptr</code> 都表示空地址</p>
</li>
<li>
<p><strong>指针的加减运算：</strong></p>
<ul>
<li><code>p++;</code> 指向下一个地址</li>
<li><code>p += 3;</code> 同理</li>
<li><code>p--;</code> 指向上一个地址</li>
<li><code>p -= 3;</code> 同理</li>
</ul>
</li>
<li>
<p><strong>类型转换：</strong> <code>(类型*)p</code> 或 <code>类型*(p)</code></p>
</li>
</ul>
