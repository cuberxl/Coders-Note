#### 指针变量

**概念**：指针是一种特殊的变量，它存储的不是数据本身，而是另一个变量在内存中的地址。通过指针可以间接读写那块内存。

**策略**：竞赛代码中指针主要用于数组游标、链表模拟与函数传参；能用下标表示的场合优先用下标，可读性更好，也更不容易越界。

---

#### 取地址与解引用

**定义**：取地址运算符 `&` 取得变量的内存地址，解引用运算符 `*` 访问指针所指向的内存。

**关系**：设 `int a; int* p = &a;`，则 `p` 存的是 `a` 的地址，`p` 等价于 `&a`，`*p` 等价于 `a`，`*p = 3` 等价于 `a = 3`。

```cpp
int a = 1;
int* p = &a;
*p = 3;
cout << a << " " << *p << endl;
```

**输出**：程序输出 `3 3`，说明通过指针修改的正是 `a` 本身。

---

#### 空指针与野指针

**定义**：空指针表示不指向任何有效内存，C++11 起推荐使用 `nullptr`；野指针是指向已释放或未初始化内存的指针。

**分析**：对空指针解引用会导致程序崩溃；对野指针解引用属于未定义行为，可能不崩溃但读到垃圾值，这类错误最难排查。

**规则**：指针定义时立即初始化，暂时没有指向就写 `nullptr`；`delete` 之后立刻把指针置空，防止重复释放。

#### 指针的算术运算

**说明**：指针加减的单位是所指向类型的大小，而不是字节。`int*` 加 $1$ 等于地址前进 $4$ 个字节。

| 写法 | 含义 |
| :--- | :--- |
| `p++` | 指向下一个同类型元素 |
| `p--` | 指向上一个同类型元素 |
| `p + k` | 向后移动 $k$ 个元素 |
| `p - q` | 两个指针之间相隔的元素个数 |

**应用**：数组名本身可以当作指向首元素的指针，因此 `a + i` 等价于 `&a[i]`，`*(a + i)` 等价于 `a[i]`。

```cpp
int a[5] = {1, 2, 3, 4, 5};
int* p = a;
for (int i = 0; i < 5; i++) {
    cout << p[i] << " ";
}
```

#### 指针与数组

**定义**：数组名在多数表达式中会退化为指向首元素的指针，因此可以赋值给同类型指针。

**区别**：数组名不是指针变量，不能被赋值；`sizeof(a)` 得到整个数组的字节数，而 `sizeof(p)` 得到指针本身的字节数。

**应用**：函数传参时数组会退化为指针，函数内部无法用 `sizeof` 求出元素个数，必须额外传入长度。

```cpp
void print(int a[], int n) {
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```

#### 类型转换与安全性

**说明**：可以用 `(类型*)p` 或 `类型*(p)` 把指针强制转换为其他类型的指针，转换后按新类型解释同一段内存。

**风险**：错误的对齐或越界解释属于未定义行为；用 `void*` 可以临时保存任意地址以输出查看，但不能直接解引用。

```cpp
int a = 1;
void* v = &a;
cout << v << endl;
```

**替代方案**：现代 C++ 更推荐用引用传参代替指针传参，用 `vector` 与下标代替裸指针运算，从源头减少越界与悬垂指针的可能。
