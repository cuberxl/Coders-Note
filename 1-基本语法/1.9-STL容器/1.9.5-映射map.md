#### 映射 map

**map**

- **定义**：`map<int, int> a;` 不允许重复键 ( 自动去重 )
- **语句**：`a[键] = 值;` 如果键存在则修改值，如果不存在则插入新的键值对
- **特点**：
    - 键可以是基本类型或 string 等，不一定是整数。
    - 值可以是基本类型或其他类型。
- **常用函数**：

| 函数 | 说明 |
| :--- | :--- |
| `a.size()` | 返回元素个数 |
| `a.empty()` | 判断是否为空 |
| `a.clear()` | 清空容器 |
| `a.begin()` / `a.end()` | 迭代器，同 vector |
| `a.insert()` | 插入键值对，不重复 |
| `a.erase()` | 删除键值对 |
| `a.count()` | 返回键是否存在 ( 0 或 1 ) |

**multimap**

- **定义**：`multimap<int, int> a;` 允许重复键
- **语句**：同 map
- **常用函数**：同 map，`a.find()` 只返回第一个匹配项

**unordered_map**

- **定义**：`unordered_map<int, int> a;` 不允许重复键
- **语句**：同 map
- **常用函数**：同 map
