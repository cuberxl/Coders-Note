#### 运算符

**概念**：运算符是对操作数执行运算的符号。C++ 的运算符按功能可分为算术、关系、逻辑、位、赋值、条件与 `sizeof` 等类别。

**策略**：优先级表不必背，凡是混合了位运算、比较运算、赋值运算的表达式，一律用括号写清楚，既避免出错也方便他人阅读。

---

#### 算术运算符

**说明**：整数的除法向零截断，取模只作用于整数；自增自减分前缀与后缀两种形式，在表达式内部的取值时机不同。

| 运算符 | 名称 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `+` | 加法 | 求和 | `a + b` |
| `-` | 减法 | 求差 | `a - b` |
| `*` | 乘法 | 求积 | `a * b` |
| `/` | 除法 | 整数除法向零截断，如 `-7 / 2 = -3` | `a / b` |
| `%` | 取模 | 结果符号与被除数一致，如 `-7 % 2 = -1` | `a % b` |
| `++` | 自增 | 前缀先加后用，后缀先用后加 | `i++`、`++i` |
| `--` | 自减 | 同上 | `i--`、`--i` |

**注意**：`a % b` 在 $b = 0$ 时是未定义行为；需要负数取模得到非负结果时，应写成 `(a % b + b) % b`。

---

#### 关系运算符

**说明**：关系运算符的结果是 `bool`，常用于条件判断与排序比较函数。

| 运算符 | 含义 | 示例 |
| :--- | :--- | :--- |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |

**陷阱**：浮点数不要直接用 `==` 比较，因为 $0.1 + 0.2 \ne 0.3$。判断相等应写成 `fabs(a - b) < 1e-8`。

---

#### 逻辑运算符

**说明**：逻辑运算符用于组合条件，具有短路求值特性，即前一个操作数已经能决定结果时，后一个操作数不会被求值。

| 运算符 | 含义 | 示例 | 短路行为 |
| :--- | :--- | :--- | :--- |
| `&&` | 逻辑与 | `a && b` | 左为假则不求右 |
| `\|\|` | 逻辑或 | `a \|\| b` | 左为真则不求右 |
| `!` | 逻辑非 | `!a` | 单目，无短路问题 |

**应用**：短路求值可用于边界保护，例如 `if (i < n && a[i] == x)` 中，当 `i < n` 为假时不会访问 `a[i]`，从而避免越界。

---

#### 位运算符

**说明**：位运算符直接作用于整数的二进制位，是状态压缩、集合表示、快速乘除的基础。

- **按位与** `a & b`：两位同为 $1$ 时结果为 $1$，常用于取某一位、判断奇偶 `a & 1`。
- **按位或** `a | b`：两位至少一个为 $1$ 时结果为 $1$，常用于置位。
- **按位异或** `a ^ b`：两位不同时结果为 $1$，满足 `a ^ a = 0`、`a ^ 0 = a`，可用于消去成对的数。
- **按位取反** `~a`：逐位取反，`~a = -a - 1`。
- **左移** `a << b`：等价于 $a \times 2^b$，注意位移量不小于类型位宽时行为未定义。
- **右移** `a >> b`：无符号数补 $0$；有符号负数补什么由实现决定，竞赛环境中通常按算术右移处理。

---

#### 赋值与条件运算符

| 运算符 | 含义 | 等价写法 |
| :--- | :--- | :--- |
| `=` | 赋值 | `a = b` |
| `+=` | 加后赋值 | `a = a + b` |
| `-=` | 减后赋值 | `a = a - b` |
| `*=` | 乘后赋值 | `a = a * b` |
| `/=` | 除后赋值 | `a = a / b` |
| `%=` | 取模后赋值 | `a = a % b` |
| `&=` `\|=` `^=` `<<=` `>>=` | 位运算后赋值 | 同理 |
| `?:` | 条件运算符 | `a > b ? a : b` 取较大值 |

---

#### 优先级与常见错误

**优先级**：单目 > 算术 > 移位 > 关系 > 按位 > 逻辑 > 条件 > 赋值 > 逗号。方向记忆容易出错，加括号最稳妥。

**常见错误**：

- `if (a = 0)` 是赋值不是判断，编译器通常只给警告，应写 `if (a == 0)`。
- `a & 1 == 0` 会解析成 `a & (1 == 0)`，因为 `==` 的优先级高于 `&`，应写 `(a & 1) == 0`。
- `i = i++` 在同一表达式中对同一变量多次修改，属于未定义行为。
- `int` 相乘溢出后再赋给 `long long` 已经来不及，应写成 `1LL * a * b`。
