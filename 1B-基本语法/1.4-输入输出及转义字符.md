#### 输入输出及转义字符

**概念**：C++ 提供两套输入输出方式，流式输入输出 ( `cin` 与 `cout` ) 与 C 风格格式化输入输出 ( `scanf` 与 `printf` )。前者类型安全、写法简洁，后者格式可控、常数更小。

**策略**：竞赛代码默认关闭流同步并解除绑定，再使用 `cin` 与 `cout`，兼顾写法与速度；需要精确控制小数位或宽度时改用 `printf`。

---

#### 流式输入输出

**定义**：`cin` 是标准输入流对象，`cout` 是标准输出流对象，通过 `>>` 与 `<<` 运算符按变量类型自动完成解析与格式化。

**注意**：`cin` 默认以空白字符 ( 空格、制表符、换行 ) 作为分隔符，读取字符串时遇到空白即停止。

**加速写法**：默认情况下 `cin` 与 C 的 `stdio` 保持同步，速度偏慢。关闭同步并解除 `cin` 与 `cout` 的绑定后可显著提速。

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

**常用成员函数**：

| 函数 | 说明 |
| :--- | :--- |
| `cin.get()` | 读取一个字符，包含空白符 |
| `cin.getline(char* s, int n)` | 读取一行到字符数组，遇换行停止 |
| `cin.ignore(n, ch)` | 忽略 n 个字符，或忽略到遇到字符 ch |
| `cin.peek()` | 查看下一个字符但不取出 |
| `cin.putback(ch)` | 把字符放回流中 |
| `cout.put(ch)` | 输出单个字符 |
| `cout.write(s, n)` | 输出字符数组的前 n 个字符 |
| `cout.precision(n)` | 设置浮点精度 |
| `cout.width(n)` | 设置最小输出宽度，仅对下一次输出有效 |
| `cout.fill(ch)` | 设置填充字符 |

#### 读取整行

**定义**：`getline(cin, s)` 读取一整行到一个 `string`，包含其中的空格，遇到换行结束。

**陷阱**：若在 `getline` 之前用过 `cin >>`，输入缓冲区里还残留一个换行符，`getline` 会立刻读到空行。应先调用 `cin.ignore()` 丢弃该换行。

```cpp
int n;
cin >> n;
cin.ignore();
string s;
getline(cin, s);
```

**说明**：在循环中反复混用 `cin >>` 与 `getline` 时，每一轮都要处理残留换行，否则会出现空行跳过的问题。

#### 格式化输入输出

**定义**：`scanf` 与 `printf` 通过格式控制字符串描述数据的类型与排版，需要包含 `<cstdio>` 头文件。

**常用格式符**：

| 格式符 | 对应类型 |
| :--- | :--- |
| `%d` | `int` |
| `%hd` | `short` |
| `%ld` | `long` |
| `%lld` | `long long` |
| `%u` | `unsigned int` |
| `%f` | `float` 输出，`double` 也可用 |
| `%lf` | `double` 输入必须用 `%lf` |
| `%.3f` | 保留三位小数 |
| `%e` | 科学计数法 |
| `%c` | `char` |
| `%s` | 字符数组 |
| `%o` | 八进制 |
| `%x` | 十六进制小写 |
| `%p` | 指针地址 |
| `%%` | 输出一个百分号 |

**宽度与对齐**：

| 写法 | 含义 |
| :--- | :--- |
| `%5d` | 宽度 $5$，右对齐，空格填充 |
| `%-5d` | 宽度 $5$，左对齐 |
| `%05d` | 宽度 $5$，前导零填充 |
| `%*d` | 宽度由前一个参数给出 |
| `%.3f` | 保留三位小数 |

**注意**：`scanf` 的格式符必须与变量类型严格匹配，`long long` 写成 `%d` 会只写入低 $32$ 位，造成难以察觉的错误。

#### 转义字符

**定义**：转义字符以反斜杠开头，用于表示无法直接输入的字符或具有特殊含义的字符。

| 转义字符 | 含义 |
| :--- | :--- |
| `\n` | 换行 |
| `\t` | 水平制表符 |
| `\r` | 回车 |
| `\a` | 响铃 |
| `\b` | 退格 |
| `\f` | 换页 |
| `\v` | 垂直制表符 |
| `\0` | 空字符，字符串结束标志 |
| `\\` | 反斜杠本身 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\x41` | 十六进制编码的字符，如 `\x41` 即 A |
| `\101` | 八进制编码的字符，如 `\101` 即 A |

**注意**：在 Windows 路径字符串中，`\` 必须写成 `\\`，例如 `"C:\\data\\in.txt"`；否则 `\d`、`\i` 会被当成转义序列。
