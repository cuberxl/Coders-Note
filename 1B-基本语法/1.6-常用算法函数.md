#### 常用算法函数

**概念**：`<algorithm>` 提供排序、查找、排列枚举、最值、填充与复制等通用算法，全部以迭代器区间 `[begin, end)` 为操作对象。

**策略**：能直接用标准库解决的场景不要手写，例如二分查找用 `lower_bound`、去重排序用 `sort` 与 `unique`，既短又不易错。

---

#### 排序与去重

| 函数 | 说明 |
| :--- | :--- |
| `sort(begin, end, cmp)` | 对区间排序，默认升序，$O(n \log n)$ |
| `stable_sort(begin, end, cmp)` | 稳定排序，相等元素保持原有次序 |
| `reverse(begin, end)` | 逆序区间元素，$O(n)$ |
| `unique(begin, end)` | 去除相邻重复元素，返回去重后区间的末尾迭代器 |
| `shuffle(begin, end, gen)` | 用随机数生成器打乱区间 |
| `random_shuffle(begin, end)` | C++14 起已弃用，不要再用 |

**说明**：`unique` 只删除相邻的重复元素，因此必须先用 `sort` 排序；它返回的是新的逻辑末尾，区间大小需要用返回值减去 `begin` 得到。

```cpp
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());
```

**应用**：对数组去重并统计不同元素个数，写法如下。

```cpp
sort(a, a + n);
int m = unique(a, a + n) - a;
```

#### 二分查找

**说明**：这三个函数都要求区间已按升序有序，内部使用二分实现，复杂度 $O(\log n)$。

| 函数 | 说明 |
| :--- | :--- |
| `lower_bound(begin, end, x)` | 第一个大于等于 $x$ 的位置 |
| `upper_bound(begin, end, x)` | 第一个严格大于 $x$ 的位置 |
| `binary_search(begin, end, x)` | 判断 $x$ 是否存在，返回 `bool` |

**应用**：$x$ 的出现次数等于 `upper_bound(...) - lower_bound(...)`；$x$ 的下标等于 `lower_bound(...) - begin`。

```cpp
int cnt = upper_bound(a, a + n, x) - lower_bound(a, a + n, x);
```

#### 排列枚举

**说明**：`next_permutation` 按字典序生成下一个排列并原地修改区间，返回是否还存在下一个排列；`prev_permutation` 方向相反。

**注意**：枚举前必须先把区间排成升序，否则只能枚举出从当前排列开始的一部分，会漏解。

```cpp
sort(p, p + n);
do {
    check(p);
} while (next_permutation(p, p + n));
```

**复杂度**：$n$ 个元素的排列共 $n!$ 组，因此这种枚举方式只适用于 $n \le 10$ 左右的规模。

#### 最值与交换

| 函数 | 说明 |
| :--- | :--- |
| `max(a, b)` | 返回较大值 |
| `min(a, b)` | 返回较小值 |
| `max_element(begin, end)` | 返回区间最大元素的迭代器 |
| `min_element(begin, end)` | 返回区间最小元素的迭代器 |
| `swap(a, b)` | 交换两个变量的值 |

**注意**：`max_element` 返回的是迭代器不是值，取值需要解引用，例如 `*max_element(a, a + n)`。

---

#### 填充与复制

| 函数 | 说明 |
| :--- | :--- |
| `fill(begin, end, val)` | 把区间内所有元素赋值为 $val$ |
| `copy(src_begin, src_end, dst_begin)` | 把源区间复制到目标位置 |
| `count(begin, end, val)` | 统计 $val$ 在区间中出现的次数 |

**注意**：`fill` 按元素赋值，`memset` 按字节赋值，两者不能混用；对 `int` 数组只应使用 `fill`。

#### C 风格内存操作

**说明**：以下函数定义在 `<cstring>`，直接按字节操作内存，速度快但不做类型检查。

| 函数 | 说明 |
| :--- | :--- |
| `memset(ptr, val, size)` | 把从 $ptr$ 起的 $size$ 个字节全部设为 $val$ |
| `memcpy(dst, src, size)` | 复制 $size$ 个字节，不处理区间重叠 |
| `memmove(dst, src, size)` | 复制 $size$ 个字节，可安全处理重叠 |
| `memcmp(p1, p2, size)` | 按字节比较两段内存 |
| `memchr(ptr, val, size)` | 在指定字节范围内查找字符 |

**注意**：`memset` 的第二个参数是字节值。把 `int` 数组清零写成 `memset(a, 0, sizeof a)` 是正确的，因为 $0$ 的每个字节都是 $0$；但设为 $1$ 得到的是 $0x01010101$ 而不是 $1$，这类错误很难排查。
