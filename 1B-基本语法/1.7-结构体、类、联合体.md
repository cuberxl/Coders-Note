#### 结构体、类、联合体

**概念**：结构体与类是用户自定义的复合类型，把若干不同类型的数据与作用于它们的函数打包在一起；联合体的所有成员共享同一块内存，同一时刻只能有一个成员有效。

**策略**：竞赛中结构体主要用于把多个属性绑成一个整体并重载比较运算符；类用于需要封装与多态的场景；联合体只在需要类型双关或极端节省内存时使用。

---

#### 结构体

**定义**：结构体用 `struct` 声明，默认成员与继承方式都是 `public`，通常配合构造函数初始化。

**应用**：把一组相互关联的字段打包，例如边的起点、终点与权值，避免开多个并行数组。

```cpp
struct Point {
    int x, y;
    Point() : x(0), y(0) {}
    Point(int x, int y) : x(x), y(y) {}
};
```

**注意**：`Point(int x, int y) : x(x), y(y)` 中冒号后面的 `x(x)` 是成员初始化列表，括号里的 `x` 是形参；若写成 `this->x = x;` 则是赋值，语义相同但多一次默认构造。

#### 运算符重载

**定义**：重载比较运算符后，结构体可以直接用于 `sort`、`priority_queue`、`set`、`map` 等标准库容器与算法。

**说明**：`sort` 与 `set` 依赖 `<` 判断次序，因此重载 `operator <` 是通用做法；`priority_queue` 默认是大根堆，其内部比较同样是 `<`。

```cpp
struct Node {
    int x, y;
    bool operator < (const Node& other) const {
        if (x != other.x) return x < other.x;
        return y < other.y;
    }
};
```

**分析**：返回 `x < other.x` 得到升序；若想得到降序，把返回改成 `x > other.x`。多关键字比较要先比第一关键字，相等时再比第二关键字，否则排序结果不满足字典序。

**陷阱**：`operator <` 必须满足严格弱序，即不能出现 `a < a` 为真的情况；写成 `<=` 会让 `sort` 越界访问而崩溃。

#### pair 二元组

**定义**：`pair<T1, T2>` 把两个值组合成一个整体，定义在 `<utility>` 中。

| 操作 | 说明 |
| :--- | :--- |
| `pair<T1, T2> p;` | 声明，两个成员默认初始化 |
| `p.first` | 第一个元素 |
| `p.second` | 第二个元素 |
| `make_pair(x, y)` | 构造一个 pair |
| `{x, y}` | C++11 起的列表初始化写法 |

**比较规则**：`pair` 自带 `<`，先比较 `first`，相等时再比较 `second`，因此放入 `set` 或对数组排序时天然按字典序。

#### struct 与 class

**定义**：两者唯一的强制区别是默认访问权限与默认继承方式。

| 关键字 | 默认访问权限 | 默认继承方式 |
| :--- | :--- | :--- |
| `struct` | `public` | `public` |
| `class` | `private` | `private` |

**策略**：只装数据、不涉及访问控制时用 `struct`；需要封装不变量、对外只暴露接口时用 `class`。这条约定能让代码意图更清楚。

#### 构造与析构

**定义**：构造函数在对象创建时自动调用，析构函数在对象销毁时自动调用，析构函数名前加 `~`。

**说明**：构造函数可以用初始化列表给成员赋初值，也可以在函数体内赋值；对引用成员与 `const` 成员，只能使用初始化列表。

```cpp
class Buffer {
public:
    Buffer(int n) : size(n), data(new int[n]) {}
    ~Buffer() { delete[] data; }
private:
    int size;
    int* data;
};
```

**规则**：只要类中申请了资源，就必须显式定义析构函数并在其中释放，否则会造成内存泄漏。

---

#### 虚函数与多态

**定义**：基类用 `virtual` 声明虚函数，派生类用 `override` 重写，通过基类指针或引用调用时会按实际对象类型分派，这就是运行时多态。

**规则**：基类的析构函数必须声明为虚函数，否则通过基类指针删除派生类对象时，派生类的析构函数不会被调用，造成资源泄漏。

```cpp
struct Base {
    virtual void show() const { }
    virtual ~Base() = default;
};

struct Derived : Base {
    void show() const override { }
};
```

**禁用拷贝**：在函数声明后写 `= delete` 可以显式禁用某个函数，例如 `A(const A&) = delete;` 用于禁止拷贝构造。

#### 联合体

**定义**：`union` 的所有成员共用同一段内存，其大小等于最大成员的大小。

**分析**：因为共享内存，给一个成员赋值会覆盖其他成员的内容，同一时刻只有一个成员有效。

```cpp
union Data {
    int i;
    float f;
};
```

**用途**：在内存极其受限的嵌入式场景中节省空间，或在底层编程中查看同一段字节的另一种解释；这类做法称为类型双关，标准 C++ 中更推荐 `memcpy` 而不是直接读写联合体成员。
