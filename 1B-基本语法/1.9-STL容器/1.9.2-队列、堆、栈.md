#### 队列、堆、栈

**queue 队列 ( 先进先出 FIFO )**

- **定义**：`queue<int> q;`

- **常用函数**：

| 函数 | 说明 |
| :--- | :--- |
| `q.push(x)` | 队尾插入元素 x |
| `q.pop()` | 弹出队头元素 |
| `q.front()` | 返回队头元素 |
| `q.back()` | 返回队尾元素 |
| `q.empty()` | 判断队列是否为空 |
| `q.size()` | 返回队列元素个数 |
| `q = queue<int>();` | 清空队列 |

**priority_queue 优先队列 ( 堆 )**

- **定义**：
    - 大根堆 ( 默认 )：`priority_queue<int> q;`
    - 小根堆：`priority_queue<int, vector<int>, greater<int>> q;`

- **常用函数**：

| 函数 | 说明 |
| :--- | :--- |
| `q.push(x)` | 插入元素 x( 自动维护堆序 ) |
| `q.top()` | 返回堆顶元素 ( 最大/最小 ) |
| `q.pop()` | 删除堆顶元素 |
| `q.empty()` | 判断是否为空 |
| `q.size()` | 返回元素个数 |

- **结构体自定义比较**：
    - 重载小于号：在结构体内定义 `bool operator < (const Node& other) const`，返回 `a < other.a` 为大根堆，返回 `a > other.a` 为小根堆。
    - 自定义比较结构体：定义一个包含 `bool operator()(const Node& x, const Node& y) const` 的结构体作为第三个模板参数传入。

**stack 栈 ( 先进后出 FILO )**

- **定义**：`stack<int> st;`

- **常用函数**：

| 函数 | 说明 |
| :--- | :--- |
| `st.push(x)` | 向栈顶插入元素 x |
| `st.top()` | 返回栈顶元素 |
| `st.pop()` | 弹出栈顶元素 |
| `st.empty()` | 判断栈是否为空 |
| `st.size()` | 返回栈元素个数 |

**注意事项**：

- 普通队列 `queue` 和栈 `stack` 默认基于 `deque` 实现。
- 优先队列 `priority_queue` 默认基于 `vector` 实现，本质是堆。
- 优先队列自定义比较时，`<` 对应大根堆，`>` 对应小根堆 ( 与 sort 的 cmp 逻辑相反 )。
