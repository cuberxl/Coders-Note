#### 字符串流

**概念**：`<sstream>` 提供基于字符串的流对象，把字符串当作流来读写，从而复用 `>>` 与 `<<` 的类型转换能力。

**应用**：解析用空格或逗号分隔的混合数据、把数字拼成字符串、在 `string` 与 `int` 之间转换，都比手写解析更简洁。

---

#### 三种流对象

**定义**：按读写方向分为三种，分别对应只写、只读与双向。

| 类型 | 方向 | 典型用途 |
| :--- | :--- | :--- |
| `ostringstream` | 只写，行为类似 `cout` | 把多个值拼成一个字符串 |
| `istringstream` | 只读，行为类似 `cin` | 按分隔符拆分字符串 |
| `stringstream` | 可读可写 | 既拼又拆，或做类型转换 |

```cpp
ostringstream oss;
oss << "n = " << 42;
string s = oss.str();
```

**说明**：`oss.str()` 用于取出当前内容的副本；`oss.str(new_str)` 则把内部内容整体替换为 `new_str`。

---

#### 清空与重置

**定义**：`str("")` 清空内部字符串，`clear()` 清除流的错误状态 ( 例如读到末尾后置位的 `eof` 标志 )。

**陷阱**：只调用 `str("")` 而不调用 `clear()` 时，流仍停留在失败状态，后续读写全部无效，表现为"清空之后再写入没有任何效果"。

```cpp
ss.str("");
ss.clear();
```

**规则**：重复使用同一个流对象前，这两个调用要成对出现。

---

#### 常用操作

| 操作 | 说明 |
| :--- | :--- |
| `oss.str()` | 取出流中的字符串 |
| `oss.str(s)` | 用 `s` 替换流中的内容 |
| `iss >> x` | 从流中读取一个值到 `x` |
| `oss << x` | 把一个值写入流 |
| `ss.clear()` | 清除错误状态 |

---

#### 典型应用

**应用一**：按空格拆分并解析整数，逐个数读出直到流结束。

```cpp
string s = "12 34 56";
stringstream ss(s);
int x;
while (ss >> x) {
    cout << x << " ";
}
```

**应用二**：数字转字符串，比 `to_string` 更灵活，因为可以一次拼接多个字段。

```cpp
stringstream ss;
ss << a << "," << b << "," << c;
string line = ss.str();
```

**应用三**：字符串转数字，读取失败时流会置位，可用 `if (ss >> x)` 判断转换是否成功，这一点是 `stoi` 抛异常的替代方案。

**性能**：字符串流内部有较多构造与状态维护，常数较大；数据量达到 $10^6$ 级别时不要用它逐条转换，应改用手写解析。
