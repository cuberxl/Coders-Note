#### 动态数组 vector

- **概念**：vector 是 STL 中的动态数组。

- **定义**：`vector<int> a;`

- **常用函数**：

| 函数 | 说明 |
| :--- | :--- |
| `a.size()` | 返回数组元素个数 |
| `a.clear()` | 清空数组 |
| `a.front()` | 返回第一个元素的值 |
| `a.back()` | 返回最后一个元素的值 |

- **迭代器**：

| 迭代器 | 说明 |
| :--- | :--- |
| `a.begin()` | 指向第一个元素的地址 |
| `a.end()` | 指向最后一个元素地址的下一位 |

- **定义迭代器**：`vector<int>::iterator i = a.begin();`

- **遍历方式**：

| 遍历方式 | 示例代码 |
| :--- | :--- |
| 下标遍历 | `for(int i = 0; i < a.size(); i++)` |
| 迭代器遍历 | `for(auto i = a.begin(); i != a.end(); i++)` |
| 范围 for 循环 | `for(int x : a)` |

- **增删操作**：

| 操作 | 说明 |
| :--- | :--- |
| `a.push_back(x)` | 在 vector 的末尾增加一个值为 x 的元素 |
| `a.pop_back()` | 删除 vector 的最后一个元素 |

- **去重操作**：
    - `a.erase(unique(a.begin(), a.end()), a.end());`

- **注意事项**：
	- `a.size()` 和 `a.empty()` 是 STL 通用函数。
	- `a.clear()` 在结构体数组中也适用。
