<h3 id="排序算法"><span class="prefix"></span><span class="content">排序算法</span><span class="suffix"></span></h3>
<hr>
<h4 id="①-冒泡排序-bubble-sort"><span class="prefix"></span><span class="content">① 冒泡排序 (bubble sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：相邻元素两两比较，较大元素上浮，重复多次</li>
<li><strong>时间复杂度</strong>：最好 O(n)，最坏/平均 O(n^2)</li>
<li><strong>空间复杂度</strong>：O(1)，原地排序</li>
<li><strong>稳定性</strong>：稳定</li>
</ul>
<h4 id="②-选择排序-selection-sort"><span class="prefix"></span><span class="content">② 选择排序 (selection sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：每次选取最小元素放到已排序序列的末尾/开头</li>
<li><strong>时间复杂度</strong>：最好/最坏/平均 O(n^2)</li>
<li><strong>空间复杂度</strong>：O(1)，原地排序</li>
<li><strong>稳定性</strong>：不稳定</li>
</ul>
<h4 id="③-插入排序-insertion-sort"><span class="prefix"></span><span class="content">③ 插入排序 (insertion sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：把当前元素插入到已排序子数组的正确位置</li>
<li><strong>时间复杂度</strong>：最好 O(n)，最坏/平均 O(n^2)</li>
<li><strong>空间复杂度</strong>：O(1)，原地排序</li>
<li><strong>稳定性</strong>：稳定</li>
</ul>
<h4 id="④-快速排序-quick-sort"><span class="prefix"></span><span class="content">④ 快速排序 (quick sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：分治法，选择枢轴，将数组分为两部分递归排序</li>
<li><strong>时间复杂度</strong>：平均O(nlogn)，最坏O(n^2)</li>
<li><strong>空间复杂度</strong>：O(logn)，递归栈</li>
<li><strong>稳定性</strong>：不稳定</li>
</ul>
<h4 id="⑤-归并排序-merge-sort"><span class="prefix"></span><span class="content">⑤ 归并排序 (merge sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：分治法，递归分为两半，排序后合并</li>
<li><strong>时间复杂度</strong>：最好/最坏/平均 O(nlogn)</li>
<li><strong>空间复杂度</strong>：O(n)，需要辅助数组</li>
<li><strong>稳定性</strong>：稳定</li>
</ul>
<h4 id="⑥-计数排序-counting-sort"><span class="prefix"></span><span class="content">⑥ 计数排序 (counting sort)</span><span class="suffix"></span></h4>
<ul>
<li><strong>思想</strong>：统计每个数值出现次数，累加计算位置，直接输出</li>
<li><strong>时间复杂度</strong>：O(n + k)，k = 数值范围</li>
<li><strong>空间复杂度</strong>：O(k)</li>
<li><strong>稳定性</strong>：稳定</li>
</ul>
