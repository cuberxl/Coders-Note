<h3 id="二分查找"><span class="prefix"></span><span class="content">二分查找</span><span class="suffix"></span></h3>
<p><strong>二分的核心</strong>：在有序/单调的序列中通过将搜索范围分成两半，快速找出满足条件的位置</p>
<p><strong>整数二分：</strong></p>
<p><strong>模板一：</strong> 找到中间值 <code>mid = l + r + 1 &gt;&gt; 1</code></p>
<ul>
<li>查找在区间左(右)侧检查 <code>mid</code> 是否满足条件（即右侧满足的性质）</li>
<li>为真，则答案在 <code>[mid, r]</code> 中，<code>l = mid;</code></li>
<li>为假，则答案在 <code>[l, mid - 1]</code> 中，<code>r = mid - 1;</code></li>
</ul>
<p><strong>模板二：</strong> 找到中间值 <code>mid = l + r &gt;&gt; 1</code></p>
<ul>
<li>
<p>查找在区间左(右)侧检查 <code>mid</code> 是否满足条件（即左侧满足的性质）</p>
</li>
<li>
<p>为真，则答案在 <code>[l, mid]</code> 中，<code>r = mid;</code></p>
</li>
<li>
<p>为假，则答案在 <code>[mid + 1, r]</code> 中，<code>l = mid + 1;</code></p>
</li>
<li>
<p><strong>为何第一种模板中 <code>mid = l + r + 1 &gt;&gt; 1</code></strong></p>
<ul>
<li>当 <code>l = r - 1</code> 时，<code>l + r &gt;&gt; 1 = 2r - 1 &gt;&gt; 1</code>，整除以2得 <code>mid = l</code>。</li>
<li>则当 <code>mid</code> 满足条件时，<code>l = mid</code>，区间为 <code>[l, r]</code>，导致死循环。</li>
<li>所以必须写成 <code>mid = l + r + 1 &gt;&gt; 1</code>。</li>
</ul>
</li>
<li>
<p><strong>浮点数二分：</strong> 找到中间值 <code>mid = l + r &gt;&gt; 1</code></p>
<ul>
<li>检查 <code>mid</code> 是否满足条件（即右侧满足的性质）</li>
<li>为真，则答案在 <code>[l, mid]</code> 中。</li>
<li>为假，则答案在 <code>[mid, r]</code> 中。</li>
</ul>
</li>
</ul>
<ul>
<li><strong>注意</strong>：浮点数二分不能精确找到答案，应在精度足够后退出。
<ul>
<li>方案1：当 <code>r - l &lt; 1e-6</code> 时退出，精度一般比题目要求高 2 位。</li>
<li>方案2：也可以固定迭代次数（如 100 次）后退出。</li>
</ul>
</li>
</ul>
