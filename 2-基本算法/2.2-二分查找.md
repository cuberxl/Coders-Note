### 二分查找
---
**二分的核心**：在有序/单调的序列中通过将搜索范围分成两半，快速找出满足条件的位置

**整数二分：**

**模板一：** 找到中间值 `mid = l + r + 1 >> 1`
- 查找在区间左(右)侧检查 `mid` 是否满足条件（即右侧满足的性质）
- 为真，则答案在 `[mid, r]` 中，`l = mid;`
- 为假，则答案在 `[l, mid - 1]` 中，`r = mid - 1;`

**模板二：** 找到中间值 `mid = l + r >> 1`
- 查找在区间左(右)侧检查 `mid` 是否满足条件（即左侧满足的性质）
- 为真，则答案在 `[l, mid]` 中，`r = mid;`
- 为假，则答案在 `[mid + 1, r]` 中，`l = mid + 1;`

- **为何第一种模板中 `mid = l + r + 1 >> 1`**
    - 当 `l = r - 1` 时，`l + r >> 1 = 2r - 1 >> 1`，整除以2得 `mid = l`。
    - 则当 `mid` 满足条件时，`l = mid`，区间为 `[l, r]`，导致死循环。
    - 所以必须写成 `mid = l + r + 1 >> 1`。

- **浮点数二分：** 找到中间值 `mid = l + r >> 1`
    - 检查 `mid` 是否满足条件（即右侧满足的性质）
    - 为真，则答案在 `[l, mid]` 中。
    - 为假，则答案在 `[mid, r]` 中。

* **注意**：浮点数二分不能精确找到答案，应在精度足够后退出。
	* 方案1：当 `r - l < 1e-6` 时退出，精度一般比题目要求高 2 位。
	* 方案2：也可以固定迭代次数（如 100 次）后退出。
