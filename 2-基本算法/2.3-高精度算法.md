<h3 id="高精度算法"><span class="prefix"></span><span class="content">高精度算法</span><span class="suffix"></span></h3>
<ul>
<li>
<p>C++ 中的整型类型无法存储超出其范围的大整数，因此需要高精度算法。</p>
</li>
<li>
<p><strong>高精度数据的存储</strong>：用 vector 存储，低位在前，高位在后。</p>
</li>
<li>
<p><strong>高精度数据的输入</strong>：用字符串输入，再转换为 vector。</p>
</li>
<li>
<p><strong>高精度加法 (add)</strong>：</p>
<ul>
<li>从低位到高位逐位相加，进位 x，最后处理进位。</li>
<li>x 的值为 x / 10，下一位加上 x % 10，最后如果进位不为 0 则补上。</li>
</ul>
</li>
<li>
<p><strong>高精度减法 (sub)</strong>：</p>
<ul>
<li>先通过比较确定 a &gt;= b，a[i] - b[i] - t，如果小于 0，则加 10 并借位 1。</li>
<li>x = a[i] - b[i] - t，如果 <code>x &lt; 0</code>，则 <code>x += 10, t = 1</code>；否则 <code>t = 0</code>。</li>
<li>最后去掉前导零。</li>
</ul>
</li>
<li>
<p><strong>高精度乘法 (mul)</strong>：</p>
<ul>
<li>将 a 从低位到高位与 b 相乘，x = a[i] * b + t，x % 10 为当前位，x / 10 为进位。</li>
<li>最后去掉前导零。</li>
</ul>
</li>
<li>
<p><strong>高精度除法 (div)</strong>：</p>
<ul>
<li>将 a 从高位到低位逐位除以 b，x = x * 10 + a[i]，x / b 为当前位，x % b 为余数。</li>
<li>最后翻转数组并去掉前导零。</li>
</ul>
</li>
</ul>
