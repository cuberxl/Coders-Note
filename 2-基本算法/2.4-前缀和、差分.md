<h3 id="前缀和、差分"><span class="prefix"></span><span class="content">前缀和、差分</span><span class="suffix"></span></h3>
<hr>
<p><strong>前缀和</strong>：通过预处理，可以在 <code>O(1)</code> 的时间内求出子数组 <code>a[l..r]</code> 的和。</p>
<ul>
<li>
<p>一维前缀和构造：<code>S[i] = S[i-1] + a[i]</code>，<code>S[0] = 0</code></p>
</li>
<li>
<p>一维前缀和查询：<code>S[R] - S[L-1]</code></p>
</li>
<li>
<p>二维前缀和构造：<code>S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + a[i][j]</code></p>
</li>
<li>
<p>二维前缀和查询：<code>S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]</code></p>
</li>
</ul>
<p><strong>差分</strong>：通过预处理，可以在 <code>O(1)</code> 的时间内完成对子数组 <code>a[l..r]</code> 的区间加减操作。</p>
<ul>
<li>
<p>一维差分构造：<code>d[i] = a[i] - a[i-1]</code></p>
</li>
<li>
<p>一维差分区间加：<code>d[l] += c, d[r+1] -= c</code></p>
</li>
<li>
<p>二维差分构造：<code>d[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]</code></p>
</li>
<li>
<p>二维差分区间加：<br>
<code>d[x1][y1] += c, d[x2+1][y1] -= c, d[x1][y2+1] -= c, d[x2+1][y2+1] += c</code></p>
</li>
</ul>
