#### 二分查找

**概念**：在有序或单调的序列中通过将搜索范围分成两半，快速找出满足条件的位置。

**核心思想**：每次比较都能排除一半的区间，因此最多比较 $O(\log n)$ 次。

---

#### 模板一

**用途**：找满足条件的最左位置，即第一个使得 `a[mid] >= k` 的下标。

**说明**：`mid` 取下界 `(l + r) >> 1`，条件成立时把右端点收缩到 `mid`。

```cpp
while (l < r) {
    int mid = (l + r) >> 1;
    if (a[mid] >= k)
        r = mid;
    else
        l = mid + 1;
}
```

---

#### 模板二

**用途**：找满足条件的最右位置，即最后一个使得 `a[mid] <= k` 的下标。

**说明**：`mid` 取上界 `(l + r + 1) >> 1`，条件成立时把左端点抬到 `mid`。

```cpp
while (l < r) {
    int mid = (l + r + 1) >> 1;
    if (a[mid] <= k)
        l = mid;
    else
        r = mid - 1;
}
```

---

#### 取整方向的由来

**分析**：当 `l = r - 1` 时，`l + r >> 1 = 2r - 1 >> 1`，整除以 $2$ 得 `mid = l`。

**推论**：若此时 `mid` 满足条件并执行 `l = mid`，区间仍为 `[l, r]`，会陷入死循环。

**结论**：所以模板二必须写成 `mid = (l + r + 1) >> 1`，模板一则不需要加一。

---

#### 浮点数二分

**说明**：整数二分靠 `l < r` 收敛，浮点数二分不能精确找到等于答案的点，只能逼近。

**流程**：

1. 取 `mid = (l + r) / 2`。
2. 检查 `mid` 是否满足条件 ( 即右侧满足的性质 ) 。
3. 为真，则答案在 `[l, mid]` 中；为假，则答案在 `[mid, r]` 中。

**终止条件**：

- 方案 1：当 `r - l < 1e-6` 时退出，精度一般比题目要求高 2 位。
- 方案 2：也可以固定迭代次数 ( 如 100 次 ) 后退出。
