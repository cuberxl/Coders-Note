#### 高精度算法

**概念**：C++ 中的整型类型 ( 如 `long long` ) 无法存储超出其范围的大整数，因此需要利用数组或 `vector` 模拟竖式运算，即高精度算法。

**存储**：通常使用 `vector` 存储，为了便于处理进位和借位，**低位在前，高位在后** ( 即 `a[0]` 存个位 )。

**输入**：先用 `string` 读入，再从后往前遍历字符串，将字符转为数字存入 `vector` 中。

---

#### 高精度加法 ( add )

**原理**：从低位到高位逐位相加，并处理进位。

**流程**：

1. 设置进位变量 $t = 0$，当前位之和为 $x = a[i] + b[i] + t$。
2. 当前位保留 $x \bmod 10$，新的进位 $t = x / 10$。
3. 循环结束后，如果进位 $t$ 不为 $0$，则将其压入结果末尾。

---

#### 高精度减法 ( sub )

**原理**：先通过比较确定被减数 $a \ge b$，然后逐位相减并处理借位。

**流程**：

1. 设置借位变量 $t = 0$，当前位之差为 $x = a[i] - b[i] - t$。
2. 如果 $x < 0$，则 $x += 10$，并将借位 $t$ 设为 $1$；否则借位 $t = 0$。
3. 最后需要去除结果末尾的前导零。

---

#### 高精度乘法 ( mul )

**原理**：将大整数 $a$ 从低位到高位与较小的整数 $b$ 相乘 ( 或两个大整数相乘 )，处理进位。

**流程**：

1. 设置进位变量 $t = 0$，当前位之积为 $x = a[i] \times b + t$。
2. 当前位保留 $x \bmod 10$，新的进位 $t = x / 10$。
3. 循环结束后，如果进位 $t$ 不为 $0$，则将其压入结果末尾。

---

#### 高精度除法 ( div )

**原理**：将大整数 $a$ 从高位到低位逐位除以较小的整数 $b$。

**流程**：

1. 设置余数变量 $r = 0$，当前被除数为 $x = r \times 10 + a[i]$。
2. 当前位的商为 $x / b$，新的余数为 $x \bmod b$。
3. 最后去除结果末尾的前导零。

---

#### 高精度压位

**概念**：为了大幅减少运算次数并提高效率，可以将数组中的每个元素不只存一位十进制数，而是存多位 ( 例如存 4 位或 9 位 )，此时底数由 $10$ 变为 $10^4$ 或 $10^9$。

**处理**：在加、减、乘运算时，取模和整除的底数改为相应的 $10^k$；在输出时，除了最高位之外，其余各位需要补足前导零 ( 例如 `printf("%09d", a[i])` )。
