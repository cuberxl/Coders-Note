### 并查集
---
**功能**：
- 将两个集合合并
- 查询两个元素是否属于同一集合

**基本原理**：
- 用一棵树表示一个集合，树根为集合编号
- 每个节点存储其父节点 p[x]
- 判断根：p[x] == x，则 x 为根

**核心操作**：

```cpp
// 初始化
for (int i = 1; i <= n; i++) p[i] = i;

// 查找（路径压缩）
int find(int x) {
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

// 合并
void merge(int a, int b) {
    p[find(a)] = find(b);
}

// 查询
if (find(a) == find(b)) {
    // 在同一集合中
}
```

**优化：**
- 路径压缩：查询时将路径上所有节点直接指向根节点，降低树高。
- 按秩合并：固定将高度小的树合入高度大的树，避免树退化为链。
- tips：在竞赛中，一般只写路径压缩即可。
- 时间复杂度：$O(\alpha(n))$。其中 $\alpha(n)$ 为反阿克曼函数，在竞赛中可基本认为其为常数。

**拓展域并查集：**
定义：传统并查集的拓展，能够处理集合间的不同关系，如相互独立或相互排斥。
