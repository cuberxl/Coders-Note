## 树状数组


**定义**：可在 $O(\log n)$ 的复杂度内计算前缀和，执行单点增加操作。

**引理**：$x = 2^{i_1} + 2^{i_2} + \cdots + 2^{i_k}$

则区间 $[1, x]$ 可被划分为 $\log(x)$ 个区间，即 $[1, 2^{i_1}], [2^{i_1}+1, 2^{i_1}+2^{i_2}], \dots$。

注意到各区间长度均为区间结尾元素的 $\text{lowbit}$。

建立树状数组 $C[x] = \sum_{i=x-\text{lowbit}(x)+1}^{x} a[i]$，则每个区间 $[1, x]$ 可分解为 $\log(x)$ 个小区间。

树状数组有如下性质：

1. $C[x]$ 保存以它为根的子树中所有叶子节点之和
2. $C[x]$ 的子节点个数等于 $\text{lowbit}(x)$ 的位数
3. $C[x]$ 的父节点为 $C[x + \text{lowbit}(x)]$
4. 树的深度为 $O(\log n)$

**操作**：
- **区间查询**：利用 $\text{lowbit}(x)$ 拆分求和
- **单点增加**：访问该点及其父节点，分别加值

**初始化**：
1. 对每个位置执行 `add`，$O(n \log n)$
2. 遍历节点，扫描其子/父节点进行累加，$O(n)$

## 拓展应用

#### 一、求逆序对

- 利用 $t[val]$ 统计 $val$ 的出现次数，则 $t[z]$ 表示集合中在 $[z, n]$ 范围内的数。
- 利用树状数组维护，倒序扫描 $a$，查询 $[1, a[i]-1]$，即在 $a[i]$ 后且 $< a[i]$ 的数，累加。将 $t[a[i]]$ 加一。
- 时间复杂度 $O((n+m) \log n)$。

#### 二、区间增加/单点查询

利用差分数组，维护差分数组前缀和（即原数组）。

- **区间增加**：`add(l, d)`, `add(r+1, -d)`

- **单点查询**：`query(1, x)`

- **代码模板**：

#define lowbit(x) (x & -x)
using namespace std;
const int N = 5E5 + 10;
int n, m;
int a[N], tr[N], d[N];
void add(int x, int v) {
    for (; x <= n; x += lowbit(x)) 
        tr[x] += v;
}
int query(int x) {
    int ans = 0;
    for (; x >= 1; x -= lowbit(x))
        ans += tr[x];
    return ans;    
}
int main() {
    cin.tie(0) -> sync_with_stdio(0);
    n = read(), m = read();
    for (int i = 1; i <= n; i ++)
    {
        a[i] = read(), d[i] = a[i] - a[i - 1];
        tr[i] += d[i];
        if (i + lowbit(i) <= n)
            tr[i + lowbit(i)] += tr[i];
    }
    while (m --) {
        int o = read();
        if (o == 1) {
            int x = read(), y = read(), k = read();
            add(x, k), add(y + 1, -k);
        }
        else {
            int x = read();
            write(query(x)), putchar('\n');
        }
    }    
    return 0;
}

#### 三、区间增加/区间查询

- **区间增加**：类比上述思路

- **区间查询**：即求 $\sum_{i=1}^{x} b[i]$

	- 变形，得 $\sum_{i=1}^{x} \sum_{j=1}^{i} b[j] = \sum_{j=1}^{x} b[j] \times (x - j + 1)$

	- 即 $(x+1) \sum_{j=1}^{x} b[j] - \sum_{j=1}^{x} j \cdot b[j]$

	- 建立两个树状数组，维护 $b[i]$ 和 $i \cdot b[i]$ 的前缀和。

	- 则 $\text{range}(x) = \text{query}_1(x) \times (x+1) - \text{query}_2(x)$

	- $[l, r]$ 的区间和 $= \text{range}(r) - \text{range}(l-1)$
	
- **代码模板**：

#define int long long
#define lowbit(x) (x & -x)
using namespace std;
const int N = 5E5 + 10;
int n, m;
int a[N], tr[2][N], d[N];
void add(int k, int x, int v) {
    for (; x <= n; x += lowbit(x)) 
        tr[k][x] += v;
}
int query(int k, int x) {
    int ans = 0;
    for (; x >= 1; x -= lowbit(x))
        ans += tr[k][x];
    return ans;    
}
int rquery(int x) {
    return (x + 1) * query(0, x) - query(1, x);
}
signed main() {
    cin.tie(0) -> sync_with_stdio(0);
    n = read(), m = read();
    for (int i = 1; i <= n; i ++) {
        a[i] = read(), d[i] = a[i] - a[i - 1];
        tr[0][i] += d[i]; 
        tr[1][i] += i * d[i];
        if (i + lowbit(i) <= n) {
             tr[0][i + lowbit(i)] += tr[0][i];
             tr[1][i + lowbit(i)] += tr[1][i];
        }
    }
    while (m --) {
        int o = read();
        if (o == 1) {
            int x = read(), y = read(), k = read();
            add(0, x, k), add(0, y + 1, -k);
            add(1, x, k * x), add(1, y + 1, (-k) * (y + 1));
        }
        else {
            int x = read(), y = read();
            write(rquery(y) - rquery(x - 1)), putchar('\n');
        }
    }    
    return 0;
}
