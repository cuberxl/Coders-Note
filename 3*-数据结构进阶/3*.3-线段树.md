#### 线段树

- **定义**：基于分治思想的二叉树结构，用于区间信息统计。

- **性质**：
  1. 每个节点代表一个区间 $[L, R]$。
  2. 根节点为整个区间 $[1, n]$。
  3. 叶节点代表一个长度为 1 的区间，即 $[x, x]$。
  4. 对于每个内部节点 $[L, R]$，其左儿子为 $[L, \text{mid}]$，右儿子为 $[\text{mid}+1, R]$，其中 $\text{mid} = \lfloor (L+R)/2 \rfloor$。

- **存储**：线段树为一棵完全二叉树 ( 除最底层外 )，树深为 $O(\log n)$，故可用一维数组存储。
  - 若叶子节点为 $n$，则最后一层有 $2n$ 个节点，加上倒数第二层，总结点数不超过 $4n$。因此数组大小开 $4n$ 即可。

- **基本操作**：
  - **`build` 函数 ( 建立线段树 )**：
    - 更新边界：$L = R$ ( 叶节点 )，则初始化条件后返回。
    - 递归建立左儿子、右儿子。
  - **`change` 函数 ( 单点修改 )**：
    - 递归边界：同上。
    - 递归：若 $x$ 在左儿子内，递归左儿子，反之递归右儿子。
    - 回溯：更新当前节点信息。
  - **`query` 函数 ( 区间查询 )**：
    - 递归边界：若该节点完全包含于 $[L, R]$，返回。
    - 若左子节点有重叠，递归左子节点；若右子节点有重叠，递归右子节点。

- **扩展应用 ( 区间修改 + 延迟标记 )**：
  - 在区间修改中，若某节点被完全覆盖，逐一更新其子节点过于耗时。为 $O(n)$，注意到：若该节点的子节点后续不会被访问，则修改是无效的。
  - 我们可以在执行修改后立即返回，向该节点增加一个标记 `lazy`，表示该节点曾被修改，但其子节点未更新。
  - 在后续指令中，若从节点向下递归时，若其有标记，更新其子节点，并为其子节点添加标记，同时删除自身标记。
  - 至此，区间修改优化为 $O(\log n)$。

- **代码模板 ( 区间修改 + 区间查询 )**：

```cpp
#define int long long
using namespace std;
const int N = 5e5 + 10;
int n, m;
int a[N];

struct Sgt {
    int l, r;
    int sum;
    int lazy;
} tr[N * 4];

void pushup(int u) {
     int ls = u * 2, rs = u * 2 + 1;
     tr[u].sum = tr[ls].sum + tr[rs].sum;
}

void update(int u, int v) {
    tr[u].sum += v * (tr[u].r - tr[u].l + 1);
    tr[u].lazy += v;
}

void pushdown(int u) {
    if (tr[u].lazy == 0) return;
    int v = tr[u].lazy; tr[u].lazy = 0;
    update(u * 2, v); update(u * 2 + 1, v);
}

void build(int u, int l, int r) {
    tr[u].l = l, tr[u].r = r;
    if (l == r) {
        tr[u].sum = a[l];
        return;
    }
    int mid = (l + r) >> 1;
    build(u * 2, l, mid);
    build(u * 2 + 1, mid + 1, r);
    pushup(u);
}

void modify(int u, int l, int r, int v) {
    if (l <= tr[u].l && tr[u].r <= r) {
        update(u, v);
        return;
    }
    pushdown(u);
    int mid = (tr[u].l + tr[u].r) >> 1;
    if (l <= mid) modify(u * 2, l, r, v);
    if (r > mid) modify(u * 2 + 1, l, r, v);
    pushup(u);
}

int query(int u, int l, int r) {
    if (l <= tr[u].l && tr[u].r <= r) {
        return tr[u].sum;
    }
    pushdown(u);
    int mid = (tr[u].l + tr[u].r) >> 1;
    int ans = 0;
    if (l <= mid) ans += query(u * 2, l, r);
    if (r > mid) ans += query(u * 2 + 1, l, r);
    return ans;
}

signed main() {
    n = read(), m = read();
    for (int i = 1; i <= n; i ++)
        a[i] = read();
    build(1, 1, n);
    while (m --) {
        int o = read();
        if (o == 1) {
            int x = read(), y = read(), k = read();
            modify(1, x, y, k);
        }
        else {
            int x = read(), y = read();
            write(query(1, x, y)), putchar('\n');
        }
    }    
    return 0;
}
```
