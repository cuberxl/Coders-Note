<h4 id="单调栈"><span class="prefix"></span><span class="content">单调栈</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定一个数列，输出每个数左边第一个比它小的数，不存在则输出 -1。</p>
<p><strong>暴力解法</strong>：两重循环，枚举每个数并向前遍历，O(n²)。</p>
<p><strong>优化思路</strong>：维护一个栈，当 a[i] &gt; a[j] 且 i &gt; j 时，a[j] 永远不可能成为后面元素的答案（因为 a[i] 更小且更靠后），可以直接弹出。</p>
<p><strong>算法</strong>：</p>
<ul>
<li>遍历每个数 x</li>
<li>当栈顶元素 ≥ x 时，不断弹出栈顶</li>
<li>若栈为空，输出 -1；否则输出栈顶元素</li>
<li>将 x 入栈</li>
</ul>
<p><strong>时间复杂度</strong>：O(n)</p>

<h4 id="单调队列（滑动窗口最值）"><span class="prefix"></span><span class="content">单调队列（滑动窗口最值）</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定一个数列，有一个大小为 k 的滑动窗口从左到右滑动，求每个窗口中的最大值。</p>
<p><strong>暴力解法</strong>：枚举每个窗口并遍历其中元素，O(nk)。</p>
<p><strong>优化思路</strong>：</p>
<ul>
<li>维护一个队列，存储元素下标</li>
<li>当 a[i] ≥ a[j] 且 i &gt; j 时，a[j] 永远不可能成为后续窗口的最大值（因为 a[i] 更大且更晚过期）</li>
<li>同时剔除超出窗口范围的下标</li>
</ul>
