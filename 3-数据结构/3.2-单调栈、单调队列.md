### 单调栈与单调队列
---
#### 单调栈

**问题**：给定一个数列，输出每个数左边第一个比它小的数，不存在则输出 -1。

**暴力解法**：两重循环，枚举每个数并向前遍历，O(n²)。

**优化思路**：维护一个栈，当 a[i] > a[j] 且 i > j 时，a[j] 永远不可能成为后面元素的答案（因为 a[i] 更小且更靠后），可以直接弹出。

**算法**：
- 遍历每个数 x
- 当栈顶元素 ≥ x 时，不断弹出栈顶
- 若栈为空，输出 -1；否则输出栈顶元素
- 将 x 入栈

**时间复杂度**：O(n)

```cpp
for (int i = 0; i < n; i++) {
    while (!st.empty() && st.top() >= a[i]) st.pop();
    cout << (st.empty() ? -1 : st.top()) << " ";
    st.push(a[i]);
}
```


#### 单调队列（滑动窗口最值）

**问题**：给定一个数列，有一个大小为 k 的滑动窗口从左到右滑动，求每个窗口中的最大值。

**暴力解法**：枚举每个窗口并遍历其中元素，O(nk)。

**优化思路**：
- 维护一个队列，存储元素下标
- 当 a[i] ≥ a[j] 且 i > j 时，a[j] 永远不可能成为后续窗口的最大值（因为 a[i] 更大且更晚过期）
- 同时剔除超出窗口范围的下标

**时间复杂度**：O(n)

```cpp
// 滑动窗口最大值
deque<int> q;
for (int i = 0; i < n; i++) {
    // 剔除超出窗口范围的下标
    if (!q.empty() && q.front() < i - k + 1) q.pop_front();
    // 维护单调递减队列
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k - 1) cout << a[q.front()] << " ";
}
```
