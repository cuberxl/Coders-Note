### KMP 模式匹配
---
**问题**：给定文本串 S 和模式串 P，求 P 在 S 中所有出现位置的起始下标。

**核心思想**：匹配失败时，利用已匹配信息，将模式串向右移动尽可能远的距离，避免从头匹配。

**next 数组定义**：

$ne[i]$ 表示 $P[0..i-1]$ 中 最长相等前后缀的长度。

**next 数组计算方法**：
- 引理：
	- 定义：当计算 $ne[i]$

**匹配过程**：

```cpp
for (int i = 1, j = 0; i <= n; i++) {
    while (j && s[i] != p[j + 1]) j = ne[j];
    if (s[i] == p[j + 1]) j++;
    if (j == m) {
        // 匹配成功，起始位置为 i - m + 1
        cout << i - m + 1 << " ";
        j = ne[j];  // 继续匹配下一个
    }
}
```
