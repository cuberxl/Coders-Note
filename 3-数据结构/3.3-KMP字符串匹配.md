<h3 id="kmp-字符串匹配"><span class="prefix"></span><span class="content">KMP 字符串匹配</span><span class="suffix"></span></h3>
<hr>
<p><strong>问题</strong>：给定文本串 S 和模式串 P，求 P 在 S 中所有出现位置的起始下标。</p>
<p><strong>核心思想</strong>：匹配失败时，利用已匹配信息，将模式串向右移动尽可能远的距离，避免从头匹配。</p>
<p><strong>next 数组定义</strong>：next[i] 表示 P[0…i-1] 中<strong>最长相等前后缀的长度</strong>。</p>
