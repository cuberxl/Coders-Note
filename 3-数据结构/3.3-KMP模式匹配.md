### KMP 模式匹配
---
**问题**：给定文本串 $s$ 和模式串 $p$，求 $p$ 在 $s$ 中所有出现位置的起始下标。

**核心思想**：匹配失败时，利用已匹配信息，将模式串向右移动尽可能远的距离，避免从头匹配。

**next 数组定义**：
- 以下定义使用 $1-based$ 索引。
- $ne[i]$ 表示 $p[1\sim i]$ 中，最长公共前后缀的长度。
- $f[i]$ 表示 $s[1\sim i]$ 中，与 $p$ 的前缀匹配的最大长度。

**next 数组计算方法**：
- 引理：
	- 定义：当计算 $ne[i]$ 时，若 $j < i\ \land\ p[1 \sim j] = p[i-j+1\sim i]$ ，即 $j$ 是 $p[1 \sim i]$ 的一个公共前后缀，则称其为 $ne[i]$ 的一个候选项.
	- 引理：若 $j_0$ 为 $ne[i]$ 的一个候选项，则小于 $j_0$ 的最大候选项为 $ne[j_0]$.
	- 证明：反证法.
假设存在  $j_1$，满足 $ne[j_0] < j_1 < j_0$，使得 $p[1 \sim j_1] = p[i - j_1 + 1 \sim i](1)$.
由于 $p[1 \sim j_0] = p[i - j_0 + 1 \sim i]$，取其后 $j_1$ 个字符，显然相等.
故 $p[j_0 - j_1 + 1 \sim j_0] = p[i - j_1 + 1 \sim i](2)$.
由$(1)(2)$ 得，$p[1 \sim j_1] = p[j_0 - j_1 + 1 \sim j_0]$，即 $j_1$  为 $j_0$ 的一个比 $ne[i]$ 更大的候选项。
这与假设矛盾，故引理成立。
- 故由引理可知，在计算 $ne[i]$时：
	- $j$ 是 $ne[i]$ 的候选项的必要条件是 $j - 1$ 是 $ne[i - 1]$ 的候选项。
	- 故，只需把 $ne[i - 1] + 1$，$ne[ne[i - 1]] + 1$，$\cdots$作为 $ne[i]$ 的可能取值即可。
