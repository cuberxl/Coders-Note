<h4 id="二进制-trie-求最大异或对"><span class="prefix"></span><span class="content">二进制 Trie 求最大异或对</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：在 N 个整数中选出两个数进行异或运算，求最大结果。</p>
<p><strong>暴力</strong>：枚举所有数对，O(n²)。</p>
<p><strong>优化</strong>：将所有数以二进制形式（31位）插入 Trie 树。</p>
<p>对每个数 x，从高位到低位遍历：</p>
<ul>
<li>若存在与 x 当前位相反的节点（0 找 1，1 找 0），则走向该节点，该位异或结果为 1</li>
<li>若不存在，则走向相同节点，该位异或结果为 0</li>
</ul>
<p><strong>时间复杂度</strong>：O(n log V)，V 为值域。</p>
