### 并查集
---
**功能**：
1. 将两个集合合并
2. 查询两个元素是否属于同一集合

**基本原理**：
- 用一棵树表示一个集合，树根为集合编号
- 每个节点存储其父节点 p[x]
- 判断根：p[x] == x，则 x 为根

**核心操作**：

```cpp
// 初始化
for (int i = 1; i <= n; i++) p[i] = i;

// 查找（路径压缩）
int find(int x) {
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

// 合并
void merge(int a, int b) {
    p[find(a)] = find(b);
}

// 查询
if (find(a) == find(b)) {
    // 在同一集合中
}
```

**路径压缩**：查询时将路径上所有节点直接指向根节点，降低树高，后续查询接近 O(1)。

**优化后时间复杂度**：近乎 O(1)（均摊）
