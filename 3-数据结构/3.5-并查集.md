<h3 id="并查集"><span class="prefix"></span><span class="content">并查集</span><span class="suffix"></span></h3>
<p><strong>功能</strong>：</p>
<ol>
<li>将两个集合合并</li>
<li>查询两个元素是否属于同一集合</li>
</ol>
<p><strong>基本原理</strong>：</p>
<ul>
<li>用一棵树表示一个集合，树根为集合编号</li>
<li>每个节点存储其父节点 p[x]</li>
<li>判断根：p[x] == x，则 x 为根</li>
</ul>
<p><strong>核心操作</strong>：</p>

<p><strong>路径压缩</strong>：查询时将路径上所有节点直接指向根节点，降低树高，后续查询接近 O(1)。</p>
<p><strong>优化后时间复杂度</strong>：近乎 O(1)（均摊）</p>
