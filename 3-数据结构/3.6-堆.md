<h3 id="堆"><span class="prefix"></span><span class="content">堆</span><span class="suffix"></span></h3>
<hr>
<ul>
<li>
<p><strong>概念</strong>：堆是一种能维护集合最值的数据结构。</p>
</li>
<li>
<p><strong>基本结构</strong>：一棵完全二叉树，除了最后一层，其他层都是满的，最后一层节点从左到右排列。</p>
</li>
<li>
<p><strong>性质</strong>：</p>
<ul>
<li>小根堆：父节点的值 &lt;= 子节点的值</li>
<li>大根堆：父节点的值 &gt;= 子节点的值</li>
<li>根节点是堆中最小（或最大）的元素。</li>
</ul>
</li>
<li>
<p><strong>存储方式（堆状结构）</strong>：设父节点编号为 x，则左子节点为 2x，右子节点为 2x + 1。</p>
<ul>
<li>注：利用一维数组可以方便地存储堆。</li>
</ul>
</li>
<li>
<p><strong>基本操作</strong>：向下调整 <code>down(x)</code>，向上调整 <code>up(x)</code></p>
</li>
<li>
<p><strong>down(x) 示例</strong>：<br>
① 小根堆 ② 修改一个元素 ③ 与左儿子、右儿子中较小的元素交换 ④ 重复直到左儿子、右儿子均大于等于根节点（即满足堆的性质）</p>
</li>
<li>
<p><strong>up(x) 示例</strong>：<br>
① 小根堆 ② 修改一个元素 ③ 与父节点比较，如果小于父节点则交换 ④ 重复直到父节点小于等于当前节点</p>
</li>
<li>
<p><strong>使用基本操作实现其他操作</strong>：</p>
<ul>
<li>① 插入 x: <code>heap[++size] = x; up(size);</code></li>
<li>② 求最小值：<code>heap[1];</code></li>
<li>③ 删除最小值：<code>heap[1] = heap[size]; size--; down(1);</code></li>
</ul>
<ul>
<li>④ 删除任意元素 k: <code>heap[k] = heap[size]; size--; up(k); down(k);</code></li>
<li>⑤ 修改任意元素 k 为 x: <code>heap[k] = x; up(k); down(k);</code></li>
</ul>
</li>
<li>
<p><strong>堆排序 (heap sort)</strong>：</p>
<ul>
<li>建堆思路：将数组建堆，不断输出堆顶。</li>
<li>建堆：从数组中间开始（size/2），将每个元素 down 一遍。</li>
</ul>
</li>
<li>
<p><strong>时间复杂度分析</strong>：建堆的时间复杂度为 <code>O(n)</code></p>
<ul>
<li>S = n/4 * 1 + n/8 * 2 + n/16 * 3 + …</li>
<li>2S = n/2 * 1 + n/4 * 2 + n/8 * 3 + …</li>
<li>两式相减得：S = n/2 + n/4 + n/8 + …</li>
<li>由等比数列求和公式可知 S &lt; n，因此建堆的复杂度为 <code>O(n)</code>。</li>
</ul>
</li>
<li>
<p><strong>维护第 k 个插入的数</strong>：</p>
<ul>
<li>定义两个数组：<code>ph[k]</code>, <code>hp[k]</code></li>
<li><code>ph[k]</code> 表示第 k 个插入的数在堆中的下标，<code>hp[k]</code> 表示堆中下标为 k 的数是第几个插入的。</li>
</ul>
