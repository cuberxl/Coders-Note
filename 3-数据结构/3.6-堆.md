### 堆
---
- **概念**：堆是一种能维护集合最值的数据结构。

- **基本结构**：一棵完全二叉树，除了最后一层，其他层都是满的，最后一层节点从左到右排列。

- **性质**：
    - 小根堆：父节点的值 <= 子节点的值
    - 大根堆：父节点的值 >= 子节点的值
    - 根节点是堆中最小（或最大）的元素。

- **存储方式（堆状结构）**：设父节点编号为 x，则左子节点为 2x，右子节点为 2x + 1。
    - 注：利用一维数组可以方便地存储堆。

- **基本操作**：向下调整 `down(x)`，向上调整 `up(x)`

- **down(x) 示例**：
    ① 小根堆 ② 修改一个元素 ③ 与左儿子、右儿子中较小的元素交换 ④ 重复直到左儿子、右儿子均大于等于根节点（即满足堆的性质）

- **up(x) 示例**：
    ① 小根堆 ② 修改一个元素 ③ 与父节点比较，如果小于父节点则交换 ④ 重复直到父节点小于等于当前节点

- **使用基本操作实现其他操作**：
    - ① 插入 x: `heap[++size] = x; up(size);`
    - ② 求最小值：`heap[1];`
    - ③ 删除最小值：`heap[1] = heap[size]; size--; down(1);`
	* ④ 删除任意元素 k: `heap[k] = heap[size]; size--; up(k); down(k);`
	* ⑤ 修改任意元素 k 为 x: `heap[k] = x; up(k); down(k);`

- **堆排序 (heap sort)**：
    - 建堆思路：将数组建堆，不断输出堆顶。
    - 建堆：从数组中间开始（size/2），将每个元素 down 一遍。

- **时间复杂度分析**：建堆的时间复杂度为 `O(n)`
    - S = n/4 * 1 + n/8 * 2 + n/16 * 3 + ...
    - 2S = n/2 * 1 + n/4 * 2 + n/8 * 3 + ...
    - 两式相减得：S = n/2 + n/4 + n/8 + ...
    - 由等比数列求和公式可知 S < n，因此建堆的复杂度为 `O(n)`。

- **维护第 k 个插入的数**：
    - 定义两个数组：`ph[k]`, `hp[k]`
    - `ph[k]` 表示第 k 个插入的数在堆中的下标，`hp[k]` 表示堆中下标为 k 的数是第几个插入的。

  ```cpp
    void heap_swap(int a, int b) { // 交换堆中下标为 a 和 b 的两个数
        swap(ph[hp[a]], ph[hp[b]]); // 交换两个数的插入顺序下标
        swap(hp[a], hp[b]); // 交换两个数的堆中下标
        swap(heap[a], heap[b]); // 交换两个数的值
    }    ```
