<h3 id="字符串哈希"><span class="prefix"></span><span class="content">字符串哈希</span><span class="suffix"></span></h3>
<ul>
<li>
<p>字符串哈希方式：一般使用字符串前缀哈希法。</p>
</li>
<li>
<p><code>h[i]</code> 表示前 i 个字符的哈希值。</p>
</li>
<li>
<p><strong>哈希值计算方法</strong>：① 将字符串看作一个 P 进制数（通常 P 取 131 或 13331）</p>
<ul>
<li>② 将 P 进制数转换为十进制数并对 Q 取模。</li>
</ul>
</li>
<li>
<p>例：<code>s = "ABCD" = {1, 2, 3, 4}</code> (将字符转为数字)</p>
<ul>
<li><code>h[1] = 1 * P^3 + 2 * P^2 + 3 * P^1 + 4 * P^0</code></li>
</ul>
</li>
<li>
<p><strong>注意</strong>：① 不能映射为 0（避免冲突）</p>
<ul>
<li>② 假设不存在冲突（P 取 131 或 13331，Q = 2^64 自然溢出）</li>
</ul>
</li>
<li>
<p>P 取 131 或 13331。</p>
</li>
<li>
<p>Q 取 2^64，使用 <code>unsigned long long</code> 自然溢出（相当于自动取模）。</p>
</li>
<li>
<p><strong>字符串前缀哈希公式</strong>：<code>h[i] = h[i-1] * P + s[i]</code></p>
</li>
<li>
<p>例：<code>s = "ABCDEF"</code></p>
<ul>
<li><code>h[1] = s[0]</code></li>
<li><code>h[2] = h[1] * P + s[1]</code></li>
<li>…</li>
<li><code>h[6] = s[0]*P^5 + s[1]*P^4 + ... + s[5]</code></li>
</ul>
</li>
<li>
<p><strong>查询子串 [l, r] 的哈希值</strong>：</p>
<ul>
<li>公式：<code>h[r] - h[l-1] * p[r-l+1]</code></li>
<li>证明：
<ul>
<li>① h[r] = 从第 1 位到第 r 位的哈希值 = h[l-1] * P^(r-l+1) + 子串 [l, r] 的哈希值</li>
<li>② h[l-1] = 前 l-1 位的哈希值</li>
<li>③ 所以 h[l-1] * P^(r-l+1) 就是前 l-1 位左移 r-l+1 位。</li>
<li>④ h[r] - h[l-1] * P^(r-l+1) 就是子串 [l, r] 的哈希值。</li>
</ul>
</li>
</ul>
</li>
<li>
<p><strong>应用</strong>：可快速判断字符串是否相等。</p>
</li>
<li>
<p><strong>双哈希</strong>：取 P1=131, P2=13331 计算两个哈希值，只有当两个哈希值都相等时才认为字符串相等，可进一步减少冲突。</p>
</li>
</ul>
