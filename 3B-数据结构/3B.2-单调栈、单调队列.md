#### 单调栈

**问题**：给定一个数列，输出每个数左边第一个比它小的数，不存在则输出 $-1$。

**暴力解法**：两重循环，枚举每个数并向前遍历，时间复杂度 $O(n^2)$。

**优化思路**：维护一个栈，当 $a[i] > a[j]$ 且 $i > j$ 时，$a[j]$ 永远不可能成为后面元素的答案 ( 因为 $a[i]$ 更小且更靠后 ) ，可以直接弹出。

**算法流程**：

1. 遍历每个数 $x$。
2. 当栈顶元素 $\geq x$ 时，不断弹出栈顶。
3. 若栈为空，输出 $-1$；否则输出栈顶元素。
4. 将 $x$ 入栈。

**时间复杂度**：$O(n)$。

```cpp
for (int i = 0; i < n; i++) {
    while (!stk.empty() && stk.top() >= a[i]) stk.pop();
    cout << (stk.empty() ? -1 : stk.top()) << " ";
    stk.push(a[i]);
}
```

#### 单调队列

**问题**：给定一个数列，有一个大小为 $k$ 的滑动窗口从左到右滑动，求每个窗口中的最大值。

**暴力解法**：枚举每个窗口并遍历其中元素，时间复杂度 $O(nk)$。

**优化思路**：

1. 维护一个队列，存储元素下标。
2. 当 $a[i] \geq a[j]$ 且 $i > j$ 时，$a[j]$ 永远不可能成为后续窗口的最大值 ( 因为 $a[i]$ 更大且更早过期 ) 。
3. 同时剔除超出窗口范围的下标。

**时间复杂度**：$O(n)$。

**说明**：滑动窗口最大值。每轮先剔除超出窗口范围的下标，再维护单调递减队列，队头即为当前窗口最大值。

```cpp
deque<int> q;
for (int i = 0; i < n; i++) {
    if (!q.empty() && q.front() < i - k + 1) q.pop_front();
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k - 1) cout << a[q.front()] << " ";
}
```
