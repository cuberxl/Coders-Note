#### 基本概念
- 中缀表达式：人类惯于使用的书写形式，运算符在操作数中间，利用括号确定优先级。例如 `(3 + 4) * 5 - 6` 。
- 后缀表达式（逆波兰式）：利于使用计算机计算的写法，两个操作数在前，操作符在后，不需要括号。上面的式子转成后缀为 `3 4 + 5 * 6 -`。

#### 后缀表达式求值
- 策略：维护一个操作数栈，依次遍历表达式：
  - 若遍历到操作数，将其直接压入栈中。
  - 若遍历到操作符，弹出栈中的两个元素，进行运算后，将结果压入栈中。
- 代码模板：
```cpp
int eval(int a, int b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;
    return 0;
}

int main() {
    string s;
    getline(cin, s); // 读入如 "3 4 + 5 * 6 -"
    stringstream ss(s);
    string token;
    stack<int> stk;
    
    while (ss >> token) {
        // 如果是数字（处理多位数和可能出现的负数）
        if (token.size() > 1 || isdigit(token[0])) {
            stk.push(stoi(token));
        } else {
            // 注意：先弹出的是右操作数
            int b = stk.top(); stk.pop();
            int a = stk.top(); stk.pop();
            stk.push(eval(a, b, token[0]));
        }
    }
    cout << stk.top() << '\n'; // 栈顶即最终结果
    return 0;
}
```

#### 中缀表达式求值/调度场算法

- 策略：维护一个操作数栈 $num$，一个操作符栈 $op$。
  - 遍历整个中缀表达式。
  - 定义函数 `eval()` ：每次取出两个操作数和一个操作符进行运算，再将结果压回。*(注意：先弹出的是右操作数，后弹出的是左操作数)*。
  - 1. 遇到数字：直接将其压入操作数栈。
  - 2. 遇到左括号 `(`：直接将其压入操作符栈。
  - 3. 遇到右括号 `)`：不断从栈中弹出元素进行 `eval()` 运算，直到遇到左括号 `(`（弹出左括号但不运算）。
  - 4. 遇到运算符（`+ - * /`）：
    - 只要操作符栈不为空，且栈顶不是左括号，且栈顶运算符的优先级**大于或等于**当前运算符，就不断弹出栈顶操作符并执行 `eval()` 运算。
    - 循环结束后，把当前运算符压入操作符栈。
  - 当表达式遍历完毕时，若操作符栈中还有元素，则继续进行 `eval()` 运算直到操作符栈为空。此时操作数栈只剩下一个元素，即为该表达式的值。
- 部分正确性证明：
  - 括号的隔离与优先计算：
    - 左括号入栈后，直到遇到右括号之前的所有运算符，都会被“封锁”在左括号之上。遇到右括号时，括号内的运算符优先级已经处理完毕，依次弹出并执行 `eval()`，这保证了括号内的运算作为一个独立的整体被优先求值。
  - 低优先级运算符入栈等待：
    - 当遇到高优先级运算符时，由于它的运算次序必须在低优先级运算符之前，因此将其压入栈中暂存，等待其右侧的操作数。
    - 例如在 `3 + 4 * 5` 中，遇到 `*` 时，`+` 被压在栈底，`*` 优先入栈并等待，从而保证了 `4 * 5` 先被计算。
  - 为什么要求栈顶优先级 $geq$当前运算符：
    - 1. 关于 $>$（高优先级优先）：栈顶若为高优先级运算符，说明其左右操作数已就绪，必须立刻计算。若当前遇到低优先级运算符，不仅不能打断高优先级的结算，还要等它算完把结果压回操作数栈后，再处理当前运算符。
    - 2. 关于 $=$（左结合律）：算术运算符 `+ - * /` 均满足**左结合性**（从左往右计算）。当遇到同级运算符时，先出现的（即栈顶元素）必须先执行，故此时使用 `>=` 弹出计算，契合了数学运算中从左到右的顺序。
  - 收尾处理的正确性：
	  - 当表达式遍历完毕后，操作符栈中剩余的元素代表了整个表达式树中**最外层、优先级最低**的运算。
	  - 此时，操作数栈中已经准备好了这些运算符所需的操作数。不断从操作符栈顶弹出元素并执行 `eval()`，本质上是从最内层向最外层还原表达式树，直到操作符栈为空。
	  - 最终，操作数栈中剩下的唯一元素就是整个中缀表达式的计算结果。
	  
-  代码模板：
```cpp
using namespace std;

stack<int> num;
stack<char> op;

int pr(char c) {
    if (c == '+' || c == '-') return 1;
    if (c == '*' || c == '/') return 2;
    return 0; 
}

void eval() {
    int b = num.top(); num.pop();
    int a = num.top(); num.pop();
    char c = op.top(); op.pop();
    if (c == '+') num.push(a + b);
    if (c == '-') num.push(a - b);
    if (c == '*') num.push(a * b);
    if (c == '/') num.push(a / b);
}

int main() {
    string s;
    cin >> s;
    for (int i = 0; i < s.size(); i++) {
        if (isdigit(s[i])) {
            int x = 0, j = i;
            while (j < s.size() && isdigit(s[j])) x = x * 10 + s[j++] - '0';
            num.push(x); i = j - 1;
        }
        else if (s[i] == '(') op.push(s[i]);
        else if (s[i] == ')') {
            while (op.top() != '(') eval();
            op.pop();
        }
        else {
            while (op.size() && op.top() != '(' && pr(op.top()) >= pr(s[i])) eval();
            op.push(s[i]);
        }
    }
    while (op.size()) eval();
    cout << num.top();
    return 0;
}
```
