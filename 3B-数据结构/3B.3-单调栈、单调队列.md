#### $\S$ 单调栈

**问题**：给定一个数列，输出每个数左边第一个比它小的数，不存在则输出 $-1$。

**暴力解法**：两重循环，枚举每个数并向前遍历，时间复杂度 $O(n^2)$。

**优化思路**：维护一个栈，当 $a[i] > a[j]$ 且 $i > j$ 时，$a[j]$ 永远不可能成为后面元素的答案 ( 因为 $a[i]$ 更小且更靠后 )，可以直接弹出。

**算法流程**：

1. 遍历每个数 $x$。
2. 当栈顶元素 $\geq x$ 时，不断弹出栈顶。
3. 若栈为空，输出 $-1$；否则输出栈顶元素。
4. 将 $x$ 入栈。

**时间复杂度**：$O(n)$。

```cpp
for (int i = 0; i < n; i++) {
    while (!stk.empty() && stk.top() >= a[i]) stk.pop();
    cout << (stk.empty() ? -1 : stk.top()) << " ";
    stk.push(a[i]);
}
```

#### $\S$ 单调队列

**问题**：给定一个数列，有一个大小为 $k$ 的滑动窗口从左到右滑动，求每个窗口中的最大值。

**暴力解法**：枚举每个窗口并遍历其中元素，时间复杂度 $O(nk)$。

**优化思路**：

1. 维护一个队列，存储元素下标。
2. 当 $a[i] \geq a[j]$ 且 $i > j$ 时，$a[j]$ 永远不可能成为后续窗口的最大值 ( 因为 $a[i]$ 更大且更早过期 )。
3. 同时剔除超出窗口范围的下标。

**时间复杂度**：$O(n)$。

**说明**：滑动窗口最大值。每轮先剔除超出窗口范围的下标，再维护单调递减队列，队头即为当前窗口最大值。

```cpp
deque<int> q;
for (int i = 0; i < n; i++) {
    if (!q.empty() && q.front() < i - k + 1) q.pop_front();
    while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k - 1) cout << a[q.front()] << " ";
}
```

#### $\S$ 长度上限的最大子段和

**问题**：给定一个长度为 $n$ 的数组，求长度不超过 $l$ 的连续子段的最大和。

**策略**：

- 求前缀和数组 $s[]$。
- 长度区间 $[i, j]$ 的和等于 $s[j] - s[i - 1]$，且区间长度限制为 $j - i + 1 \leq l$。
- 暴力做法：枚举左右端点 $i, j$，时间复杂度 $O(ln)$。

**优化（单调队列）**：

- 枚举所有右端点 $j$，此时合法的左端点前一位 $i - 1$ 的范围是 $[j - l, j - 1]$。
- 此时 $s[j]$ 为定值，我们只需要在这个窗口内找到 $s[i - 1]$ 的**最小值**即可。
- 定义一个滑动窗口，在 $s[]$ 上维护 $s[i-1]$ 的最小值（单调递增队列）。
- 将 $s[j] - s[dq.front()]$ 作为答案的候选项，最大值即为答案。
- 时间复杂度：$O(n)$。

**代码模板**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 10;
int n, l;
long long a[N], s[N];
deque<int> dq;

int main() {
    cin >> n >> l;
    for (int i = 1; i <= n; i ++) {
        cin >> a[i];
        s[i] = s[i - 1] + a[i];
    }
    
    long long ans = -1e18;
    dq.push_back(0);
    
    for (int i = 1; i <= n; i ++) {
        while (dq.size() && dq.front() < i - l)
            dq.pop_front();
            
        if (dq.size())
            ans = max(ans, s[i] - s[dq.front()]);
            
        while (dq.size() && s[dq.back()] >= s[i])
            dq.pop_back();
        dq.push_back(i);
    }
    
    cout << ans << '\n';
    return 0;
}
```

#### $\S$ 长度上限的最大子段和

**问题**：给定一个长度为 $n$ 的数组，求长度 $\in [l, r]$ 的连续子段的最大和。

**策略**：
- 仿照刚才的思路，维护一个滑动窗口，维护合法的 $s[i - 1]$ 的最小值。 
- 设当前右端点为 $j$，则合法的左端点下标范围为 $i \in [i - r + 1, i - l + 1]$，即 $i - 1 \in [i - r, i - l]$。
- 当右端点大于 $l$ 时，入队 $i - l$，弹出所有 $< i - r$ 的下标。
- 将 $s[j] - s[dq.front()]$ 作为答案的候选项，最大值即为答案。
- 时间复杂度：$O(n)$。

**代码模板**：
```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e5 + 10;
int n, x, y;
long long a[N], s[N];
deque<int> dq;

int main() {
    cin >> n >> x >> y;
    for (int i = 1; i <= n; i ++) {
        cin >> a[i];
        s[i] = s[i - 1] + a[i];
    }
    
    long long ans = -1e18;
    dq.push_back(0);
    
    for (int i = 1; i <= n; i ++) {
        while (dq.size() && dq.front() < i - y)
            dq.pop_front();
            
        if (i >= x) {
            int l = i - x;
            while (dq.size() && s[dq.back()] >= s[l])
                dq.pop_back();
            dq.push_back(l);
        }
            
        if (dq.size())
            ans = max(ans, s[i] - s[dq.front()]);
    }
    
    cout << ans << '\n';
    return 0;
}

```
