#### 并查集

**功能**：

- 将两个集合合并。
- 查询两个元素是否属于同一集合。

**基本原理**：

- 用一棵树表示一个集合，树根为集合编号。
- 每个节点存储其父节点 $p[x]$。
- 判断根：$p[x] = x$，则 $x$ 为根。

---

#### 核心操作

**说明**：`find(x)` 查找元素所在集合，`merge(a, b)` 合并两个元素所在的集合；`main` 中把每个元素初始化为独立集合。

```cpp
int find(int x) {
    if (p[x] != x)
        p[x] = find(p[x]);
    return p[x];
}

void merge(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra != rb) p[ra] = rb;
}

int main() {
    for (int i = 1; i <= n; i++)
        p[i] = i;
    return 0;
}
```

---

#### 优化

**路径压缩**：查询时将路径上所有节点直接指向根节点，降低树高。

**按秩合并**：固定将高度小的树合入高度大的树，避免树退化为链。

**tips**：在竞赛中，一般只写路径压缩即可。

**时间复杂度**：$O(\alpha(n))$。其中 $\alpha(n)$ 为反阿克曼函数，对于 $\forall N<{2^{2^{10^{19729}}}}$，均有 $\alpha(n)<5$。故反阿克曼函数在算法竞赛中可看做一个常数。

#### 带权并查集

**定义**：传统并查集的拓展，能够在并和查的基础上维护额外信息以解决更多问题。

**典例**：食物链。

---

#### 拓展域并查集

**定义**：传统并查集的拓展，能够处理集合间的不同关系，如相互独立或相互排斥。

**典例**：关押罪犯。
