#### 深度优先搜索 DFS

**定义**：DFS 的核心策略是"**不撞南墙不回头**"。

**过程**：它会从起点出发，沿着一条路**一直往下走**，直到走到底 ( 无法继续或到达目标 )，然后再**回溯**到上一个岔路口，换另一条路继续走到底。

**性质**：这个过程会一直重复，直到探索完所有可能的路径。

**分析**：由于只保存当前路径，DFS 的空间复杂度为 $O(h)$，$h$ 为搜索深度；但它不保证第一次到达目标就是最短路径。

**说明**：下面的三个板子对应 DFS 最基础的三类枚举模型——子集、组合、排列，其余搜索题大多由它们改造而来。三个板子都用 $u$ 表示当前处理到第几个位置，用 `b[]` 标记元素是否已被使用。

---

#### 子集枚举

**模型**：每个元素只有「选」与「不选」两种状态，共 $2^n$ 个子集。

**说明**：`b[i]` 表示元素 $i$ 是否被选中；先进入不选的分支、再进入选的分支，输出即为字典序。

```cpp
void dfs(int u) {
    if (u > n) {
        for (int i = 1; i <= n; i++) {
            if (b[i])
                cout << i << ' ';
        }
        cout << '\n';
        return;
    }
    b[u] = 0;
    dfs(u + 1);
    b[u] = 1;
    dfs(u + 1);
}
```

#### 组合枚举

**模型**：从 $n$ 个元素中选出恰好 $m$ 个，共 $C_n^m$ 种方案。

**说明**：`a` 存储当前已选的元素；先选再考虑不选，保证输出按字典序。

**剪枝**：选超了或者选太少了就直接返回。

- 已选个数超过 $m$：`a.size() > m`。
- 剩余元素全部选上也凑不够 $m$：`a.size() + (n - u + 1) < m`。

```cpp
void dfs(int u) {
    if (a.size() > m || a.size() + (n - u + 1) < m)
        return;
    if (u > n) {
        for (int i = 0; i < a.size(); i++)
            cout << a[i] << ' ';
        cout << '\n';
        return;
    }
    a.push_back(u);
    dfs(u + 1);
    a.pop_back();
    dfs(u + 1);
}
```

#### 全排列

**模型**：$n$ 个元素的所有排列，共 $n!$ 种。

**问题**：给定一个数 $n$，求这个数的所有排列。

**解决**：通过枚举每一层可能的选择来构造解。

**说明**：`a[u]` 存第 $u$ 位放的数，`b[i]` 表示数字 $i$ 是否已经被用过；进入下一层前标记，回溯时撤销。

```cpp
void dfs(int u) {
    if (u > n) {
        for (int i = 1; i <= n; i++)
            cout << a[i] << ' ';
        cout << '\n';
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (!b[i]) {
            b[i] = 1;
            a[u] = i;
            dfs(u + 1);
            b[i] = 0;
        }
    }
}
```

#### N 皇后问题

**问题**：在 $n \times n$ 的棋盘上放置 $n$ 个皇后，求所有的可行方案。

**解决**：将第 $i$ 个皇后放在第 $i$ 行，通过枚举可用的列，递归构造每一行的皇后位置。

**实现**：`dfs(u)` 表示正在放第 $u$ 行的皇后，`col[u]` 表示第 $u$ 列是否可用，`dg[u+i-1]` 和 `udg[n-u+i-1]` 表示两条对角线是否可用。
