<h3 id="差分约束"><span class="prefix"></span><span class="content">差分约束</span><span class="suffix"></span></h3>
<ul>
<li>
<p><strong>定义</strong>：是一种解决多个不等式关系问题的数学工具。简单来说，当我们有很多变量，并且它们之间存在大小关系时，差分约束可以帮助我们找到它们的可行解或判断是否有解。</p>
</li>
<li>
<p><strong>例</strong>：<code>a &gt;= b + 3</code>，差分约束就可以解决此类问题。</p>
</li>
<li>
<p>又比如 <code>a &gt;= c + 3</code> 且 <code>a &lt;= 10</code>，</p>
</li>
<li>
<p><code>d &gt;= b + 2</code>，求 a, b, c, d 的取值范围。</p>
</li>
<li>
<p>直接解它依旧很难，但可以使用差分约束转换为最短路问题求解。</p>
</li>
<li>
<p><strong>核心思想</strong>：不等式与图的关系。每个不等式均可转换为一条有向边。</p>
<ul>
<li><code>x &lt;= y + c</code>：从 <code>y → x</code> 连一条权值为 c 的有向边，此时求最短路。</li>
<li><code>x &gt;= y + c</code>：从 <code>y → x</code> 连一条权值为 c 的有向边，此时求最长路。</li>
</ul>
</li>
<li>
<p>求所有变量最小值用最长路算法，最大值用最短路算法。</p>
</li>
<li>
<p>最短路、最长路可以相互转换：</p>
<ul>
<li>在 <code>x &gt;= y + c</code> 中，可变形为 <code>y &lt;= x - c</code>，从而实现转换。</li>
</ul>
</li>
<li>
<p><strong>最短路中的不等式</strong>：<code>dist[v] &lt;= dist[u] + w</code>，即三角不等式，满足这一特点。</p>
</li>
<li>
<p><strong>建立差分约束系统</strong>：<br>
① 将不等式转化为一般形式（<code>x &lt;= y + c</code>）<br>
② 建图<br>
③ 构造超级源点 S，让 S 到任何点的距离为 0，使图连通。<br>
或将每一个点入队，计算最短路（使用 SPFA 算法）。</p>
</li>
<li>
<p>若存在负环，则无解，因为此时最短路径不存在。</p>
</li>
</ul>
