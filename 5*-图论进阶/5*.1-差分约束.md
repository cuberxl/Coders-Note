### 差分约束
---
- **定义**：是一种解决多个不等式关系问题的数学工具。简单来说，当我们有很多变量，并且它们之间存在大小关系时，差分约束可以帮助我们找到它们的可行解或判断是否有解。

- **例**：`a >= b + 3`，差分约束就可以解决此类问题。
- 又比如 `a >= c + 3` 且 `a <= 10`，
- `d >= b + 2`，求 a, b, c, d 的取值范围。
- 直接解它依旧很难，但可以使用差分约束转换为最短路问题求解。

- **核心思想**：不等式与图的关系。每个不等式均可转换为一条有向边。
    - `x <= y + c`：从 `y → x` 连一条权值为 c 的有向边，此时求最短路。
    - `x >= y + c`：从 `y → x` 连一条权值为 c 的有向边，此时求最长路。

- 求所有变量最小值用最长路算法，最大值用最短路算法。
- 最短路、最长路可以相互转换：
    - 在 `x >= y + c` 中，可变形为 `y <= x - c`，从而实现转换。

- **最短路中的不等式**：`dist[v] <= dist[u] + w`，即三角不等式，满足这一特点。

- **建立差分约束系统**：
    ① 将不等式转化为一般形式（`x <= y + c`）
    ② 建图
    ③ 构造超级源点 S，让 S 到任何点的距离为 0，使图连通。
    或将每一个点入队，计算最短路（使用 SPFA 算法）。

- 若存在负环，则无解，因为此时最短路径不存在。
