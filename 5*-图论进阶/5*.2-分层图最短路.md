### 分层图最短路
---
**定义**：每个节点拆成多层，每层代表一种状态。本质是 DP + 最短路。

**经典模型**：k次免费通行机会（边权为0）。

**构图**：
- 将原图复制到 k+1 层（0~k），第 i 层表示已使用 i 次
- 层内边：正常边权（不用免费机会）
- 层间边：第 i 层 u → 第 i+1 层 v，边权为0（使用免费机会）

```cpp
// 状态转移
if (dis[j][used] > dis[i][used] + w)  // 不用免费机会
if (used < k && dis[j][used+1] > dis[i][used])  // 使用免费机会
```
