  
### 最短路计数问题
---
**问题**：给定一张图，问从点1开始，到点i的最短路径条数。

**解决**：额外维护数组 cnt

```cpp
if (dis[j] > d + w[j]) {
    dis[j] = d + w[j];
    cnt[j] = cnt[ver];   // 找到更短路径，继承上一节点路径
} else if (dis[j] == d + w[j]) {
    cnt[j] += cnt[ver];  // 找到新最短路径，累加
}
```
