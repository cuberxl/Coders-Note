### 5.2 拓扑排序

---

**定义**：拓扑排序是对有向无环图（DAG）所有顶点的一种线性排序，使得对图中任意一条有向边 $u \to v$，$u$ 在排序中都出现在 $v$ 之前。

**核心思想**：不断将入度为 $0$ 的点加入队列，并将其出边删除（即邻接点入度减 $1$）。

```cpp
bool topsort() {
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        if (indeg[i] == 0) q.push(i);
    }
    
    int cnt = 0;  // 已加入拓扑序的点数
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ans[++cnt] = u;
        for (int i = h[u]; i != -1; i = ne[i]) {
            int v = e[i];
            indeg[v]--;
            if (indeg[v] == 0) q.push(v);
        }
    }
    return cnt == n;  // 若所有点都入队，则为 DAG
}
```

**性质**：
- 若存在环，则环上所有点入度恒不为 $0$，无法入队，最终 `cnt < n`。
- 拓扑序不唯一（队列中任意顺序均合法）。
