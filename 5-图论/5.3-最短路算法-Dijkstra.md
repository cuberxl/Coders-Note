<hr>
<h4 id="一、朴素-dijkstra-算法：将图用邻接矩阵存储"><span class="prefix"></span><span class="content">一、朴素 Dijkstra 算法：将图用邻接矩阵存储</span><span class="suffix"></span></h4>
<p>① 初始化距离，令 <code>dist[1] = 0</code>，其余为 <code>INF</code><br>
② for i = 1 to n (循环 n 次)</p>
<ul>
<li>白点：已确定最短路的点；蓝点：未确定最短路的点</li>
<li>
<ol>
<li>找到蓝点中距离最近的点 t，将 t 设为白点</li>
</ol>
</li>
<li>
<ol start="2">
<li>用 t 松弛其他蓝点的距离：如果 <code>dist[v] &gt; dist[t] + w</code>，则更新 <code>dist[v]</code></li>
</ol>
</li>
</ul>
<h4 id="二、堆优化-dijkstra-算法：将图用邻接表存储"><span class="prefix"></span><span class="content">二、堆优化 Dijkstra 算法：将图用邻接表存储</span><span class="suffix"></span></h4>
<ul>
<li>
<p>通过分析朴素 Dijkstra 的瓶颈为寻找最近点的时间复杂度 <code>O(n)</code>，故予以优化。</p>
</li>
<li>
<p>使用堆优化查找最近点，可将找最近点的复杂度降为 <code>O(log n)</code>。</p>
</li>
<li>
<p>使用优先队列实现，由于优先队列不支持修改堆中元素，故采用惰性删除（即插入新元素，当堆顶元素为过时时直接跳过）。</p>
</li>
<li>
<p>时间复杂度退化为 <code>O(m log n)</code>，由于 <code>m &lt; n^2</code>，故最差 <code>O(m log n)</code>。</p>
</li>
<li>
<p>属于同一量级，一般使用优先队列。</p>
</li>
<li>
<p>由于堆中存在过时元素，当堆顶的最小值可能是已被确认的旧值，通过比较 <code>dist</code> 与堆中存储的数值即可判断是否过时，从而避免重复处理。</p>
</li>
</ul>
