<h3 id="最短路算法---bellman-ford"><span class="prefix"></span><span class="content">最短路算法 - Bellman-Ford</span><span class="suffix"></span></h3>
<hr>
<p>模板：</p>
<pre><code class="prism language-cpp"><span class="token keyword">for</span> 循环 n 次
    <span class="token keyword">for</span> 遍历所有边
        dist<span class="token punctuation">[</span>v<span class="token punctuation">]</span> <span class="token operator">=</span> <span class="token function">min</span><span class="token punctuation">(</span>dist<span class="token punctuation">[</span>v<span class="token punctuation">]</span><span class="token punctuation">,</span> dist<span class="token punctuation">[</span>u<span class="token punctuation">]</span> <span class="token operator">+</span> w<span class="token punctuation">)</span><span class="token punctuation">;</span> <span class="token comment">// 松弛</span>
</code></pre>
<ul>
<li>
<p>其利用三角不等式 <code>dist[v] &lt;= dist[u] + w</code>。</p>
</li>
<li>
<p>“若有负权回路，最短路不一定存在。” ① → ② → ③ → ④</p>
</li>
<li>
<p>如图 1 所示，1 → 5 过程中，在 2 → 3 → 4 中，负权回路可以走无数次，dist 会越来越小，即不存在最短路。</p>
</li>
<li>
<p>Bellman-Ford 算法可判断负权回路。</p>
</li>
<li>
<p>循环迭代 k 次，<code>dist[v]</code> 的含义是经过不超过 k 条边的最短路。</p>
</li>
<li>
<p>若迭代第 n 次仍在更新，则存在一条边数为 n+1 的最短路。</p>
</li>
<li>
<p>n 条边有 n+1 个点，而 1~n 条边最多有 n 个点，由抽屉原理可知，一定有两个点的编号相同，即一定存在环，且由于还能使路径变短，说明该环为负环。</p>
</li>
<li>
<p>“Bellman-Ford 算法可判断负环，但时间复杂度高，一般使用 SPFA 算法。”</p>
</li>
<li>
<p><strong>backup 数组备份的作用</strong>：如图 2 所示，① → ② → ③ → ④</p>
</li>
<li>
<p>遍历所有边，1 2 3 4 实现 ④ 的运算变为 2，但若题目要求边数限制为 1，则 ② → ③ → ④ 的路径不需要走，发生了串联，故需要备份，使用上一次迭代的 dist 数组，以此避免串联。</p>
</li>
<li>
<p>因为存在负权边，所以部分非连通节点可能由 <code>INF</code> 变为 <code>INF + (-w)</code> -&gt; 无穷大减一个数，仍为 <code>INF</code>。</p>
</li>
<li>
<p>故判断非连通时，应写为 <code>dist[v] &gt; dist[u] + w</code> (且 <code>dist[u] != INF</code>)。</p>
</li>
</ul>
