
### 最短路算法 - Bellman-Ford
---
模板：
```cpp
for 循环 n 次
    for 遍历所有边
        dist[v] = min(dist[v], dist[u] + w); // 松弛
```

- 其利用三角不等式 `dist[v] <= dist[u] + w`。

- “若有负权回路，最短路不一定存在。” ① → ② → ③ → ④
- 如图 1 所示，1 → 5 过程中，在 2 → 3 → 4 中，负权回路可以走无数次，dist 会越来越小，即不存在最短路。

- Bellman-Ford 算法可判断负权回路。
- 循环迭代 k 次，`dist[v]` 的含义是经过不超过 k 条边的最短路。
- 若迭代第 n 次仍在更新，则存在一条边数为 n+1 的最短路。
- n 条边有 n+1 个点，而 1~n 条边最多有 n 个点，由抽屉原理可知，一定有两个点的编号相同，即一定存在环，且由于还能使路径变短，说明该环为负环。

- “Bellman-Ford 算法可判断负环，但时间复杂度高，一般使用 SPFA 算法。”

- **backup 数组备份的作用**：如图 2 所示，① → ② → ③ → ④
- 遍历所有边，1 2 3 4 实现 ④ 的运算变为 2，但若题目要求边数限制为 1，则 ② → ③ → ④ 的路径不需要走，发生了串联，故需要备份，使用上一次迭代的 dist 数组，以此避免串联。

- 因为存在负权边，所以部分非连通节点可能由 `INF` 变为 `INF + (-w)` -> 无穷大减一个数，仍为 `INF`。
- 故判断非连通时，应写为 `dist[v] > dist[u] + w` (且 `dist[u] != INF`)。
