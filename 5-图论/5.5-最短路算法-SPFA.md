<h3 id="最短路算法---spfa"><span class="prefix"></span><span class="content">最短路算法 - SPFA</span><span class="suffix"></span></h3>
<ul>
<li>
<p>SPFA 算法在 Bellman-Ford 的基础上进行了优化，三角不等式 <code>dist[v] = min(dist[v], dist[u] + w)</code>。</p>
</li>
<li>
<p>在 SPFA 中，只有 <code>dist[u]</code> 变小了，后继的节点才可能更新。</p>
</li>
<li>
<p><strong>利用队列进行优化</strong>：</p>
<ul>
<li>起点加入队列，当队列非空：</li>
<li>① 取出队头 u，队头出队。</li>
<li>② 遍历 u 的所有出边 <code>u → v</code>，若更新成功，且 v 不在队列中，则入队。</li>
</ul>
</li>
<li>
<p>队列中存储待更新的节点。</p>
</li>
<li>
<ul>
<li>SPFA 算法也可替代 Dijkstra 算法，但若遇到网格图，SPFA 算法可能退化为 <code>O(nm)</code> 极慢，但一般快于 Dijkstra 算法。</li>
</ul>
</li>
<li>
<p><strong>SPFA 判负环思路</strong>：定义 <code>dist[i]</code> 表示最短距离，<code>cnt[i]</code> 表示最短路边数，在松弛时 <code>cnt[v] = cnt[u] + 1</code>。</p>
</li>
<li>
<p>若 <code>cnt[v] &gt; n</code>，则该路径出现负环，则存在负环。</p>
</li>
<li>
<p>由于判断的是整个图，故需将所有点入队。</p>
</li>
<li>
<p><strong>dist 初始化为 0 的原因</strong>：由于是判断负环，我们只需要找是否存在能持续更新的环，比较的是差的变化，而非距离值本身。</p>
</li>
<li>
<p>在判负环的实际问题中，<code>dist</code> 初始化为 0 比初始化为 <code>INF</code> 更高效（因为只需找环的差值）。</p>
</li>
</ul>
