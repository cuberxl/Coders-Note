#### 概念

- 树和图的两种存储方式，树是特殊的无环连通图。
- 图分为有向图、无向图 ( 无向图可看作有向图的双向边，$a \to b$，$b \to a$ ) 。
- 故无向图是特殊的有向图。

---

#### 存储方式

**说明**：链式前向星用三个数组模拟邻接表，`add(a, b)` 添加一条 $a \to b$ 的边。

```cpp
int h[N], e[N], ne[N], idx;

void add(int a, int b) {
    e[idx] = b;
    ne[idx] = h[a];
    h[a] = idx++;
}
```

---

#### 图的遍历 DFS

**说明**：`st[u]` 标记节点 $u$ 已被访问，递归进入未访问的邻点。

```cpp
void dfs(int u) {
    st[u] = true;
    for (int i = h[u]; i != -1; i = ne[i]) {
        int j = e[i];
        if (!st[j]) dfs(j);
    }
}
```

---

#### 图的遍历 BFS

**说明**：从起点入队开始，每次取出队头，把未访问的邻点标记后入队。

```cpp
queue<int> q;
q.push(1);
st[1] = true;
while (!q.empty()) {
    int t = q.front();
    q.pop();
    for (int i = h[t]; i != -1; i = ne[i]) {
        int j = e[i];
        if (!st[j]) {
            st[j] = true;
            q.push(j);
        }
    }
}
```
