#### 分层图最短路

**定义**：每个节点拆成多层，每层代表一种状态。本质是 DP + 最短路。

**经典模型**：$k$ 次免费通行机会 ( 边权为 $0$ )。

---

#### 构图

1. 将原图复制到 $k+1$ 层 ( $0 \sim k$ )，第 $i$ 层表示已使用 $i$ 次。
2. 层内边：正常边权 ( 不用免费机会 )。
3. 层间边：第 $i$ 层 $u \to$ 第 $i+1$ 层 $v$，边权为 $0$ ( 使用免费机会 )。

---

#### 状态转移

**说明**：

- 不使用免费机会：从同层的 $i$ 转移到 $j$，代价为边权 $w$。
- 使用免费机会：从第 $used$ 层的 $i$ 转移到第 $used+1$ 层的 $j$，代价为 $0$。

```cpp
if (dis[j][used] > dis[i][used] + w)
if (used < k && dis[j][used+1] > dis[i][used])
```
