#### 最短路计数问题

**问题**：给定一张图，问从点 $1$ 开始，到点 $i$ 的最短路径条数。

**解决**：额外维护数组 $cnt$。

---

#### 状态转移

**说明**：找到更短的路径时，直接继承上一节点的路径条数；路径长度相等时，把新路径的条数累加到原有条数上。

```cpp
if (dis[j] > d + w[j]) {
    dis[j] = d + w[j];
    cnt[j] = cnt[ver];
} else if (dis[j] == d + w[j]) {
    cnt[j] += cnt[ver];
}
```
