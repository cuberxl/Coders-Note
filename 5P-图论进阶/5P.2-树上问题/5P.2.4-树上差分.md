#### $\S$ 概念

通过在树上对特定节点打上“差分标记”，最后利用一次自底向上的 DFS 子树求和，来快速还原出每个节点（或每条边）被操作的次数，分为点差分和边差分两类。属于最近公共祖先的一种应用。

---

#### $\S$ 树上差分 · 边差分

策略：

- 设我们要对两个节点 $u, v$ 间的路径进行操作 $+ k$，且 $\text{LCA}(u, v) = p$
- 将节点 $u$ 和 $v$ 的值加 $k$，将节点 $p$ 的值减 $2k$。
- 利用 DFS 自底向上对每个节点的子树大小进行统计，节点 $u$ 的子树大小即为节点 $u$ 和其父亲节点间的连边的权值。

证明：
- 路径上的边被正确标记：对于 $u \to p$ 和 $v \to p$ 路径上的任意一点 $x$，由于 $u$ 或 $v$ 在其子树内，标记会随着子树求和一路传递上来，使得这些边被加上 $k$。
- 路径外的边不受影响：对于 $u \to p$ 和 $v \to p$ 路径之外的节点，其子树中不含 $u$ 或 $v$，没有差分标记流入，其子树和保持不变，也就是覆盖次数不变。
- 防止标记向上溢出：在 $p$ 点处，$u$ 和 $v$ 的标记汇聚，导致它凭空多出了 $2k$。但 $p$ 与其父亲之间的边并不在 $u \to v$ 路径上，所以要在 $p$ 点减去 $2k$，阻止标记流向 $p$ 的祖先。

代码模板：

```cpp
void change(int u, int v, int k) {
    int p = lca(u, v);
    f[p] -= 2 * k;
    f[u] += k; f[v] += k;
}
void dfs_3(int u) {
    val[u] = f[u];
    for (int i = h[u]; ~i; i = ne[i]) {
        int v = to[i];
        if (v == fa[u]) continue;
        dfs_3(v);
        val[u] += val[v];
    }
}
```

#### $\S$ 闇の连锁

- 问题：[Acwing 352. 闇の连锁](https://www.acwing.com/problem/content/354/)

- 策略：
- 根据题目意义，易得 Dark 有 $n - 1$ 条树边和 $m$ 条非树边。
  - 首先，观察没有非树边的 Dark。
  - 显然，斩断任意一条树边都可以将 Dark 击败。
-  若 Dark 有一条非树边：
   - 显然，这条非树边与树边形成了一个环。
   - 如果要在环上斩断 Dark，显然需要斩断该非树边和一条环上的树边。
- 若 Dark 有若干条非树边：
  - 显然每条非树边都会与树边形成一个环，我们称之为该非树边被环覆盖。
  - 则这棵树上有若干个环，每条树边都可能处在一个或几个环中。 
  - 如果一条树边没有被任何环覆盖，则斩断该树边，Dark 已经一分为二，此时再斩断任意一条非树边均可击败 Dark，方案数为 $m$。
  - 如果一条树边只被一个环覆盖，如上一种情况所述，方案数为 $1$。
  - 如果一条树边被若干个环覆盖，斩断这条树边后，斩断任意一条非树边都不可以击败 Dark（环仍然存在），方案数为 $0$。
- 如何维护树边位于几个环中：
  - 若有一条从 $u$ 到 $v$ 的非树边，则 $u \rightarrow v$ 路径上的边均被非树边覆盖了一次（即处在一个环中）
  - 故可利用树上差分（边差分）进行维护。
  - 最后按照上述逻辑统计答案。
