#### $\S$ 点双连通分量 ( v-DCC )
- **割点**：对于一个连通图来说，如果将某个点 ( 和与其关联的所有边 ) 删去，图会变为非连通图，则该点被称为割点。
- **点双连通分量**：在一个无向图中，任意两点均有两条点不重复的路径的极大子图。其具有如下性质：
  - 点双连通分量内部没有割点 ( 充要条件 )。
  - 任意两个点双连通分量之间最多一个公共点，且该点一定是割点。
  - 点双连通分量可以在缩点后成为一棵圆方树。
