
### 背包 DP

---

**DP问题基本结构**：
- **状态表示**：表示的集合 + 表示的属性（$max$/$min$/$count$）
- **状态计算（集合划分）**：不重不漏


#### 一、01背包问题

**问题**：$N$ 个物品，背包容量 $V$，每件物品只能取一次，求最大价值。

**状态表示**：$f[i][j]$ 表示从前 $i$ 个物品中选，总体积不超过 $j$ 的最大价值。

**集合划分**：依照第 $i$ 个物品选或不选划分
- 不选第 $i$ 个物品：$f[i][j] = f[i-1][j]$
- 选第 $i$ 个物品：$f[i][j] = f[i-1][j-v] + w$（仅当 $j \ge v$）

**递推式**：$f[i][j] = \max(f[i-1][j], f[i-1][j-v] + w)$

**空间优化**：删去第一维，$f[j] = \max(f[j], f[j-v] + w)$，$j$ 从大到小枚举。


#### 二、完全背包问题

**问题**：每件物品可取无限次，求最大价值。

**状态表示**：$f[i][j]$ 表示从前 $i$ 个物品中选，总体积不超过 $j$ 的最大价值。

**集合划分**：依照第 $i$ 个物品选几个（$0, 1, 2, \dots$）划分
- 选 $k$ 个：$f[i-1][j-k \cdot v] + k \cdot w$

**递推式**：
$f[i][j] = \max(f[i-1][j], f[i-1][j-v] + w, f[i-1][j-2v] + 2w, \dots)$

**优化**：
- 将 $j$ 替换为 $j-v$：$f[i][j-v] = \max(f[i-1][j-v], f[i-1][j-2v] + w, \dots)$
- 代入得：$f[i][j] = \max(f[i-1][j], f[i][j-v] + w)$

**空间优化**：$f[j] = \max(f[j], f[j-v] + w)$，$j$ 从小到大枚举。


#### 三、多重背包问题

**问题**：每个物品最多取 $c$ 次，求最大价值。

**状态表示**：$f[i][j]$ 表示从前 $i$ 个物品中选，总体积不超过 $j$ 的最大价值。

**集合划分**：依照第 $i$ 个物品选几个（$0, 1, 2, \dots, c$）划分

**二进制优化**：
- 将 $c$ 拆分为：$2^0, 2^1, 2^2, \dots, 2^k, c - 2^{k+1} + 1$
- 这些数可组合出 $0 \sim c$ 的任意整数，转化为 01 背包问题。
- 时间复杂度：$O(NV \log c)$

**单调队列优化**：时间复杂度可降至 $O(NV)$。


#### 四、分组背包问题

**问题**：有若干组物品，每组只能选一个，求最大价值。

**状态表示**：$f[i][j]$ 表示从前 $i$ 组物品中选，总体积不超过 $j$ 的最大价值。

**集合划分**：依照第 $i$ 组选哪个物品（或不选）划分
- 不选第 $i$ 组：$f[i][j] = f[i-1][j]$
- 选第 $i$ 组第 $k$ 个：$f[i-1][j-v[i][k]] + w[i][k]$

**递推式**：$f[i][j] = \max(f[i-1][j], \max_k(f[i-1][j-v[i][k]] + w[i][k]))$

**优化**：同一组中体积相同的物品可去重，减小常数。
