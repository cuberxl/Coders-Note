<h3 id="背包-dp"><span class="prefix"></span><span class="content">背包 DP</span><span class="suffix"></span></h3>
<p><strong>DP问题基本结构</strong>：</p>
<ul>
<li><strong>状态表示</strong>：表示的集合 + 表示的属性（max/min/count）</li>
<li><strong>状态计算（集合划分）</strong>：不重不漏</li>
</ul>
<h4 id="一、01背包问题"><span class="prefix"></span><span class="content">一、01背包问题</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：N个物品，背包容量V，每件物品只能取一次，求最大价值。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从前i个物品中选，总体积不超过j的最大价值。</p>
<p><strong>集合划分</strong>：依照第i个物品选或不选划分</p>
<ul>
<li>不选第i个物品：<code>f[i][j] = f[i-1][j]</code></li>
<li>选第i个物品：<code>f[i][j] = f[i-1][j-v] + w</code>（仅当 j &gt;= v）</li>
</ul>
<p><strong>递推式</strong>：<code>f[i][j] = max(f[i-1][j], f[i-1][j-v] + w)</code></p>
<p><strong>空间优化</strong>：删去第一维，<code>f[j] = max(f[j], f[j-v] + w)</code>，j从大到小枚举。</p>
<h4 id="二、完全背包问题"><span class="prefix"></span><span class="content">二、完全背包问题</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：每件物品可取无限次，求最大价值。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从前i个物品中选，总体积不超过j的最大价值。</p>
<p><strong>集合划分</strong>：依照第i个物品选几个（0, 1, 2, …）划分</p>
<ul>
<li>选k个：<code>f[i-1][j-k*v] + k*w</code></li>
</ul>
<p><strong>递推式</strong>：</p>
<ul>
<li><code>f[i][j] = max(f[i-1][j], f[i-1][j-v] + w, f[i-1][j-2v] + 2w, ...)</code></li>
</ul>
<p><strong>优化</strong>：</p>
<ul>
<li>将 j 替换为 j-v：<code>f[i][j-v] = max(f[i-1][j-v], f[i-1][j-2v] + w, ...)</code></li>
<li>代入得：<code>f[i][j] = max(f[i-1][j], f[i][j-v] + w)</code></li>
</ul>
<p><strong>空间优化</strong>：<code>f[j] = max(f[j], f[j-v] + w)</code>，j从小到大枚举。</p>
<h4 id="三、多重背包问题"><span class="prefix"></span><span class="content">三、多重背包问题</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：每个物品最多取c次，求最大价值。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从前i个物品中选，总体积不超过j的最大价值。</p>
<p><strong>集合划分</strong>：依照第i个物品选几个（0, 1, 2, …, c）划分</p>
<p><strong>二进制优化</strong>：</p>
<ul>
<li>将c拆分为：<code>2^0, 2^1, 2^2, ..., 2^k, c - 2^(k+1) + 1</code></li>
<li>这些数可组合出0~c的任意整数，转化为01背包问题。</li>
<li>时间复杂度：O(NV log c)</li>
</ul>
<p><strong>单调队列优化</strong>：时间复杂度可降至O(NV)。</p>
<h4 id="四、分组背包问题"><span class="prefix"></span><span class="content">四、分组背包问题</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：有若干组物品，每组只能选一个，求最大价值。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从前i组物品中选，总体积不超过j的最大价值。</p>
<p><strong>集合划分</strong>：依照第i组选哪个物品（或不选）划分</p>
<ul>
<li>不选第i组：<code>f[i][j] = f[i-1][j]</code></li>
<li>选第i组第k个：<code>f[i-1][j-v[i][k]] + w[i][k]</code></li>
</ul>
<p><strong>递推式</strong>：<code>f[i][j] = max(f[i-1][j], max_k(f[i-1][j-v[i][k]] + w[i][k]))</code></p>
<p><strong>优化</strong>：同一组中体积相同的物品可去重，减小常数。</p>
