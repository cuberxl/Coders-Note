<h3 id="线性dp"><span class="prefix"></span><span class="content">线性DP</span><span class="suffix"></span></h3>
<p><strong>定义</strong>：线性DP是最基础的DP模型，其状态转移通常具有线性结构，常见于一维或二维递推。</p>
<hr>
<h4 id="一、数字三角形"><span class="prefix"></span><span class="content">一、数字三角形</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定一个数字三角形，求从顶部到底部的一条路径，使得路径上数字之和最大。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从顶部到达第 <code>i</code> 行第 <code>j</code> 列的最大路径和。</p>
<p><strong>状态计算</strong>：考虑最后一步，只能从上方 <code>f[i-1][j]</code> 或左上方 <code>f[i-1][j-1]</code> 转移而来。</p>
<p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = max(f[i-1][j], f[i-1][j-1]) + a[i][j]
</code></pre>
<p><strong>注意</strong>：初始化时将所有 <code>f[i][j]</code> 赋为 <code>-INF</code>（负无穷），以防边界问题。</p>
<h4 id="二、最长上升子序列（lis）"><span class="prefix"></span><span class="content">二、最长上升子序列（LIS）</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定一个数列，求最长的严格递增子序列长度（不要求连续）。</p>
<p><strong>状态表示</strong>：<code>f[i]</code> 表示以第 <code>i</code> 个数结尾的最长上升子序列长度。</p>
<p><strong>状态计算</strong>：枚举前面所有满足 <code>a[j] &lt; a[i]</code> 的位置 <code>j</code>，取最大值加 1。</p>
<p><strong>递推式</strong>：</p>
<pre><code>f[i] = max(f[i], f[j] + 1)  (0 ≤ j &lt; i, a[j] &lt; a[i])
</code></pre>
<p><strong>时间复杂度</strong>：<code>O(n²)</code>。</p>
<p><strong>优化（O(n log n)）</strong>：</p>
<p>维护数组 <code>q</code>，其中 <code>q[len]</code> 表示长度为 <code>len</code> 的上升子序列末尾的最小值。</p>
<p>遍历 <code>a[i]</code>：</p>
<ul>
<li>若 <code>a[i] &gt; q.back()</code>，加入 <code>q</code> 末尾；</li>
<li>否则在 <code>q</code> 中二分查找第一个 <code>≥ a[i]</code> 的位置并替换。</li>
</ul>
<p><strong>核心性质</strong>：<code>q</code> 是单调递增的，因此可用二分查找。</p>
<h4 id="三、最长公共子序列（lcs）"><span class="prefix"></span><span class="content">三、最长公共子序列（LCS）</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定两个序列 <code>a</code> 和 <code>b</code>，求它们的最长公共子序列长度。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示 <code>a</code> 的前 <code>i</code> 个字符和 <code>b</code> 的前 <code>j</code> 个字符的最长公共子序列长度。</p>
<p><strong>状态计算</strong>：考虑 <code>a[i]</code> 和 <code>b[j]</code> 是否匹配：</p>

<table>
<thead>
<tr>
<th align="left">情况</th>
<th align="left">含义</th>
<th align="left">取值</th>
</tr>
</thead>
<tbody>
<tr>
<td align="left">00</td>
<td align="left">不选 <code>a[i]</code>，不选 <code>b[j]</code></td>
<td align="left"><code>f[i-1][j-1]</code></td>
</tr>
<tr>
<td align="left">01</td>
<td align="left">不选 <code>a[i]</code>，选 <code>b[j]</code></td>
<td align="left"><code>f[i-1][j]</code></td>
</tr>
<tr>
<td align="left">10</td>
<td align="left">选 <code>a[i]</code>，不选 <code>b[j]</code></td>
<td align="left"><code>f[i][j-1]</code></td>
</tr>
<tr>
<td align="left">11</td>
<td align="left">选 <code>a[i]</code> 和 <code>b[j]</code>（仅当相等）</td>
<td align="left"><code>f[i-1][j-1] + 1</code></td>
</tr>
</tbody>
</table><p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = max(f[i-1][j], f[i][j-1])
if (a[i] == b[j]) f[i][j] = max(f[i][j], f[i-1][j-1] + 1)
</code></pre>
<h4 id="四、最短编辑距离"><span class="prefix"></span><span class="content">四、最短编辑距离</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定两个字符串 <code>a</code> 和 <code>b</code>，允许对 <code>a</code> 进行插入、删除、替换操作，求将 <code>a</code> 变为 <code>b</code> 的最少操作次数。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示将 <code>a</code> 的前 <code>i</code> 个字符变为 <code>b</code> 的前 <code>j</code> 个字符的最少操作次数。</p>
<p><strong>状态计算</strong>：考虑最后一次操作：</p>

<table>
<thead>
<tr>
<th align="left">操作</th>
<th align="left">转移</th>
<th align="left">含义</th>
</tr>
</thead>
<tbody>
<tr>
<td align="left">删除</td>
<td align="left"><code>f[i-1][j] + 1</code></td>
<td align="left"><code>a[i]</code> 多余，删掉</td>
</tr>
<tr>
<td align="left">插入</td>
<td align="left"><code>f[i][j-1] + 1</code></td>
<td align="left">插入 <code>b[j]</code> 来匹配</td>
</tr>
<tr>
<td align="left">替换/匹配</td>
<td align="left">相等：<code>f[i-1][j-1]</code><br>不等：<code>f[i-1][j-1] + 1</code></td>
<td align="left">替换 <code>a[i]</code> 为 <code>b[j]</code> 或直接匹配</td>
</tr>
</tbody>
</table><p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = min(f[i-1][j] + 1, f[i][j-1] + 1, f[i-1][j-1] + (a[i] != b[j]))
</code></pre>
<p><strong>边界</strong>：</p>
<ul>
<li><code>f[i][0] = i</code>（删除 <code>i</code> 次）</li>
<li><code>f[0][j] = j</code>（插入 <code>j</code> 次）</li>
</ul>
