### 线性DP
---
**定义**：线性DP是最基础的DP模型，其状态转移通常具有线性结构，常见于一维或二维递推。

#### 一、数字三角形

**问题**：给定一个数字三角形，求从顶部到底部的一条路径，使得路径上数字之和最大。

**状态表示**：`f[i][j]` 表示从顶部到达第 `i` 行第 `j` 列的最大路径和。

**状态计算**：考虑最后一步，只能从上方 `f[i-1][j]` 或左上方 `f[i-1][j-1]` 转移而来。

**递推式**：
```
f[i][j] = max(f[i-1][j], f[i-1][j-1]) + a[i][j]
```

**注意**：初始化时将所有 `f[i][j]` 赋为 `-INF`（负无穷），以防边界问题。


#### 二、最长上升子序列（LIS）

**问题**：给定一个数列，求最长的严格递增子序列长度（不要求连续）。

**状态表示**：`f[i]` 表示以第 `i` 个数结尾的最长上升子序列长度。

**状态计算**：枚举前面所有满足 `a[j] < a[i]` 的位置 `j`，取最大值加 1。

**递推式**：
```
f[i] = max(f[i], f[j] + 1)  (0 ≤ j < i, a[j] < a[i])
```

**时间复杂度**：`O(n²)`。

**优化（O(n log n)）**：

维护数组 `q`，其中 `q[len]` 表示长度为 `len` 的上升子序列末尾的最小值。

遍历 `a[i]`：
- 若 `a[i] > q.back()`，加入 `q` 末尾；
- 否则在 `q` 中二分查找第一个 `≥ a[i]` 的位置并替换。

**核心性质**：`q` 是单调递增的，因此可用二分查找。


#### 三、最长公共子序列（LCS）

**问题**：给定两个序列 `a` 和 `b`，求它们的最长公共子序列长度。

**状态表示**：`f[i][j]` 表示 `a` 的前 `i` 个字符和 `b` 的前 `j` 个字符的最长公共子序列长度。

**状态计算**：考虑 `a[i]` 和 `b[j]` 是否匹配：

| 情况 | 含义 | 取值 |
|:---|:---|:---|
| 00 | 不选 `a[i]`，不选 `b[j]` | `f[i-1][j-1]` |
| 01 | 不选 `a[i]`，选 `b[j]` | `f[i-1][j]` |
| 10 | 选 `a[i]`，不选 `b[j]` | `f[i][j-1]` |
| 11 | 选 `a[i]` 和 `b[j]`（仅当相等） | `f[i-1][j-1] + 1` |

**递推式**：
```
f[i][j] = max(f[i-1][j], f[i][j-1])
if (a[i] == b[j]) f[i][j] = max(f[i][j], f[i-1][j-1] + 1)
```


#### 四、最短编辑距离

**问题**：给定两个字符串 `a` 和 `b`，允许对 `a` 进行插入、删除、替换操作，求将 `a` 变为 `b` 的最少操作次数。

**状态表示**：`f[i][j]` 表示将 `a` 的前 `i` 个字符变为 `b` 的前 `j` 个字符的最少操作次数。

**状态计算**：考虑最后一次操作：

| 操作 | 转移 | 含义 |
|:---|:---|:---|
| 删除 | `f[i-1][j] + 1` | `a[i]` 多余，删掉 |
| 插入 | `f[i][j-1] + 1` | 插入 `b[j]` 来匹配 |
| 替换/匹配 | 相等：`f[i-1][j-1]`<br>不等：`f[i-1][j-1] + 1` | 替换 `a[i]` 为 `b[j]` 或直接匹配 |

**递推式**：
```
f[i][j] = min(f[i-1][j] + 1, f[i][j-1] + 1, f[i-1][j-1] + (a[i] != b[j]))
```

**边界**：
- `f[i][0] = i`（删除 `i` 次）
- `f[0][j] = j`（插入 `j` 次）
