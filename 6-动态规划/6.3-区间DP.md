<h3 id="区间dp"><span class="prefix"></span><span class="content">区间DP</span><span class="suffix"></span></h3>
<p><strong>定义</strong>：状态表示为一个连续区间，大区间的最优解由若干小区间合并而来。</p>
<hr>
<h4 id="一、石子合并"><span class="prefix"></span><span class="content">一、石子合并</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：有排成一排的 <code>N</code> 堆石子，均有一定的质量，每次只能合并相邻两堆，代价为其质量之和，求合并为一堆的最小代价。</p>
<p><strong>状态表示</strong>：</p>
<ul>
<li>集合：所有将第 <code>i</code> 堆到第 <code>j</code> 堆石子合并的方式</li>
<li>属性：<code>min</code>（最小值）</li>
</ul>
<p><strong>状态计算</strong>：以最后一次合并的分界线 <code>k</code> 分类：</p>
<ul>
<li>左边合并为 <code>f[i][k]</code></li>
<li>右边合并为 <code>f[k+1][j]</code></li>
<li>最后一次合并代价为区间和 <code>S[j] - S[i-1]</code></li>
</ul>
<p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = min(f[i][k] + f[k+1][j] + S[j] - S[i-1])  (i ≤ k &lt; j)
</code></pre>
<p><strong>遍历顺序</strong>：为保证计算 <code>f[i][j]</code> 时，其依赖的子区间已计算完毕，按区间长度从小到大枚举：</p>
