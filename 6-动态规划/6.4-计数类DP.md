
### 计数类DP

---

**定义**：属性为方案数的 DP 问题。

#### 一、整数划分问题

**问题**：求整数 $n$ 划分成若干个正整数的方案数（顺序无关，如 $3 = 1+2$ 与 $2+1$ 视为同一种）。


**解法一（完全背包思想）**

**状态表示**：$f[i][j]$ 表示从 $1 \sim i$ 中选数，总和为 $j$ 的方案数。
- 属性：$count$（方案数）

**状态计算**：同完全背包，考虑第 $i$ 个数选 $k$ 个。

**递推式**：
$$f[i][j] = \sum_{k \ge 0} f[i-1][j - k \cdot i]$$

**优化**：
- $f[i][j-i] = \sum_{k \ge 1} f[i-1][j - k \cdot i]$
- 故 $f[i][j] = f[i-1][j] + f[i][j-i]$

```cpp
// 一维空间优化（完全背包正序枚举）
f[0] = 1;
for (int i = 1; i <= n; i++) {
    for (int j = i; j <= n; j++) {
        f[j] += f[j - i];
    }
}
// 答案：f[n]
```


**解法二（最小值分类）**

**状态表示**：$f[i][j]$ 表示总和为 $i$，恰好用 $j$ 个数表示的方案数。
- 属性：$count$（方案数）

**状态计算**：按表示的 $j$ 个数中最小值为 $1$ 分类：

1. **最小值 = 1**：取走一个 $1$，$f[i][j] = f[i-1][j-1]$
2. **最小值 > 1**：每个数都减 $1$，$f[i][j] = f[i-j][j]$

**递推式**：
$$f[i][j] = f[i-1][j-1] + f[i-j][j]$$

```cpp
f[0][0] = 1;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        f[i][j] = f[i-1][j-1] + f[i-j][j];
    }
}
// 答案：sum(f[n][1] + f[n][2] + ... + f[n][n])
```
