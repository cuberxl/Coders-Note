<h3 id="计数类dp"><span class="prefix"></span><span class="content">计数类DP</span><span class="suffix"></span></h3>
<p><strong>定义</strong>：属性为方案数的 DP 问题。</p>
<hr>
<h4 id="一、整数划分问题"><span class="prefix"></span><span class="content">一、整数划分问题</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：求整数 <code>n</code> 划分成若干个正整数的方案数（顺序无关，如 <code>3 = 1+2</code> 与 <code>2+1</code> 视为同一种）。</p>
<p><strong>解法一（完全背包思想）</strong></p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示从 <code>1 ~ i</code> 中选数，总和为 <code>j</code> 的方案数。</p>
<ul>
<li>属性：<code>count</code>（方案数）</li>
</ul>
<p><strong>状态计算</strong>：同完全背包，考虑第 <code>i</code> 个数选 <code>k</code> 个。</p>
<p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = sum(f[i-1][j], f[i-1][j-i], f[i-1][j-2i], ...)
</code></pre>
<p><strong>优化</strong>：</p>
<ul>
<li><code>f[i][j-i] = sum(f[i-1][j-i], f[i-1][j-2i], ...)</code></li>
<li>故 <code>f[i][j] = f[i-1][j] + f[i][j-i]</code></li>
</ul>

<p><strong>解法二（最小值分类）</strong></p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示总和为 <code>i</code>，恰好用 <code>j</code> 个数表示的方案数。</p>
<ul>
<li>属性：<code>count</code>（方案数）</li>
</ul>
<p><strong>状态计算</strong>：按表示的 <code>j</code> 个数中最小值为 <code>1</code> 分类：</p>
<ol>
<li><strong>最小值 = 1</strong>：取走一个 <code>1</code>，<code>f[i][j] = f[i-1][j-1]</code></li>
<li><strong>最小值 &gt; 1</strong>：每个数都减 <code>1</code>，<code>f[i][j] = f[i-j][j]</code></li>
</ol>
<p><strong>递推式</strong>：</p>
<pre><code>f[i][j] = f[i-1][j-1] + f[i-j][j]
</code></pre>
