<h3 id="状态压缩-dp"><span class="prefix"></span><span class="content">状态压缩 DP</span><span class="suffix"></span></h3>
<p><strong>定义</strong>：用一个二进制整数来表示一个集合/状态，从而将状态压缩为整数，便于进行状态转移。</p>
<hr>
<h4 id="一、蒙德里安的梦想"><span class="prefix"></span><span class="content">一、蒙德里安的梦想</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：求把 <code>N x M</code> 的棋盘分割成若干个 <code>1 x 2</code> 的长方形的方案数。</p>
<p><strong>解决</strong>：先考虑横向骨牌放好时，纵向骨牌也就唯一确定了。因此只需要枚举横向摆放的方案数。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code> 表示第 <code>i</code> 列的状态，<code>j</code> 为一个二进制数，表示从 <code>i-1</code> 列伸出来的横骨牌的状态。</p>
<p><strong>状态转移</strong>：<br>
定义 <code>k</code> 为从 <code>i-2</code> 列伸出来的横骨牌的状态：</p>
<ol>
<li><code>k</code> 和 <code>j</code> 不能有冲突（同一位置上不能重叠），需满足：<code>(j &amp; k) == 0</code></li>
<li>每一列剩下的连续空格子必须为偶数个长度（纵向骨牌是 <code>1 x 2</code> 的，必须竖着放）</li>
</ol>
<p>因此，<code>j | k</code> 不能有连续奇数个 <code>0</code>。</p>
<p><strong>状态计算</strong>：<br>
枚举 <code>j</code> 和 <code>k</code>，检查第 <code>i</code> 列的状态是否合法：</p>
<pre><code class="prism language-cpp">f<span class="token punctuation">[</span>i<span class="token punctuation">]</span><span class="token punctuation">[</span>j<span class="token punctuation">]</span> <span class="token operator">+=</span> f<span class="token punctuation">[</span>i<span class="token operator">-</span><span class="token number">1</span><span class="token punctuation">]</span><span class="token punctuation">[</span>k<span class="token punctuation">]</span>
</code></pre>
<p><strong>初始化</strong>：<code>f[0][0] = 1</code>（第 0 列左边没有列，不可能有骨牌伸出）</p>
<p><strong>最终答案</strong>：<code>f[m][0]</code>（第 m 列没有横骨牌伸到格子外面）</p>
<h4 id="二、最短-hamilton-路径"><span class="prefix"></span><span class="content">二、最短 Hamilton 路径</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定一张 <code>n</code> 个点的带权无向图，求从起点 <code>0</code> 到终点 <code>n-1</code> 的最短 Hamilton 路径（不重不漏地经过每个点恰好一次）。</p>
<p><strong>状态表示</strong>：<code>f[i][j]</code></p>
<ul>
<li>集合：所有从 <code>0</code> 到 <code>j</code>，且经过的点的集合表示为二进制 <code>i</code> 的所有路径</li>
<li>属性：<code>min</code>（路径长度的最小值）</li>
</ul>
<p><strong>状态计算</strong>：依据倒数第二个点 <code>k</code> 进行分类</p>
<p>设倒数第二个点为 <code>k</code>，则求 <code>0 -&gt; k -&gt; j</code> 的最短路径：</p>
<ul>
<li><code>k -&gt; j</code> 的距离已知</li>
<li><code>0 -&gt; k</code> 的路径集合为 <code>i - {j}</code></li>
</ul>
<p><strong>递推式</strong>：</p>
<pre><code class="prism language-cpp">f<span class="token punctuation">[</span>i<span class="token punctuation">]</span><span class="token punctuation">[</span>j<span class="token punctuation">]</span> <span class="token operator">=</span> <span class="token function">min</span><span class="token punctuation">(</span>f<span class="token punctuation">[</span>i <span class="token operator">-</span> <span class="token punctuation">(</span><span class="token number">1</span> <span class="token operator">&lt;&lt;</span> j<span class="token punctuation">)</span><span class="token punctuation">]</span><span class="token punctuation">[</span>k<span class="token punctuation">]</span> <span class="token operator">+</span> a<span class="token punctuation">[</span>k<span class="token punctuation">]</span><span class="token punctuation">[</span>j<span class="token punctuation">]</span><span class="token punctuation">)</span>
</code></pre>
<p><strong>最终答案</strong>：</p>
<pre><code class="prism language-cpp">f<span class="token punctuation">[</span><span class="token punctuation">(</span><span class="token number">1</span> <span class="token operator">&lt;&lt;</span> n<span class="token punctuation">)</span> <span class="token operator">-</span> <span class="token number">1</span><span class="token punctuation">]</span><span class="token punctuation">[</span>n<span class="token operator">-</span><span class="token number">1</span><span class="token punctuation">]</span>
</code></pre>
