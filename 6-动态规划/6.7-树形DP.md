### 树形 DP
---
**定义**：在树形数据结构上进行动态规划，父节点状态由子节点递推而来。

#### 一、没有上司的舞会

**问题**：有 `n` 个职工，关系构成一棵树，每个节点代表一个职员，没有职员愿意与直接上司一同参会。每个职员有一个快乐指数，求邀请参会人员的最大快乐指数总和。

**状态表示**：`f[u][j]`
- 集合：以 `u` 为根的子树中，`j` 表示是否选 `u`（0 不选，1 选）的所有方案
- 属性：`max`（快乐指数最大值）

**状态计算**：

```
f[u][0] = sum(max(f[son][0], f[son][1]))   // u 不选，子节点可选可不选
f[u][1] = sum(f[son][0])                    // u 选，子节点必定不选
```

**实现**：树结构用邻接表存储，从根节点开始递归求解。

```cpp
void dfs(int u) {
    f[u][1] = w[u];
    for (int i = h[u]; i != -1; i = ne[i]) {
        int v = e[i];
        dfs(v);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}
```
