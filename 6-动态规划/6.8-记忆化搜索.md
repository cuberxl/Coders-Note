### 记忆化搜索
---
**定义**：带缓存的 DFS，避免重复计算。

#### 一、滑雪

**问题**：给定一个 `n x m` 的滑雪场，每个位置都有一定高度，可向四个方向（上下左右）滑动，求最长滑雪长度。

**状态表示**：`f[i][j]`
- 集合：从 `(i, j)` 开始滑的所有路径
- 属性：`max`（最长路径长度）

**状态计算**：枚举上下左右四个方向，选择能走且能获得最长路径的方向。

**递推式**：
```
f[i][j] = max(f[tx][ty] + 1)
```
其中 `(tx, ty)` 为下一步合法的坐标，且要求高度小于当前点。

```cpp
int dfs(int x, int y) {
    if (f[x][y] != -1) return f[x][y];
    f[x][y] = 1;
    for (int i = 0; i < 4; i++) {
        int tx = x + dx[i], ty = y + dy[i];
        if (tx < 1 || tx > n || ty < 1 || ty > m) continue;
        if (h[tx][ty] < h[x][y]) {
            f[x][y] = max(f[x][y], dfs(tx, ty) + 1);
        }
    }
    return f[x][y];
}
```
