#### 区间DP

**定义**：状态表示为一个连续区间，大区间的最优解由若干小区间合并而来。

---

#### 石子合并

**问题**：有排成一排的 $N$ 堆石子，均有一定的质量，每次只能合并相邻两堆，代价为其质量之和，求合并为一堆的最小代价。

**分析**：

- **状态表示**：

- 集合：所有将第 $i$ 堆到第 $j$ 堆石子合并的方式。
- 属性：$\min$ ( 最小值 ) 。

- **状态转移**：以最后一次合并的分界线 $k$ 分类。

- 左边合并为 $f[i][k]$。
- 右边合并为 $f[k+1][j]$。
- 最后一次合并代价为区间和 $S[j] - S[i-1]$。

**递推式**：$f[i][j] = \min\limits_{i \le k < j} (f[i][k] + f[k+1][j] + S[j] - S[i-1])$。

**遍历顺序**：为保证计算 $f[i][j]$ 时，其依赖的子区间已计算完毕，按区间长度从小到大枚举。

**说明**：外层枚举区间长度，再枚举起点与终点，最后枚举分割点 $k$。

```cpp
for (int len = 2; len <= n; len++) {
    for (int i = 1; i + len - 1 <= n; i++) {
        int j = i + len - 1;
        f[i][j] = INF;
        for (int k = i; k < j; k++) {
            f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + S[j] - S[i-1]);
        }
    }
}
```

**注意**：$f[i][i] = 0$ ( 单堆无需合并 ) ，区间长度从 $2$ 开始枚举。
