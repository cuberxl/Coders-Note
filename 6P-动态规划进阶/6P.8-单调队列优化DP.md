**概念**：利用一个保持单调性的双端队列，高效维护动态规划转移中一段范围内的最大值或最小值，从而避免逐个枚举所有候选状态
三要素：
- 单调性：决策变量 $j$ 的取值范围必须是随主状态 $i$ 单调向右滑动且有界的区间
- 可分离性：代价函数 $cost(i,j)$ 必须能拆分为只与 $i$ 相关的项和只与 $j$ 相关的项之和。
- 决策支配性：新决策若比旧决策更优且存活时间更长，则旧决策可被永久淘汰。

#### $\S$ 围栏
**问题**： [AcWing 298 . 围栏](https://www.acwing.com/problem/content/300/)

**分析**：
- 考虑使用单调队列优化。
- 首先，保证 DP 的线性，将工人按照 $s_i$ 从小到大排序。
- 状态表示：$f[i][j]$ 表示让前 $i$ 涂前 $j$ 个围栏。
- 状态转移：依据最后一块木板分类。
  - 若第 $i$ 个工人没有干活，则 $f[i][j] = f[i - 1][j]$ 
  - 若第 $j$ 块模板没刷，则  $f[i][j] = f[i][j - 1]$
  - 若工人刷了 $k + 1 \sim j$ 块围栏，则 $f[i][j] = f[i][k] + p[i] * (j - k)$
  - 其中变量只有 $k$，对其进行着重分析：
  - 状态转移方程为：
$$
f[i][j] = \max(f[i][k] + p[i] * (j - k)
$$
  - 取值：$k + 1 \leq s[i] \leq j， j - k > l[i]$
  - 故 $k \in [j - l[i], j - 1], j \geq s[i]$
- 故单调性显然成立。
- 可拆分性：对状态转移方程改写：
$$
f[i][j] = p * j + \max(f[i][k] - p[i] * k)
$$
- 可拆分性成立。
- 对于决策支配性，参考滑动窗口，更劣更老的决策会更早滑出，成立。

**策略：**
对于每一层循环：
- 利用单调队列，预处理出所有决策，求其最大值，由于 $k \in [j - l[i], j - 1], j \geq s[i]$
- 故 $k \in [\max(0, s[i] - l[i]), j - 1]$。
- 对所有 $j \in [1, n]$ 进行枚举：
  - 首先更新前两种情况： $f[i][j] = max(f[i - 1][j], f[i][j - 1]$。
  - 当 $j \geq s[i]$ 时，进入第三种情况。
    - 当队头下标非法 $< j - l[i]$ 时，踢出。
    - 当队列非空时，队头为最小值，进行转移。
 - $f[m][n]$ 即为答案。

**代码**： 
```cpp
#include <bits/stdc++.h>

using namespace std;
const int N = 1.6e4 + 10, M = 1e2 + 10;

struct pt {
    int l, p, s;
};
bool operator < (pt a, pt b) {
    return a.s < b.s;
}

pt a[N];
int f[M][N];
deque<int> dq;

int calc(int i, int k) {
    return f[i - 1][k] - a[i].p * k;
}

signed main() {
    int n = rd(), m = rd();
    
    for (int i = 1; i <= m; i ++) {
        int l = rd(), p = rd(), s = rd();
        a[i] = {l, p, s};
    }
    sort(a + 1, a + m + 1);
    
    for (int i = 1; i <= m; i ++) {
        dq.clear();
        for (int k = max(0ll, a[i].s - a[i].l); k <= a[i].s - 1; k ++) {
            while (dq.size() && calc(i, dq.back()) <= calc(i, k))
                dq.pop_back();
            dq.push_back(k);
        }
        for (int j = 1; j <= n; j ++) {
            f[i][j] = max(f[i - 1][j], f[i][j - 1]);
            
            if (j >= a[i].s) {
                while (dq.size() && dq.front() < j - a[i].l)
                    dq.pop_front();
                if (dq.size())
                    f[i][j] = max(f[i][j], a[i].p * j + calc(i, dq.front()));
            }
        }
    }
    wt(f[m][n]);
    return 0;
}
```

#### $\S$ 理想的正方形

**问题**：[Acwing 1091. 理想的正方形](https://www.acwing.com/problem/content/1093/)

**分析**：此题考察二维单调队列（用于解决二维矩阵上的最值问题）。

**策略**：设矩阵大小为  $n \times m$，查询矩阵边长为 $l$。
- 使用 $n$ 个单调队列 $rdq$。
- 设 $rmx/rmn[r][i]$ 存储第 $r$ 行以 $i$ 为起点，长度为 $l$ 的滑动窗口的极值。
- 对每一行每一个长度为 $l$ 的区间，在原序列上求一次最值，存储在 $rmx/rmn$ 中。
- 再使用 $m$ 个单调队列 $cdq$。
- 设 $cmx/cmn[i][c]$ 存储第 $c$ 列以 $i$ 为起点，长度为 $l$ 的滑动窗口的极值。
- 对每一列长度为 $l$ 的区间，在 $rmx/rmn$ 上求一次最值，存储在 $cmx/rmn[]$ 中。
- 故，矩阵 $[i \sim i + l - 1],[j \sim j + l - 1]$ 的求值被转化为 $cmx/cmn[i][j]$ 的值。

```cpp
#include <bits/stdc++.h>

using namespace std;

const int N = 1e3 + 10;

int a[N][N];
int rmx[N][N], rmn[N][N];
int cmx[N][N], cmn[N][N];
deque<int> dq;

signed main() {
    int n = rd(), m = rd(), l = rd();
    for (int i = 1; i <= n; i ++) {
        for (int j = 1; j <= m; j ++) {
            a[i][j] = rd();
        }
    }
    
    for (int i = 1; i <= n; i ++) {
    	dq.clear();
        for (int j = 1; j <= m; j ++) {
        	while (dq.size() && dq.front() < j - l + 1)
        		dq.pop_front();
        	while (dq.size() && a[i][dq.back()] >= a[i][j])
        		dq.pop_back();
			dq.push_back(j);
			if (j >= l) rmn[i][j - l + 1] = a[i][dq.front()]; 
        }
    }
    
    for (int i = 1; i <= n; i ++) {
    	dq.clear();
        for (int j = 1; j <= m; j ++) {
        	while (dq.size() && dq.front() < j - l + 1)
        		dq.pop_front();
        	while (dq.size() && a[i][dq.back()] <= a[i][j])
        		dq.pop_back();
			dq.push_back(j);
			if (j >= l) rmx[i][j - l + 1] = a[i][dq.front()]; 
        }
    }
    
    for (int j = 1; j <= m - l + 1; j++) {
    	dq.clear();
        for (int i = 1; i <= n; i ++) {
        	while (dq.size() && dq.front() < i - l + 1)
        		dq.pop_front();
        	while (dq.size() && rmn[dq.back()][j] >= rmn[i][j])
        		dq.pop_back();
			dq.push_back(i);
			if (i >= l) cmn[i - l + 1][j] = rmn[dq.front()][j]; 
        }
    }
    
    for (int j = 1; j <= m - l + 1; j ++) {
    	dq.clear();
        for (int i = 1; i <= n; i ++) {
        	while (dq.size() && dq.front() < i - l + 1)
        		dq.pop_front();
        	while (dq.size() && rmx[dq.back()][j] <= rmx[i][j])
        		dq.pop_back();
			dq.push_back(i);
			if (i >= l) cmx[i - l + 1][j] = rmx[dq.front()][j]; 
        }
    }
    
    
    int ans = 1e9;
    for (int i = 1; i <= n - l + 1; i ++) {
    	for (int j = 1; j <= m - l + 1; j ++) {
    		ans = min(ans, cmx[i][j] - cmn[i][j]);
		}
	}
    wt(ans);
    return 0;
}
```
