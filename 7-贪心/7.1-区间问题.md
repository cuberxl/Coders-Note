<h3 id="区间问题"><span class="prefix"></span><span class="content">区间问题</span><span class="suffix"></span></h3>
<hr>
<h4 id="一、区间选点"><span class="prefix"></span><span class="content">一、区间选点</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定 <code>n</code> 个区间，在数轴上选择尽可能少的点，使每个区间都至少包含一个点。</p>
<p><strong>策略</strong>：</p>
<ol>
<li>将所有区间按右端点从小到大排序。</li>
<li>依次枚举每个区间，若当前区间未被覆盖，则选择该区间的右端点；否则跳过。</li>
</ol>
<p><strong>证明</strong>：设贪心结果为 <code>ans</code>，最优解为 <code>opt</code>。</p>
<ul>
<li>显然 <code>opt &lt;= ans</code></li>
<li>贪心方案选出了 <code>ans</code> 个互不相交的区间，覆盖它们至少需要 <code>ans</code> 个点，故 <code>opt &gt;= ans</code></li>
<li>综上，<code>opt = ans</code></li>
</ul>
<h4 id="二、最大不相交区间数"><span class="prefix"></span><span class="content">二、最大不相交区间数</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定 <code>n</code> 个区间，选择若干个两两不相交的区间，求最多能选多少个。</p>
<p><strong>策略</strong>：同上一题（按右端点排序，贪心选择）。</p>
<p><strong>证明</strong>：</p>
<ul>
<li><code>opt &gt;= ans</code>：贪心找到了 <code>ans</code> 个不相交区间，显然可行</li>
<li>反证法：若 <code>opt &gt; ans</code>，则至少需要 <code>opt</code> 个点覆盖所有区间，但贪心用 <code>ans</code> 个点即可覆盖，矛盾</li>
<li>综上，<code>opt = ans</code></li>
</ul>
<h4 id="三、区间分组"><span class="prefix"></span><span class="content">三、区间分组</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定 <code>n</code> 个区间，将其划分为若干组，使组内区间两两不相交，求最少分组数。</p>
<p><strong>策略</strong>：</p>
<ol>
<li>将所有区间按左端点从小到大排序。</li>
<li>依次处理每个区间，判断能否放入现有组中：
<ul>
<li>若不能（与所有组冲突），则新建一个组</li>
<li>若可以，则更新该组的最右端点</li>
</ul>
</li>
<li>用小根堆维护各组的最右端点，便于快速判断。</li>
</ol>
<p><strong>证明</strong>：设贪心结果为 <code>ans</code>，最优解为 <code>opt</code>。</p>
<ul>
<li>显然 <code>opt &lt;= ans</code></li>
<li>当建立第 <code>ans</code> 个组时，该区间的左端点 <code>L</code> 与其他 <code>ans-1</code> 个组的左端点均有冲突，即 <code>ans</code> 个区间在 <code>L</code> 处相交，至少需要 <code>ans</code> 个组来分开它们，故 <code>opt &gt;= ans</code></li>
<li>综上，<code>opt = ans</code></li>
</ul>
<h4 id="四、区间覆盖"><span class="prefix"></span><span class="content">四、区间覆盖</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：给定 <code>n</code> 个区间和一个目标区间 <code>[s, t]</code>，用最少的区间完全覆盖 <code>[s, t]</code>。</p>
<p><strong>策略</strong>：</p>
<ol>
<li>将所有区间按左端点从小到大排序。</li>
<li>依次枚举每个区间，在所有能覆盖当前起点 <code>s</code> 的区间中，选择右端点最大的区间。</li>
<li>将 <code>s</code> 更新为该右端点，继续覆盖，直到覆盖到 <code>t</code>。</li>
</ol>
<p><strong>证明</strong>（替换法）：对于贪心方案的第一次选择，我们选择了右端点最大的区间。若最优解 <code>opt</code> 选择的不是该区间，可将其替换为贪心选择的区间，不影响后续覆盖且区间数不变。依此类推，贪心解与最优解等价。故 <code>opt = ans</code>。</p>
