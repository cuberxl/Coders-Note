#### 哈夫曼树

- **定义**：给定 $n$ 个权值作为叶子节点，构造一棵二叉树，使得所有叶节点的带权路径长度之和最小，这样的树称为哈夫曼树，也叫最优二叉树。
  - 带权路径长度 = 叶子权值 × 路径长度。

- **满二叉树**：每个节点要么是叶节点，要么有两个子节点。哈夫曼树一定是一棵满二叉树。

- **贪心策略**：每次取出权值最小的两个，合并成新节点，放回集合。

- **证明**：
  1. **引理**：权值最小的两个叶子一定在最底层，且可以为兄弟。
     - **反证法**：若深度最大的叶子不是最小，将其与最小的叶子交换，权值仍会变小，矛盾。
  2. 将 $w_1, w_2$ 合并，得 $n-1$ 个叶子的树，原问题变为规模更小的同类问题。故一直递归，得到最优解。

#### 哈夫曼编码

- **概念**：一种用于数据压缩的变长编码方式。根据字符出现的频率 ( 即权值 ) 构建哈夫曼树，频率越高的字符离根节点越近，编码越短。

- **构建规则**：
  - 将每个字符看作一个叶子节点，其权值为该字符在文本中出现的频率 ( 次数 )。
  - 按照哈夫曼树的贪心策略构建出最优二叉树。
  - 从根节点出发，走向左子节点记为 `0`，走向右子节点记为 `1` ( 反之亦可 )。
  - 从根节点到某字符叶子节点的路径上经过的 `0/1` 序列，即为该字符的哈夫曼编码。

- **性质**：
  - **前缀码**：任何一个字符的编码都不是另一个字符编码的前缀，保证了解码时不会产生歧义。
  - **最优性**：由于哈夫曼树的带权路径长度最小，因此这种编码方式能使整个文本编码后的总长度最短。

#### n 叉哈夫曼树与补 0

- **概念**：将二叉哈夫曼树推广到 $n$ 叉 ( 每个节点最多有 $n$ 个子节点 )，即每次从集合中取出权值最小的 $n$ 个节点合并。

- **问题与补 0 操作**：
  - 在严格 $n$ 叉哈夫曼树中 ( 每个非叶子节点必须恰好有 $n$ 个子节点 )，如果叶子节点总数 $N$ 无法满足 $(N - 1) \bmod (n - 1) == 0$，那么最后一次合并时凑不够 $n$ 个节点，会导致树根不是严格满的，影响最优性。
  - **补 0 策略**：为了让每次合并都能完美取出 $n$ 个节点，需要在初始叶子节点中补充若干个权值为 $0$ 的虚叶子节点。
  - **补充数量**：若 $(N - 1) \bmod (n - 1) \neq 0$，则需要补充的 $0$ 的个数为 $(n - 1) - ((N - 1) \bmod (n - 1))$。
  - 补 $0$ 之后，按照每次取最小 $n$ 个节点合并的贪心策略构建，即可得到最优的 $n$ 叉哈夫曼树。
