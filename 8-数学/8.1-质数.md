<h3 id="8.1-质数"><span class="prefix"></span><span class="content">8.1 质数</span><span class="suffix"></span></h3>
<hr>
<p><strong>定义</strong>：在大于 <code>1</code> 的整数中，若其仅被 <code>1</code> 和自身整除，则称该数为质数（或素数），否则称为合数。</p>
<h4 id="一、试除法判定质数"><span class="prefix"></span><span class="content">一、试除法判定质数</span><span class="suffix"></span></h4>
<p><strong>依据定义</strong>：枚举每个约数，判断是否能整除。</p>
<p><strong>优化</strong>：若 <code>d|n</code>，则 <code>(n/d)|n</code>，故只需枚举每对约数中的较小者，即只枚举至 <code>√n</code>，故 <code>i ≤ n/i</code>。</p>
<p><strong>注意</strong>：<code>sqrt(n)</code> 较慢，且有浮点误差，不建议使用。写 <code>i*i ≤ n</code>，若 <code>n</code> 接近 <code>INT_MAX</code>，<code>i*i</code> 会溢出，导致 TLE。</p>
<h4 id="二、分解质因数（试除法）"><span class="prefix"></span><span class="content">二、分解质因数（试除法）</span><span class="suffix"></span></h4>
<p>从小到大枚举 <code>x</code> 的所有约数并一直试除，直至无法整除。</p>
<p>枚举至 <code>i</code> 时，<code>x</code> 中已不含 <code>2 ~ i-1</code> 的质因子。若能整除，则 <code>i</code> 是质因子。</p>
<p><strong>优化</strong>：<code>n</code> 中只包含一个大于 <code>√n</code> 的质因子（反证法易证）。故可以枚举至 <code>√n</code>，特判最后一个质因子。</p>
<p><strong>时间复杂度</strong>：<code>O(log n) ~ O(√n)</code>。</p>
<h4 id="三、质数筛法"><span class="prefix"></span><span class="content">三、质数筛法</span><span class="suffix"></span></h4>
<p><strong>1. 朴素筛法</strong></p>
<p>得到一个数表，将每个数的倍数都删去，若有未删去的数，则 <code>2 ~ n-1</code> 均不能将其整除，则该数为质数。</p>
<p><strong>时间复杂度</strong>：<code>O(n log n)</code>。</p>
<p>调和级数：<code>lim(n→∞)(1/1 + 1/2 + ... + 1/n) = ln(n) + C</code>（C 是欧拉常数，约为 <code>0.577</code>）</p>
<p><strong>2. 优化筛法（埃氏筛）</strong></p>
<p>判断一个数是否为质数，仅需判断 <code>1 ~ n-1</code> 的质数，故将所有质数的倍数删去即可。</p>
<p><strong>质数定理</strong>：<code>1 ~ n</code> 中有 <code>n/ln n</code> 个质数。</p>
<p><strong>质数倒数和公式</strong>：<code>∑1/p ≈ ln ln n + M</code>，其中 M 为梅塞尔-梅尔滕斯常数，约为 <code>0.261497</code>。</p>
<p><strong>时间复杂度</strong>：<code>O(n log log n)</code>。</p>
<p><strong>3. 优化埃氏筛法</strong></p>
<ul>
<li>每个质数的倍数筛除时，当 <code>k &lt; i</code> 时，<code>i × k</code> 已被更小的质数筛过，无需再筛。故可以从 <code>i × i</code> 开始筛。</li>
<li>若 <code>i &gt; √n</code> 且 <code>i</code> 为合数，那么 <code>i = a × b</code>，显然 <code>a, b</code> 中必有一个小于等于 <code>√n</code>，故只需枚举到 <code>√n</code> 即可筛掉 <code>1 ~ n</code> 的全部质数。</li>
</ul>
<p><strong>时间复杂度</strong>：<code>O(n log log n)</code>，常数更小。</p>
<p><strong>4. 线性筛法（欧拉筛）</strong></p>
<p><strong>核心</strong>：每一个数只会被它的最小质因子筛去。</p>
<p><strong>流程</strong>：</p>
<ul>
<li>若当前数 <code>i</code> 未被筛掉，则 <code>i</code> 为质数。</li>
<li>枚举质数表中的质数 <code>p_j</code>，求积 <code>i × p_j</code>。务必保证 <code>i × p_j ≤ n</code>。</li>
<li>若 <code>i</code> 能被当前质数整除，则停止循环。</li>
</ul>
<p><strong>证明</strong>：</p>
<ol>
<li>当 <code>i % p_j == 0</code> 时，显然 <code>p_j</code> 是 <code>i</code> 的最小质因子，则 <code>i × p_j</code> 的最小质因子也是 <code>p_j</code>。</li>
<li>当 <code>i % p_j != 0</code> 时，<code>p_j</code> 一定小于 <code>i</code> 的所有质因子，即 <code>p_j</code> 也是 <code>i × p_j</code> 的最小质因子。</li>
<li>对于任一合数 <code>x</code>，设 <code>p</code> 为其最小质因子，当 <code>i = x/p</code> 时，<code>x</code> 会被筛去，且 <code>i</code> 一定会枚举到 <code>x/p</code>。原因：<code>x = i × p</code>，<code>p</code> 为 <code>x</code> 的最小质因子，若枚举不到 <code>p</code>，则 <code>x</code> 必有一个更小的质因子 <code>q &lt; p</code>，矛盾。</li>
</ol>
<p><strong>综上</strong>：对于任意一个合数 <code>x</code>，它会被其最小质因子筛去。</p>
<p><strong>时间复杂度</strong>：<code>O(n)</code>。</p>
