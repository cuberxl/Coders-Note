<h3 id="8.2-约数"><span class="prefix"></span><span class="content">8.2 约数</span><span class="suffix"></span></h3>
<hr>
<p><strong>定义</strong>：若整数 <code>a</code> 能被整数 <code>b</code> 整除，则 <code>b</code> 就叫做 <code>a</code> 的约数（因数），记为 <code>b|a</code>。</p>
<h4 id="一、试除法求一个数的所有约数"><span class="prefix"></span><span class="content">一、试除法求一个数的所有约数</span><span class="suffix"></span></h4>
<p>枚举每个数，判断是否能整除。</p>
<p><strong>优化</strong>：同质数判定，枚举至 <code>√n</code>，较大的约数由 <code>n/i</code> 计算所得。</p>
<p><strong>注意</strong>：<code>i × i = n</code> 时只加一次。</p>
<h4 id="二、约数个数"><span class="prefix"></span><span class="content">二、约数个数</span><span class="suffix"></span></h4>
<p><strong>引理</strong>：代数基本定理：<code>n = p1^a1 · p2^a2 · ... · pk^ak</code>。</p>
<p>对 <code>n</code> 的任意一个因数 <code>d</code>，有 <code>d = p1^b1 · p2^b2 · ... · pk^bk</code>，其中 <code>0 ≤ bi ≤ ai</code>。由乘法原理，因数个数为 <code>(a1+1)(a2+1)...(ak+1)</code> 个。</p>
<p><strong>举例</strong>：<code>int</code> 范围内，约数最多的数高度合数，如 <code>963460800</code>，有 <code>1536</code> 个约数。</p>
<h4 id="三、约数之和"><span class="prefix"></span><span class="content">三、约数之和</span><span class="suffix"></span></h4>
<p><strong>公式</strong>：<code>(p1^0 + p1^1 + ... + p1^a1)(p2^0 + p2^1 + ... + p2^a2)...(pk^0 + pk^1 + ... + pk^ak)</code></p>
<p>展开后每一项都是 <code>p1^b1 · p2^b2 · ... · pk^bk</code> 的形式，<code>0 ≤ bi ≤ ai</code>，每一项均为 <code>n</code> 的不同约数，故不重不漏地枚举了所有约数。</p>
<p><strong>秦九韶算法</strong>：对于多项式 <code>f(x) = an·x^n + a(n-1)·x^(n-1) + ... + a1·x + a0</code>，等价于递推关系：</p>
<pre><code>bn = an
bk = b(k+1) · x + ak
</code></pre>
<p>可利用该算法计算每一项的系数，也称作<strong>霍纳法则</strong>。</p>
<h4 id="四、欧几里得算法（辗转相除法）"><span class="prefix"></span><span class="content">四、欧几里得算法（辗转相除法）</span><span class="suffix"></span></h4>
<p><strong>引理</strong>：若 <code>d|a</code> 且 <code>d|b</code>，则 <code>d|(ax+by)</code> 恒成立。</p>
<p><strong>定理</strong>：<code>gcd(a,b) = gcd(b, a mod b)</code>。</p>
<p><strong>证明</strong>：不妨设 <code>a = q × b + r</code>，即 <code>r = a mod b</code>。对于 <code>a, b</code> 的公因数 <code>d</code>：<br>
<code>∵ d|a, d|b ∴ d|(a-qb)</code>，即 <code>d|r</code>；反之亦然，得证。</p>
