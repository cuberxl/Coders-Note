### 8.2 约数

---

**定义**：若整数 `a` 能被整数 `b` 整除，则 `b` 就叫做 `a` 的约数（因数），记为 `b|a`。


#### 一、试除法求一个数的所有约数

枚举每个数，判断是否能整除。

**优化**：同质数判定，枚举至 `√n`，较大的约数由 `n/i` 计算所得。

**注意**：`i × i = n` 时只加一次。


#### 二、约数个数

**引理**：代数基本定理：`n = p1^a1 · p2^a2 · ... · pk^ak`。

对 `n` 的任意一个因数 `d`，有 `d = p1^b1 · p2^b2 · ... · pk^bk`，其中 `0 ≤ bi ≤ ai`。由乘法原理，因数个数为 `(a1+1)(a2+1)...(ak+1)` 个。

**举例**：`int` 范围内，约数最多的数高度合数，如 `963460800`，有 `1536` 个约数。


#### 三、约数之和

**公式**：`(p1^0 + p1^1 + ... + p1^a1)(p2^0 + p2^1 + ... + p2^a2)...(pk^0 + pk^1 + ... + pk^ak)`

展开后每一项都是 `p1^b1 · p2^b2 · ... · pk^bk` 的形式，`0 ≤ bi ≤ ai`，每一项均为 `n` 的不同约数，故不重不漏地枚举了所有约数。

**秦九韶算法**：对于多项式 `f(x) = an·x^n + a(n-1)·x^(n-1) + ... + a1·x + a0`，等价于递推关系：
```
bn = an
bk = b(k+1) · x + ak
```
可利用该算法计算每一项的系数，也称作**霍纳法则**。


#### 四、欧几里得算法（辗转相除法）

**引理**：若 `d|a` 且 `d|b`，则 `d|(ax+by)` 恒成立。

**定理**：`gcd(a,b) = gcd(b, a mod b)`。

**证明**：不妨设 `a = q × b + r`，即 `r = a mod b`。对于 `a, b` 的公因数 `d`：
`∵ d|a, d|b ∴ d|(a-qb)`，即 `d|r`；反之亦然，得证。
