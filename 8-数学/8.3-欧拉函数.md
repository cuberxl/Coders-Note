<h3 id="8.3-欧拉函数"><span class="prefix"></span><span class="content">8.3 欧拉函数</span><span class="suffix"></span></h3>
<hr>
<p><strong>定义</strong>：<code>φ(n)</code> 表示 <code>1 ~ n</code> 中与 <code>n</code> 互质的数的个数。</p>
<p><strong>互质</strong>：若 <code>gcd(a,b) = 1</code>，则 <code>a,b</code> 互质。</p>
<h4 id="一、欧拉函数的求法"><span class="prefix"></span><span class="content">一、欧拉函数的求法</span><span class="suffix"></span></h4>
<p>设 <code>N = p1^a1 · p2^a2 · ... · pk^ak</code>，则有：<br>
<code>φ(N) = N · (1 - 1/p1) · (1 - 1/p2) · ... · (1 - 1/pk)</code></p>
<p>例：<code>φ(6) = 6 × 1/2 × 2/3 = 2</code></p>
<p><strong>证明</strong>：基于<strong>容斥原理</strong>。</p>
<ol>
<li>从 <code>1 ~ N</code> 去掉 <code>p1, p2, ..., pk</code> 的所有倍数。即 <code>N - N/p1 - ... - N/pk</code>。此时被重复减去多次。</li>
<li>加上所有 <code>pi · pj</code> 的倍数。即 <code>+ N/(p1·p2) + ...</code>。此时共被加/减了 <code>C(n,1) + C(n,2) ...</code>。</li>
<li>依次类推，最终得到上述公式。</li>
</ol>
<p><strong>观察公式</strong>：展开后每一项系数恰好为 <code>±1</code> 和 <code>±1/pi</code>，符合容斥原理。</p>
<p><strong>单点求法时间复杂度</strong>：<code>O(√n)</code>。</p>
<h4 id="二、筛法求欧拉函数"><span class="prefix"></span><span class="content">二、筛法求欧拉函数</span><span class="suffix"></span></h4>
<p>求 <code>1 ~ n</code> 个数的欧拉函数，可用线性筛法在 <code>O(n)</code> 的时间内求出。</p>
<ol>
<li>若一个数为质数，则 <code>φ(p) = p - 1</code>（<code>1 ~ p-1</code> 均与其互质）。</li>
<li>若 <code>x</code> 为合数，设 <code>x = p_j · i</code>。
<ul>
<li>若 <code>i % p_j == 0</code> 时，<code>p_j</code> 是 <code>i</code> 的最小质因子，则质因数集合不变，故 <code>φ(x) = p_j · i · (1-1/p1)... = p_j · φ(i)</code>。</li>
<li>若 <code>i % p_j != 0</code> 时，则 <code>i</code> 的质因数集合中加上 <code>p_j</code>，故 <code>φ(x) = p_j · i · (1-1/p1)...(1-1/p_j) = (p_j - 1) · φ(i)</code>。</li>
</ul>
</li>
</ol>
