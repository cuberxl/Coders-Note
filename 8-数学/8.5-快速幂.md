<h3 id="8.5-快速幂"><span class="prefix"></span><span class="content">8.5 快速幂</span><span class="suffix"></span></h3>
<hr>
<p><strong>定义</strong>：用于快速计算 <code>a^b mod p</code> 的算法。</p>
<p><strong>核心思想</strong>：将 <code>b</code> 拆分为二进制：<code>b = 2^k1 + 2^k2 + ... + 2^km</code>。</p>
<p>则 <code>a^b = a^(2^k1) · a^(2^k2) · ... · a^(2^km)</code>。故只需计算 <code>a^(2^0), a^(2^1), ...</code> 这些项，将 <code>b</code> 中二进制为 <code>1</code> 的位相乘即为答案。</p>
<h4 id="一、快速幂求逆元"><span class="prefix"></span><span class="content">一、快速幂求逆元</span><span class="suffix"></span></h4>
<p><strong>逆元</strong>：在模 <code>m</code> 下，若存在整数 <code>x</code>，使得 <code>a · x ≡ 1 (mod m)</code>，则称 <code>x</code> 是 <code>a</code> 在模 <code>m</code> 下的乘法逆元，记作 <code>a^(-1) (mod m)</code>。</p>
<p><strong>逆元存在的充要条件</strong>：<code>a</code> 与模数 <code>m</code> 互质。</p>
<p><strong>证明</strong>：<code>∵ a · x ≡ 1 (mod m)</code>，即 <code>a · x = 1 + k · m</code>，即 <code>ax - mk = 1</code>。由裴蜀定理，该方程有解的充要条件为 <code>gcd(a,m) = 1</code>，即 <code>a, m</code> 互质。</p>
<p><strong>当模数为质数 <code>p</code> 时</strong>：<code>a^(p-2) ≡ a^(-1) (mod p)</code>。</p>
<p><strong>证明</strong>：由费马小定理得 <code>a^(p-1) ≡ 1 (mod p)</code>。<code>∵ a · x ≡ 1</code>，且 <code>a · a^(p-2) = a^(p-1) ≡ 1</code>，所以 <code>x = a^(p-2)</code>。</p>
<h4 id="二、扩展欧拉定理（指数降幂）"><span class="prefix"></span><span class="content">二、扩展欧拉定理（指数降幂）</span><span class="suffix"></span></h4>
<p><strong>公式</strong>：</p>
<ul>
<li>当 <code>a, m</code> 互质时：<code>a^b ≡ a^(b mod φ(m)) (mod m)</code></li>
<li>当 <code>a, m</code> 不一定互质且 <code>b ≥ φ(m)</code> 时：<code>a^b ≡ a^(b mod φ(m) + φ(m)) (mod m)</code></li>
</ul>
<p><strong>证明（互质情况）</strong>：设 <code>b = k · φ(m) + r</code>，则 <code>r = b mod φ(m)</code>。</p>
<p><code>a^b = a^(k·φ(m) + r) = (a^φ(m))^k · a^r ≡ 1^k · a^r = a^(b mod φ(m)) (mod m)</code>。</p>
