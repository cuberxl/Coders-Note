### 8.6 扩展欧几里得算法

---

#### 一、裴蜀定理

**内容**：对于任意正整数 `a, b`，一定存在整数 `x, y`，使得 `ax + by = gcd(a, b)`。

**方程形式**：`ax + by = c` 有整数解的充要条件为 `gcd(a, b) | c`。

**证明**：当 `b = 0` 时，显然 `x = 1, y = 0` 时等式成立。

当 `b > 0` 时，假设存在一对整数 `x, y`，使 `bx + (a mod b)y = gcd(b, a mod b)`。

`bx + (a mod b)y = bx + (a - ⌊a/b⌋ · b)y = ay + b · (x - ⌊a/b⌋ · y)`

故令 `x' = y, y' = x - ⌊a/b⌋ · y`，即得 `ax' + by' = gcd(a,b)`。

由数学归纳法，得证。


#### 二、扩展欧几里得算法（exgcd）

**定义**：求一组整数解 `x, y`，满足 `ax + by = gcd(a, b)`，同时求出 `gcd(a, b)`。

**步骤**：
1. 递归计算 `gcd(b, a mod b)`，设其解为 `x, y`，满足 `bx + (a mod b)y = gcd(a, b)`。
2. 由 `a mod b = a - ⌊a/b⌋ · b`，代入得：
   `bx + (a - ⌊a/b⌋ · b)y = ay + b(x - ⌊a/b⌋ · y)`
3. 故本层解为：`x' = y, y' = x - ⌊a/b⌋ · y`


#### 三、通解

**形式**：设一组特解为 `x0, y0`，则通解为：
```
x = x0 - (b/d) · k
y = y0 + (a/d) · k
```
其中 `d = gcd(a, b)`，`k ∈ Z`。

**证明**：代入通解：
`a(x0 - (b/d)k) + b(y0 + (a/d)k) = ax0 + by0 - (ab/d)k + (ab/d)k = ax0 + by0 = gcd(a, b)`


#### 四、求线性同余方程

**问题**：求 `ax ≡ b (mod m)` 的解。

**解法**：原式等价于 `ax = my + b`，即 `ax - my = b`，令 `y' = -y`，则 `ax + my' = b`。

由裴蜀定理，该方程有解的充要条件为 `gcd(a, m) | b`。

使用扩展欧几里得算法求 `ax + my = gcd(a, m)` 的特解 `x0, y0`，则原方程的解为 `x = x0 · (b / gcd(a, m))`。
