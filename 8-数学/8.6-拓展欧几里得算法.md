<h3 id="8.6-扩展欧几里得算法"><span class="prefix"></span><span class="content">8.6 扩展欧几里得算法</span><span class="suffix"></span></h3>
<hr>
<h4 id="一、裴蜀定理"><span class="prefix"></span><span class="content">一、裴蜀定理</span><span class="suffix"></span></h4>
<p><strong>内容</strong>：对于任意正整数 <code>a, b</code>，一定存在整数 <code>x, y</code>，使得 <code>ax + by = gcd(a, b)</code>。</p>
<p><strong>方程形式</strong>：<code>ax + by = c</code> 有整数解的充要条件为 <code>gcd(a, b) | c</code>。</p>
<p><strong>证明</strong>：当 <code>b = 0</code> 时，显然 <code>x = 1, y = 0</code> 时等式成立。</p>
<p>当 <code>b &gt; 0</code> 时，假设存在一对整数 <code>x, y</code>，使 <code>bx + (a mod b)y = gcd(b, a mod b)</code>。</p>
<p><code>bx + (a mod b)y = bx + (a - ⌊a/b⌋ · b)y = ay + b · (x - ⌊a/b⌋ · y)</code></p>
<p>故令 <code>x' = y, y' = x - ⌊a/b⌋ · y</code>，即得 <code>ax' + by' = gcd(a,b)</code>。</p>
<p>由数学归纳法，得证。</p>
<h4 id="二、扩展欧几里得算法（exgcd）"><span class="prefix"></span><span class="content">二、扩展欧几里得算法（exgcd）</span><span class="suffix"></span></h4>
<p><strong>定义</strong>：求一组整数解 <code>x, y</code>，满足 <code>ax + by = gcd(a, b)</code>，同时求出 <code>gcd(a, b)</code>。</p>
<p><strong>步骤</strong>：</p>
<ol>
<li>递归计算 <code>gcd(b, a mod b)</code>，设其解为 <code>x, y</code>，满足 <code>bx + (a mod b)y = gcd(a, b)</code>。</li>
<li>由 <code>a mod b = a - ⌊a/b⌋ · b</code>，代入得：<br>
<code>bx + (a - ⌊a/b⌋ · b)y = ay + b(x - ⌊a/b⌋ · y)</code></li>
<li>故本层解为：<code>x' = y, y' = x - ⌊a/b⌋ · y</code></li>
</ol>
<h4 id="三、通解"><span class="prefix"></span><span class="content">三、通解</span><span class="suffix"></span></h4>
<p><strong>形式</strong>：设一组特解为 <code>x0, y0</code>，则通解为：</p>
<pre><code>x = x0 - (b/d) · k
y = y0 + (a/d) · k
</code></pre>
<p>其中 <code>d = gcd(a, b)</code>，<code>k ∈ Z</code>。</p>
<p><strong>证明</strong>：代入通解：<br>
<code>a(x0 - (b/d)k) + b(y0 + (a/d)k) = ax0 + by0 - (ab/d)k + (ab/d)k = ax0 + by0 = gcd(a, b)</code></p>
<h4 id="四、求线性同余方程"><span class="prefix"></span><span class="content">四、求线性同余方程</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：求 <code>ax ≡ b (mod m)</code> 的解。</p>
<p><strong>解法</strong>：原式等价于 <code>ax = my + b</code>，即 <code>ax - my = b</code>，令 <code>y' = -y</code>，则 <code>ax + my' = b</code>。</p>
<p>由裴蜀定理，该方程有解的充要条件为 <code>gcd(a, m) | b</code>。</p>
<p>使用扩展欧几里得算法求 <code>ax + my = gcd(a, m)</code> 的特解 <code>x0, y0</code>，则原方程的解为 <code>x = x0 · (b / gcd(a, m))</code>。</p>
