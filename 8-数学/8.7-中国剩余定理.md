### 8.7 中国剩余定理

---

#### 一、中国剩余定理（CRT）

设有同余方程组：
```
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
...
x ≡ ak (mod mk)
```
其中 `m1, m2, ..., mk` 两两互质。

**解法**：设 `M = m1·m2·...·mk`，`Mi = M / mi`，`ti` 为 `Mi` 模 `mi` 的逆元，即 `Mi · ti ≡ 1 (mod mi)`。因为 `m1, m2, ..., mk` 两两互质，所以 `Mi` 与 `mi` 互质，逆元 `ti` 存在。

**特解**：`x0 = a1·M1·t1 + a2·M2·t2 + ... + ak·Mk·tk`

**证明**：代入第 `i` 个方程：
- `Mi · ti ≡ 1 (mod mi)`，所以 `ai·Mi·ti ≡ ai (mod mi)`
- 对于 `∀ j ≠ i`，`Mj` 中包含因子 `mi`，所以 `Mj ≡ 0 (mod mi)`，`aj·Mj·tj ≡ 0 (mod mi)`
- 故 `x ≡ ai (mod mi)`，方程组得证。

**通解**：`x = x0 + k·M`，间隔为 `M`。最小正整数解为 `x0 mod M`。


#### 二、扩展中国剩余定理（exCRT）

**问题**：同 CRT，但 `m1, m2, ..., mk` 不一定两两互质。

**核心思想**：两两合并。

设有两个方程：
```
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
```
即 `x = a1 + k1·m1 = a2 + k2·m2`，移项得 `m1·k1 - m2·k2 = a2 - a1`。

用扩展欧几里得算法解出 `k1, k2`，有解条件为 `gcd(m1, m2) | (a2 - a1)`。

通解为：
```
k1 = k1' + (m2/d)·t
k2 = k2' + (m1/d)·t
```
代入 `x = a1 + m1·k1` 得：
`x = a1 + m1·k1' + (m1·m2/d)·t`

设 `A = a1 + m1·k1'`，`M = m1·m2 / d`，则方程变为 `x = A' + M'·t`，即 `x ≡ A' (mod M')`。

**结论**：两个方程合并为 `x ≡ A (mod M')`。依次合并所有方程，最终得到 `x ≡ A (mod M)`，最小正整数解为 `A mod M`。
