<h3 id="8.7-中国剩余定理"><span class="prefix"></span><span class="content">8.7 中国剩余定理</span><span class="suffix"></span></h3>
<hr>
<h4 id="一、中国剩余定理（crt）"><span class="prefix"></span><span class="content">一、中国剩余定理（CRT）</span><span class="suffix"></span></h4>
<p>设有同余方程组：</p>
<pre><code>x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
...
x ≡ ak (mod mk)
</code></pre>
<p>其中 <code>m1, m2, ..., mk</code> 两两互质。</p>
<p><strong>解法</strong>：设 <code>M = m1·m2·...·mk</code>，<code>Mi = M / mi</code>，<code>ti</code> 为 <code>Mi</code> 模 <code>mi</code> 的逆元，即 <code>Mi · ti ≡ 1 (mod mi)</code>。因为 <code>m1, m2, ..., mk</code> 两两互质，所以 <code>Mi</code> 与 <code>mi</code> 互质，逆元 <code>ti</code> 存在。</p>
<p><strong>特解</strong>：<code>x0 = a1·M1·t1 + a2·M2·t2 + ... + ak·Mk·tk</code></p>
<p><strong>证明</strong>：代入第 <code>i</code> 个方程：</p>
<ul>
<li><code>Mi · ti ≡ 1 (mod mi)</code>，所以 <code>ai·Mi·ti ≡ ai (mod mi)</code></li>
<li>对于 <code>∀ j ≠ i</code>，<code>Mj</code> 中包含因子 <code>mi</code>，所以 <code>Mj ≡ 0 (mod mi)</code>，<code>aj·Mj·tj ≡ 0 (mod mi)</code></li>
<li>故 <code>x ≡ ai (mod mi)</code>，方程组得证。</li>
</ul>
<p><strong>通解</strong>：<code>x = x0 + k·M</code>，间隔为 <code>M</code>。最小正整数解为 <code>x0 mod M</code>。</p>
<h4 id="二、扩展中国剩余定理（excrt）"><span class="prefix"></span><span class="content">二、扩展中国剩余定理（exCRT）</span><span class="suffix"></span></h4>
<p><strong>问题</strong>：同 CRT，但 <code>m1, m2, ..., mk</code> 不一定两两互质。</p>
<p><strong>核心思想</strong>：两两合并。</p>
<p>设有两个方程：</p>
<pre><code>x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
</code></pre>
<p>即 <code>x = a1 + k1·m1 = a2 + k2·m2</code>，移项得 <code>m1·k1 - m2·k2 = a2 - a1</code>。</p>
<p>用扩展欧几里得算法解出 <code>k1, k2</code>，有解条件为 <code>gcd(m1, m2) | (a2 - a1)</code>。</p>
<p>通解为：</p>
<pre><code>k1 = k1' + (m2/d)·t
k2 = k2' + (m1/d)·t
</code></pre>
<p>代入 <code>x = a1 + m1·k1</code> 得：<br>
<code>x = a1 + m1·k1' + (m1·m2/d)·t</code></p>
<p>设 <code>a' = a1 + m1·k1'</code>，<code>M' = m1·m2 / d</code>，则方程变为 <code>x = a' + M'·t</code>，即 <code>x ≡ a' (mod M')</code>。</p>
<p><strong>结论</strong>：两个方程合并为 <code>x ≡ a' (mod M')</code>。依次合并所有方程，最终得到 <code>x ≡ a (mod M)</code>，答案为 <code>a mod M</code>。</p>
