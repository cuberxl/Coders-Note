#### 矩阵快速幂

- **概念**：利用快速幂的思想，计算出一个矩阵的幂。
- **代码模板：**
```cpp
using namespace std;
using lint = long long;
const int N = 1e2 + 10;
const int MOD = 1e9 + 7;
struct Mat {
    lint val[N][N];
    int n, m;
    Mat(int _n, int _m) {
        n = _n, m = _m;
        memset(val, 0, sizeof val);
    }
    Mat operator * (const Mat & b) const {
        Mat c(n, b.m);
        for (int i = 1; i <= n; i ++)
            for (int k = 1; k <= m; k ++) {
                if (val[i][k] == 0) continue;
                for (int j = 1; j <= b.m; j ++)
                    c.val[i][j] = mod(c.val[i][j] + val[i][k] * b.val[k][j]);
            }
        return c;
    }
};
Mat qpow(Mat a, lint k) {
    Mat ans(a.n, a.n);
    for (int i = 1; i <= a.n; i ++)
        ans.val[i][i] = 1;
    while (k) {
        if (k & 1) ans = ans * a;
        a = a * a;
        k >>= 1;
    }
    return ans;
}
```

#### 矩阵快速幂加速递推

- **概念**：若普通递推的数据过大，$O(n)$ 也可能超时，就可以使用矩阵快速幂对递推进行一些优化。
- 可优化的前提：
  - 状态可表示为一个长度为 $n$ 的行向量矩阵（包括当前的状态和转移依赖的前驱状态），称之为状态矩阵。
  - 变化的形式是线性的。
  - 递推式在每次询问的时候都作用在不同的数据，但本身不变。
  - 递推轮数很长，但状态矩阵很小。
- **策略：**
	- 我们可以构造一个矩阵（称为转移矩阵），使状态矩阵乘上转移矩阵后可以得到下一个状态，那么第 $n$ 个状态就可以由状态矩阵乘上转移矩阵的 $n$ 次幂得出。
- 时间复杂度 $O(n^3 \log T)$，其中 $T$ 为递推轮数.

#### 求斐波那契第 n 项
- 构造状态矩阵 $F_i = [a_{i1}, a_{i2}]$，其中 $a_{i1}$ 表示斐波那契数列的第 $i - 1$ 项，$a_{i2}$ 表示斐波那契数列的第 $i$ 项.
- 定义转移矩阵 $A$，令 $F_{i - 1} \times A = F_i$，故 $A$ 应为 $2 \times 2$ 矩阵.
- 设其为$\begin{bmatrix} a & b\\ c & d\end{bmatrix}$，则：
  - $a_i = a_{i - 1} 、t a + a_i * c$
  - $a_{i + 1} = a_{i - 1} * b + a_i * d$
-  故转移矩阵为$\begin{bmatrix} 0 & 1\\ 1 & 1\end{bmatrix}$.
