# Markdown + LaTeX 速查

## 一、公式环境

| 写法 | 说明 |
| :--- | :--- |
| `$...$` | 行内公式，和文字混排 |
| `$$...$$` | 块级公式，独占一行居中 |

`$$` 前后空一行，不然容易解析失败。

---

## 三、空格

普通空格会被忽略，要用命令：

| 命令 | 宽度 |
| :--- | :--- |
| `\,` | 最窄 |
| `\ ` | 常用 |
| `\quad` | 1 字符 |
| `\qquad` | 2 字符 |
| `\!` | 负空格，缩间距 |

---

## 四、换行与对齐

- `\\` 换行
- `&` 对齐点

```latex
$$
\begin{aligned}
f(x) &= (x+1)^2 \\
&= x^2 + 2x + 1
\end{aligned}
$$
```

## 六、特殊结构

### 分段函数
```latex
$$
f(x) = \begin{cases}
1, & x > 0 \\
0, & x = 0 \\
-1, & x < 0
\end{cases}
$$
```

### 矩阵
| 环境 | 括号 |
| :--- | :--- |
| `matrix` | 无 |
| `pmatrix` | 圆括号 |
| `bmatrix` | 方括号 |
| `vmatrix` | 竖线 |
| `Bmatrix` | 花括号 |

```latex
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
```

### 方程组
```latex
$$
\begin{cases}

\end{cases}

```

| `\tbinom{n}{k}` | $\tbinom{n}{k}$ |

## 八、容易踩的坑

- `$` 没闭合 → 不渲染
- 文本里写 `$100` → 写成 `\$100`
- 表格里写 `|x|` → 写成 `\lvert x \rvert`
- 文本里写 `a_b_c` → 写成 `a\_b\_c`
- 多字符上下标不加 `{}` → 出错
- 公式里敲空格 → 要用 `\ ` 或 `\quad`
- 换行只写 `\` → 要写 `\\`
- 花括号直接写 → 用 `\{` `\}`
